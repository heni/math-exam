# Чего не хватает в литературе

Запрос на дополнительные книги. Составлен из карты покрытия (`docs/sources.md`)
и того, что по каждому вопросу нужно уметь **доказать**, а не просто изложить.

Устроен по принципу «одна книга закрывает несколько вопросов»: шесть позиций
ниже закрывают четырнадцать вопросов из двадцати.

**Оговорка про кандидатов.** Названия книг ниже — кандидаты, названные по
памяти. Выходные данные (издательство, год, издание) **не сверены** и подлежат
проверке при добавлении в `docs/sources.md`. Имя книги — не источник, пока не
открыт титульный лист.

## Достаточно покрыто, искать не нужно

- **06** (оптимальное управление, принцип максимума) — шесть-семь книг,
  включая сборник задач.
- **10** (минимизация функций многих переменных) — покрыто избыточно.
- **13** (численное дифференцирование и интегрирование) — [3] [4] плюс [21]
  `(?)`; после сверки [21] вопрос закрыт.
- **07** (Фурье, Лаплас, Хаара) — формально есть две книги по уравнениям
  математической физики, но **ни в одной не нашлось вхождения «Фурье»**. Перед
  поиском новой книги проверить их оглавления: возможно, тема есть под другим
  названием («метод разделения переменных»).

## Инструмент, а не книга

Поставить `djvulibre-bin` (утилита `djvutxt`): шесть книг коллекции в формате
`.djvu` нельзя ни искать, ни цитировать по странице. Среди них [21] и [17] —
именно те, на которые карта покрытия ссылается «по названию» для вопросов 01,
11, 13, 16, 19. Без этого пять записей останутся непроверяемыми.
