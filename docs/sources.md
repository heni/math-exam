# Литература и покрытие программы

Список книг, по которым собираются конспекты, и карта: какой вопрос программы
какой книгой закрыт. Сами файлы в репозиторий не входят — здесь
библиографические записи, по которым книгу можно найти и цитировать по странице.

## Как проверено

Покрытие установлено **поиском по содержимому**, а не по названиям: по каждой
книге с текстовым слоем прогнан поиск характерных терминов всех двадцати
вопросов. Отсюда три оговорки, все существенные:

- **Помета ✓** — выходные данные считаны с титульного листа, покрытие проверено
  поиском по тексту. **Помета (?)** — запись собрана из имени файла, титул не
  прочитан, покрытие не проверено: это книги в формате `.djvu` (нет `djvutxt` в
  системе) и два сканированных PDF без текстового слоя. Для них покрытие —
  гипотеза по названию.
- **Поиск по терминам даёт ложные срабатывания.** Проверенный случай: в [12]
  нашёлся «принцип максимума», но это принцип максимума для гармонических
  функций, а не принцип максимума Понтрягина (вопрос 06).
- Перед тем как сослаться на книгу в `README.md` вопроса, **главу надо
  открыть**: помета ✓ означает «термин в книге есть», а не «тема изложена с
  доказательствами».

## Чем коллекция сильна и где провал

**Сильно перекрыто:** оптимизация и вариационное исчисление (вопросы 06, 10) —
шесть-семь книг на вопрос, включая сборник задач [11].

**Не покрыто профильными источниками:** 05 (вейвлеты), 08, 12, 14, 17
(вероятность и статистика целиком), 09 и 15 (функциональный анализ как
предмет), 16 (машинное обучение), 04 (наблюдатели и теория управления).

**Почти бесполезны для программы:** четыре книги по линейному программированию
([9] [13] [14] [15]) — проверено, в них симплекс-метод и двойственность, а не
чебышёвское приближение как задача ЛП. Пригодятся, только если вопрос 19
решим подавать через ЛП-постановку.

Какие книги нужно добрать и зачем — `docs/wanted-sources.md`.
