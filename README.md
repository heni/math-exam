# Подготовка к кандидатскому экзамену по математике

Конспекты, численные примеры и презентации по программе вступительного
экзамена в аспирантуру, специальность **математическое моделирование,
численные методы и комплексы программ**. Двадцать вопросов программы, по
каждому — три артефакта.

## Что собирается по каждому вопросу

| Артефакт | Файл | Назначение |
|---|---|---|
| Конспект теории | `theory.pdf` | определения, формулировки, **полные доказательства**, разбор посылок |
| Численные примеры | `examples.ipynb` | воспроизводимые расчёты по теме: где метод работает и где ломается |
| Презентация | `slides.pdf` | маршрут ответа: результаты, схемы доказательств, разобранные задачи |

Конспект и презентация пишутся в Markdown с TeX-вставками (`theory.md`,
`slides.md`) и собираются pandoc'ом; ноутбук ведётся как jupytext-скрипт
`examples.py`. Подробности — `docs/build.md`.

Формулировка теоремы в презентации совпадает с конспектом слово в слово:
презентация сокращает доказательства, но не формулировки.

статистика (3, 8, 12, 14, 17), управление (4, 6, 20), машинное обучение
(2, 16, 18). Блоки заметно пересекаются: карта связей между вопросами — в
`docs/glossary.md`, раздел «Сквозные связи».

Текущая готовность: `make list`.

## Структура

```
questions/NN-slug/        материалы одного вопроса
  README.md               план содержания, связи, источники
  theory.md  -> theory.pdf
  slides.md  -> slides.pdf
  examples.py -> examples.ipynb
  figures/                картинки, построенные в examples.py
build/                    pandoc-настройки и общие LaTeX-преамбулы
templates/                шаблоны трёх артефактов
tools/                    генератор каталога вопроса, проверки, таблица готовности
docs/                     глоссарий, стиль изложения, сборка
assets/                   картинки, общие для нескольких вопросов
```

## Сборка

```bash
pip install -r requirements.txt
make new Q=11     # развернуть шаблоны в каталоге вопроса 11
make q11          # собрать его артефакты
make -j4          # собрать всё
make check        # проверки согласованности
```

Нужны `pandoc` 3.x и TeX Live с `beamer`, `beamertheme-metropolis`,
`polyglossia` и шрифтом Lato. Подробности и проверенные версии —
`docs/build.md`.

## Соглашения

- Проза — русская и развёрнутая; комментарии в коде — английские и минимально
  достаточные.
- Обозначения — только из `build/preamble-*.tex`: один символ имеет один смысл
  во всех двадцати вопросах. Зарезервированные буквы и известные коллизии
  перечислены в `docs/glossary.md`.
- Любое число в конспекте или презентации либо вычислено в `examples.py` того
  же вопроса, либо имеет ссылку на источник с указанием главы.
- Численные примеры детерминированы: seed задаётся явно через
  `np.random.default_rng(SEED)`.
- Язык и композиция изложения — `docs/style-guide.md`.
