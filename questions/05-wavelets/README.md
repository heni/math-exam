## Состав вопроса (факт)

  условием допустимости, разложением единицы и обращением (с полными

  необходимое условие фреймовости с вычислением следа, достаточное

  масштабное уравнение и маска, основное тождество, критерий Рисса,
  теорема Малла — Мейера с полным доказательством); вейвлеты с
  компактным носителем (Безу, спектральная факторизация Рисса,
  существование $\varphi$ по маске, жёсткий фрейм Лоутона, критерий

  коэффициентов, оценка Донохо — Джонстон берётся готовой).
- **Расширенная часть** (стр. 30–32): сплайн-вейвлеты Баттле — Лемарье и цена
  ортонормировки (формулы [25] гл. 7 пересчитаны на единичную
  нормировку Фурье); дискретные вейвлетные базисы в $\C^N$ и
  сплайн-вейвлеты на решётке [66].
- **Численные примеры** (examples.ipynb): (1) условие допустимости
  Хаара, $C_\psi = 2\ln 2$; (2) CWT Хаара: $\sin t$ (проверка

- **Слайды**: 26 кадров основного прохода + 3 запасных (Баттле — Лемарье,

## Разделение материала с вопросом 07

Л3 едина: спектральная иерархия «Фурье → Лаплас → Хаар → вейвлеты». Вопросы
07 и 05 разрезают её так, чтобы ни один объект не жил в двух местах:

- **Вопрос 07** несёт: рамку «интегральное преобразование с ядром» (общий
  вид $(Tf)(s)=\int K(s,t)f\,d\mu$ и таблицу ядер — от неё отталкиваются оба
  вопроса); весь аппарат Фурье (образ, обращение, Парсеваль, свёртка); ДПФ и
  БПФ; систему Хаара как ортонормированный базис $L_2$ с полнотой и БПХ.
- **Вопрос 05** несёт: непрерывное вейвлет-преобразование (CWT) с условием
  допустимости, фреймы, кратномасштабный анализ (КМА), масштабирующую функцию,
  ортонормированные вейвлеты (конструкция Добеши), быстрое вейвлетное
  преобразование, сжатие.
- **Точка стыка**: система Хаара — простейший ортогональный вейвлет (мост
  07→05: $\psi_{\text{Хаара}}$ одновременно закрывает базис Хаара вопроса 07
  и служит примером № 1 КМА вопроса 05; пирамида «сглаживание–детализация»
  вопроса 07 — частный случай Малла-разложения $V_j\oplus W_j$). В каждом
  конспекте стык проговорен одним замечанием, без дублирования доказательств:
  07 доказывает ортонормированность и полноту Хаара, 05 — аксиомы КМА на его
  примере со ссылкой «простейший случай».

## Что должно войти

### Определения

- [x] непрерывное вейвлет-преобразование $CWT(a,b)$; масштаб $a$ и сдвиг $b$;
      условие допустимости $C_\psi<\infty$; материнский вейвлет;
- [x] фрейм, константы фрейма $A,B$; тесный фрейм; фреймовый оператор;
- [x] кратномасштабный анализ: лестница $V_j$, масштабирующая функция $\varphi$,
      ортодополнение $W_j$, вейвлет $\psi$, маски (квадратуры зеркальных
      фильтров);
- [x] вейвлеты Добеши (компактный носитель, степень гладкости);
- [x] быстрое вейвлетное преобразование (БВП): каскадная схема; банк фильтров;
- [x] двумерное разложение и сжатие (JPEG2000-рамка).

### Теоремы с полными доказательствами (план, детализируется при написании)

- [x] **Т1 (условие допустимости и обращение CWT).** Разложение единицы
      (resolution of identity): условие $C_\psi<\infty$ необходимо и
      достаточно для восстановления; формула обращения [11] гл. 2.
- [x] **Т2 (фреймы и устойчивость).** Определение фрейма; неравенство фрейма;
      существование двойственного фрейма; условие фрейма $\{ \psi_{j,k}\}$
      [11] гл. 3, §3.3.2 границы фрейма.
- [x] **Т3 (из фрейма — к КМА).** Когда диадический фрейм порождает КМА;
      базисы Рисса в $V_0$ [11] гл. 5.
- [x] **Т4 (существование ортонормированного вейвлет-базиса).** Маска $m_0$,
      критерий Коэна (в литературе — критерий Коэна — Добеши — Фово;
      в конспекте — критерий Коэна с полным доказательством, следствие
      Воэна; матричный критерий Лоутона — формулировкой).
- [x] **Т5 (регулярность и моменты).** Степень гладкости $\psi$ и число
      нулевых моментов $\int t^k\psi=0$; скорость убывания коэффициентов для
      гладких сигналов (противопоставление сомнительному «$O(1/j)$» из Л3).
- [x] **Т6 (алгоритм БВП).** Каскадное разложение: быстрота $O(N)$, обратная
      схема; связь с банком фильтров [11] гл. 5, [66] гл. 2 §4.
- [x] **Т7 (сжатие).** Оценка ошибки пороговой обработки через число нулевых
      моментов и модуль непрерывности; почему вейвлеты Добеши лучше Хаара для
      гладких сигналов [25] гл. 9? (уточнить главу при написании).
