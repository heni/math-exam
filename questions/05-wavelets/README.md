## Разделение материала с вопросом 07

Л3 едина: спектральная иерархия «Фурье → Лаплас → Хаар → вейвлеты». Вопросы
07 и 05 разрезают её так, чтобы ни один объект не жил в двух местах:

- **Вопрос 07** несёт: рамку «интегральное преобразование с ядром» (общий
  вид $(Tf)(s)=\int K(s,t)f\,d\mu$ и таблицу ядер — от неё отталкиваются оба
  вопроса); весь аппарат Фурье (образ, обращение, Парсеваль, свёртка); ДПФ и
  БПФ; систему Хаара как ортонормированный базис $L_2$ с полнотой и БПХ.
- **Вопрос 05** несёт: непрерывное вейвлет-преобразование (CWT) с условием
  допустимости, фреймы, кратномасштабный анализ (КМА), масштабирующую функцию,
  ортонормированные вейвлеты (конструкция Добеши), быстрое вейвлетное
  преобразование, сжатие.
- **Точка стыка**: система Хаара — простейший ортогональный вейвлет (мост
  07→05: $\psi_{\text{Хаара}}$ одновременно закрывает базис Хаара вопроса 07
  и служит примером № 1 КМА вопроса 05; пирамида «сглаживание–детализация»
  вопроса 07 — частный случай Малла-разложения $V_j\oplus W_j$). В каждом
  конспекте стык проговорен одним замечанием, без дублирования доказательств:
  07 доказывает ортонормированность и полноту Хаара, 05 — аксиомы КМА на его
  примере со ссылкой «простейший случай».

## Что должно войти

### Определения

- [ ] непрерывное вейвлет-преобразование $CWT(a,b)$; масштаб $a$ и сдвиг $b$;
      условие допустимости $C_\psi<\infty$; материнский вейвлет;
- [ ] фрейм, константы фрейма $A,B$; тесный фрейм; фреймовый оператор;
- [ ] кратномасштабный анализ: лестница $V_j$, масштабирующая функция $\varphi$,
      ортодополнение $W_j$, вейвлет $\psi$, маски (квадратуры зеркальных
      фильтров);
- [ ] вейвлеты Добеши (компактный носитель, степень гладкости);
- [ ] быстрое вейвлетное преобразование (БВП): каскадная схема; банк фильтров;
- [ ] двумерное разложение и сжатие (JPEG2000-рамка).

### Теоремы с полными доказательствами (план, детализируется при написании)

- [ ] **Т1 (условие допустимости и обращение CWT).** Разложение единицы
      (resolution of identity): условие $C_\psi<\infty$ необходимо и
      достаточно для восстановления; формула обращения [11] гл. 2.
- [ ] **Т2 (фреймы и устойчивость).** Определение фрейма; неравенство фрейма;
      существование двойственного фрейма; условие фрейма $\{ \psi_{j,k}\}$
      [11] гл. 3, §3.2 границы фрейма.
- [ ] **Т3 (из фрейма — к КМА).** Когда диадический фрейм порождает КМА;
      базисы Рисса в $V_0$ [11] гл. 5.
- [ ] **Т4 (существование ортонормированного вейвлет-базиса).** Маска $m_0$,
      условие Коэна—Добеши—Фово? (проверить по [11] гл. 6 — выбрать нужный
      критерий; в конспекте — достаточное условие с доказательством).
- [ ] **Т5 (регулярность и моменты).** Степень гладкости $\psi$ и число
      нулевых моментов $\int t^k\psi=0$; скорость убывания коэффициентов для
      гладких сигналов (противопоставление сомнительному «$O(1/j)$» из Л3).
- [ ] **Т6 (алгоритм БВП).** Каскадное разложение: быстрота $O(N)$, обратная
      схема; связь с банком фильтров [11] гл. 5, [66] гл. 2 §4.
- [ ] **Т7 (сжатие).** Оценка ошибки пороговой обработки через число нулевых
      моментов и модуль непрерывности; почему вейвлеты Добеши лучше Хаара для
      гладких сигналов [25] гл. 9? (уточнить главу при написании).

### Численные примеры (план)
