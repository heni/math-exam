### Теоремы с полными доказательствами

Ядро (спросят):

- [x] байесовское правило минимизирует апостериорный риск почти всюду; равенство
      байесовского риска среднему апостериорного (Тонелли) — идея [07] теорема 11.1;
- [x] квадратичная потеря: байесовское правило = апостериорное среднее (доказательство

- [x] абсолютная потеря: байесовское правило = апостериорная медиана (доказательство
      через интегральное представление $\mathsf E\lvert\theta-c\rvert$);
- [x] потеря 0-1 (конечное $\Theta$): байесовское правило = MAP;
- [x] достаточное условие минимаксности: байесовское правило с риском, не
      превосходящим байесовский, минимаксно; частный случай — постоянный риск;
      следствие: априорное наименее благоприятно — [07] лемма (1) и следствие,
      печ. 104–105;
- [x] лемма о последовательности априорных (предельный переход) — [07] лемма (2),
      печ. 107;
- [x] $\overline X_N$ — минимаксная оценка среднего нормального закона при
      квадратичной потере, минимаксный риск $\sigma^2/N$; биномиальная модель:
      оценка $a\overline X_N+b$ с постоянным риском, минимаксный риск
      $1/(4(\sqrt N+1)^2)$, наихудшее априорное $\mathrm{Beta}(\sqrt N/2,\sqrt N/2)$
