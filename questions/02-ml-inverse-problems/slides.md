## План и мотивация

- Один объект — три имени: регуляризация Тихонова (обратные задачи) =
  гребневая регрессия (*ridge regression*, статистика) = $L_2$-регуляризация,
  или снижение весов (*weight decay*, машинное обучение).
- Прямая задача: по параметрам модели $q$ вычисляется выход $f = Aq$;
  обратная — по наблюдаемому выходу $f$ определить причину $q$ [42] (Галанин).
- Три группы обратных задач [42] (Галанин): по постановке (характеристики
  среды по замерам решения); структура и параметры модели по опытным данным;
  синтез системы по желаемому выходу. Обучение модели — задача второй группы.
- План: основная часть — обратные задачи и регуляризация; расширенная часть —
  ИНС и методы обучения.

## Корректность по Адамару

Пусть $A$ отображает $Q$ в $F$; вместо $f$ задано приближение $f_\delta$ с
уровнем погрешности $\delta > 0$, $\norm{f - f_\delta} \le \delta$; точное
решение — $q_T$.

\begin{definition}\label{def:hadamard}
Задача $Aq = f$ \textbf{корректна на паре пространств $Q$ и $F$ (корректна
по Адамару)}, если выполнены три условия [14] (Кабанихин):

1) для любого $f \in F$ существует решение $q_T \in Q$, то есть $R(A) = F$
(существование);

2) решение единственно, то есть существует обратный оператор $A^{-1}$
(единственность);

3) для любой окрестности $O(q_T) \subset Q$ найдётся окрестность
$O(f) \subset F$ такая, что $A^{-1} O(f) \subset O(q_T)$, то есть $A^{-1}$
непрерывен (устойчивость).
\end{definition}

\begin{definition}
Задача $Aq = f$ \textbf{некорректна} (англ. \textit{ill-posed problem} — [32], [39]) на
паре $Q$, $F$, если нарушено хотя бы одно из трёх требований
определения [14] (Кабанихин).
\end{definition}

## Примеры неустойчивости

:::::: columns
::: {.column width="52%"}
- Дифференцирование: $f_\delta = f + \delta \sin(x/\delta^2)$, тогда
  $\norm{f_\delta - f}_C = \delta$, но $\norm{(f_\delta - f)'}_C = 1/\delta \to \infty$ [14] (Кабанихин). Численно: наклон $\log h^*$ против $\log \delta$ равен $0{,}527$ при предсказанных $1/2$.
- Фредгольм 1-го рода: $q_n = q_T + n \sin(n^2 s)$ — $\norm{q_n - q_T}_C \to \infty$ при $\norm{A q_n - f}_C \le K_1/n^2 \to 0$ [14] (Кабанихин).
- Теплопроводность, обратное время: ошибка $\delta_n$ в $n$-й моде превращается в $\delta_n e^{a^2 \pi^2 n^2 T / l^2}$ [14] (Кабанихин).
- Задача Коши для Лапласа: $u_n = \frac1n \sin(ny) \cosh(nx)$ — данные $\to 0$, решение растёт как $e^{nx}/(2n)$ [14].

## Условная корректность

\begin{definition}\label{def:conditional}
Задача $Aq = f$ \textbf{условно корректна на множестве $M \subset Q$
(корректна по Тихонову)}, если $f \in A(M)$ и выполнены условия [14]
(Кабанихин):

1) решение $q_T$ единственно на $M$;

2) для любой окрестности $O(q_T)$ существует окрестность $O(f)$ такая, что
$A^{-1}\bigl(O(f) \cap A(M)\bigr) \subset O(q_T)$ (условная устойчивость).

Множество $M$ называется \textbf{множеством корректности} [14] (Кабанихин).
\end{definition}

\begin{theorem}[непрерывность обратного оператора на компакте]
Пусть $Q$ и $F$ — метрические пространства, $M \subset Q$ компактно,
отображение $A : Q \to F$ непрерывно и взаимно однозначно переводит $M$ в
$A(M) \subset F$. Тогда обратное отображение $A^{-1} : A(M) \to M$
непрерывно.
\end{theorem}

Модуль непрерывности $\omega(\delta) = \sup\{\rho_Q(A^{-1} f_1, A^{-1} f_2) : f_1, f_2 \in A(M),\ \rho_F(f_1, f_2) \le \delta\}$ — лучшая гарантированная оценка погрешности на классе $M$.

## Регуляризирующий алгоритм

\begin{definition}\label{def:reg-family}
\textbf{Регуляризирующим семейством} для задачи $Aq = f$ называется семейство
операторов $\{R_\alpha\}_{\alpha > 0}$, $R_\alpha : F \to Q$, такое что [14]
(Кабанихин):

1) для любого $\alpha > 0$ оператор $R_\alpha$ непрерывен;

2) для любого $f \in R(A)$ и $q_T = A^{-1}f$
$\lim_{\alpha \to +0} R_\alpha f = q_T$.
\end{definition}

\begin{definition}\label{def:reg-algorithm}
Пусть вместо $f$ задано $f_\delta$ с $\norm{f - f_\delta} \le \delta$.
Отображение $R_{\alpha(\delta, f_\delta)}$, сопоставляющее данным элемент
$q_{\alpha\delta} = R_{\alpha(\delta, f_\delta)} f_\delta$, —
\textbf{регуляризирующий алгоритм} (англ. \textit{regularization algorithm}), если
$\sup_{\norm{f - f_\delta} \le \delta} \norm{R_{\alpha(\delta, f_\delta)}
f_\delta - A^{-1} f} \longrightarrow 0 \;(\delta \to 0)$
для всех $f \in R(A)$; выбор $\alpha = \alpha(\delta, f_\delta)$ —
\textbf{согласование параметра регуляризации с погрешностью данных}.
\end{definition}

Ключевая оценка: $\norm{q_T - q_{\alpha\delta}} \le \gamma(q_T, \alpha) + \norm{R_\alpha}\,\delta$; уклонение $\gamma$ мало при малых $\alpha$, а $\norm{R_\alpha} \to \infty$ при $\alpha \to 0$ — точность и устойчивость \textbf{балансируются параметром $\alpha$}.

## Метод Тихонова

\begin{definition}\label{def:tikhonov-functional}
Пусть $Q$, $F$ — гильбертовы пространства, $A : Q \to F$ — линейный
ограниченный оператор, $f_\delta \in F$, $q^0 \in Q$ — пробное решение
(априорное приближение). \textbf{Функционалом Тихонова} называется
$$M^\alpha[q] = \norm{Aq - f_\delta}^2 + \alpha\,\norm{q - q^0}^2 ,
\qquad \alpha > 0 ,$$
а \textbf{методом регуляризации А. Н. Тихонова} — построение приближённого
решения по правилу $q_{\alpha\delta} = \argmin_{q \in Q} M^\alpha[q]$
[14] (Кабанихин).
\end{definition}

\begin{theorem}[существование и единственность минимизатора]
Пусть $Q$ и $F$ — гильбертовы пространства, $A : Q \to F$ — линейный
ограниченный оператор, $\alpha > 0$, $q^0 \in Q$. Тогда для любого
$f_\delta \in F$ функционал $M^\alpha$
достигает своей нижней грани на единственном элементе $q_\alpha \in Q$.
\end{theorem}

\begin{proposition}[нормальное уравнение]
Минимизатор $q_\alpha$ функционала Тихонова
удовлетворяет уравнению Эйлера
$(A^*A + \alpha I)\, q_\alpha = A^* f_\delta + \alpha q^0$,
причём оператор $A^*A + \alpha I$ обратим и $\norm{(A^*A + \alpha I)^{-1}}
\le 1/\alpha$.
\end{proposition}

## Сходимость и скорость

\begin{theorem}[сходимость метода Тихонова]
Пусть $Q$, $F$ — гильбертовы пространства, $A : Q \to F$ — линейный
вполне непрерывный оператор, $f \in R(A)$, решение $q_T$ уравнения $Aq = f$
единственно. Пусть $\norm{f - f_\delta} \le \delta$, и параметр выбран по
правилу $\alpha = \alpha(\delta)$ так, что
$$\lim_{\delta \to 0} \alpha(\delta) = 0,
\qquad
\lim_{\delta \to 0} \frac{\delta^2}{\alpha(\delta)} = 0 .$$
Тогда регуляризованные решения $q_{\alpha(\delta),\delta}$
сходятся к точному:
$\norm{q_{\alpha(\delta),\delta} - q_T} \to 0$ при $\delta \to 0$.
\end{theorem}

\textbf{Схема доказательства:} ограниченность $\norm{q_{\alpha\delta} - q^0}^2 \le \delta^2/\alpha + \norm{q_T - q^0}^2$ $\to$ слабая сходимость подпоследовательностей, которую вполне непрерывность $A$ переводит в сильную $\to$ сильная сходимость через раскрытие квадрата нормы. Полное доказательство — в theory.pdf.

Скорость: в конечномерном разрешимом случае из нормального уравнения $\norm{q_{\alpha\delta} - q_T} \le \frac{\alpha}{\lambda_r}\norm{q_T} + \frac{\delta}{2\sqrt{\alpha}}$ ($\lambda_r$ — наименьшее положительное собственное значение $A^*A$); балансировка двух членов при $\delta \sim \varepsilon$ даёт $\alpha \sim \varepsilon^{2/3}$ и точность $O(\varepsilon^{2/3})$ [14] (Кабанихин).

## Принцип невязки

\begin{lemma}[монотонность невязки]
Пусть $A : \R^n \to \R^m$ — линейный оператор, $f_\delta \in \R^m$,
$q^0 = 0$, $q_\alpha = (A^*A + \alpha I)^{-1}A^* f_\delta$, и пусть
$X = U D V^{\T}$ — сингулярное разложение $A$ с сингулярными числами
$d_1 \ge \dots \ge d_r > 0$. Тогда невязка
$$\rho(\alpha) = \norm{A q_\alpha - f_\delta}^2
= \sum_{j=1}^{r} \Bigl( \frac{\alpha}{d_j^2 + \alpha} \Bigr)^{\!2}
\bigl( u_j^{\T} f_\delta \bigr)^2 + \norm{(I - P) f_\delta}^2 ,$$
где $P$ — ортогональный проектор на $R(A) = \operatorname{lin}\{u_1, \dots, u_r\}$.
В частности, $\rho$ непрерывна и (строго) монотонно возрастает по $\alpha$
при условии $P f_\delta \ne 0$, причём
$$\lim_{\alpha \to 0} \rho(\alpha) = \norm{(I-P)f_\delta}^2
= \operatorname{dist}^2(f_\delta, R(A)),
\qquad
\lim_{\alpha \to \infty} \rho(\alpha) = \norm{f_\delta}^2 .$$
\end{lemma}

\begin{theorem}[принцип невязки]
В условиях леммы пусть дополнительно $f \in
R(A)$, $\norm{f - f_\delta} \le \delta$ и
$\operatorname{dist}(f_\delta, R(A)) < \delta < \norm{f_\delta}$.
Тогда уравнение $\rho(\alpha) = \delta^2$
имеет единственный корень $\alpha(\delta) > 0$.
\end{theorem}

## Гребневой фильтр

\begin{proposition}[спектральный анализ гребня]
Пусть $X = U D V^{\T}$. Тогда
$$X \widehat w = \sum_{j=1}^{r} \frac{d_j^2}{d_j^2 + \alpha}\,
\bigl(u_j^{\T} y\bigr)\, u_j .$$
В частности, гребень оставляет направления $u_j$ и коэффициенты $u_j^{\T}y$
нетронутыми, но сжимает каждый на множитель $d_j^2/(d_j^2 + \alpha) \in
(0,1)$; сжатие сильнее всего там, где $d_j^2 \lesssim \alpha$, то есть
вдоль малых сингулярных направлений [16] (Хасти, Тибширани, Фридман).
\end{proposition}

::: {.column width="52%"}
- Эффективное число степеней свободы: $\operatorname{df}(\alpha) = \tr S = \sum_j \frac{d_j^2}{d_j^2 + \alpha}$ — от $r$ при $\alpha \to 0$ до $0$.
- Механизм: вклад шума вдоль $v_j$ умножается на $d_j/(d_j^2 + \alpha) \le 1/(2\sqrt\alpha)$ — вместо $1/d_r$ у МНК; цена — смещение.
- Тот же фильтр $\lambda/(\lambda + \alpha)$ у квазирешения Иванова: ограничение $\leftrightarrow$ штраф.

## Эмпирический риск и переобучение

Словарь: $X$ — роль $A$, $w$ — роль $q$, $y$ — роль $f_\delta$; $m$ —
число примеров, $n$ — число параметров.

\begin{definition}\label{def:empirical-risk}
Пусть $g(x, w)$ — модель с параметрами $w \in \R^n$, $\ell(\widehat y, y)$
— функция потерь. \textbf{Эмпирическим риском} (англ. \textit{empirical risk} — [51])
называется средняя потеря по обучающей выборке
$Q(w) = \frac1m \sum_{i=1}^m \ell\bigl(g(x_i, w),\, y_i\bigr)$
[53] (Воронцов); метод эмпирического риска ищет $\widehat w \in \argmin_w Q(w)$ [53] (Воронцов).
\end{definition}

При квадратичной потере $\ell(\widehat y, y) = (\widehat y - y)^2$ это ровно
МНК: $Q(w) = \tfrac1m \norm{Xw - y}^2$, $\delta \sim \sqrt m\,\sigma$.

\textbf{Переобучение — проявление некорректности по устойчивости:} в
квадратной ситуации $\widehat w = X^{-1} y$ и
$$\frac{\norm{\delta w}}{\norm{w}}
\le \varkappa(X)\, \frac{\norm{\delta y}}{\norm{y}} ;$$
в сквозном примере $\varkappa(X^{\T}X) = 2{,}4367\cdot 10^{6}$: ёмкость
даёт существование под любые данные, малые собственные значения —
неустойчивость.

## Регуляризатор как априорное распределение

\begin{theorem}[байесовский вывод $L_2$-регуляризатора]
Пусть модель линейна: $y = Xw + \varepsilon$, шум гауссовский и
гомоскедастичен: $\varepsilon_i$ независимы, $\varepsilon_i \sim
\mathcal N(0, \sigma^2)$; априорное распределение весов гауссовское:
$w \sim \mathcal N(0, \nu^2 I)$. Тогда MAP-оценка (англ. \textit{maximum a
posteriori} — максимум апостериорной плотности)
$\widehat w^{\mathrm{MAP}} = \argmax_w \bigl[ \log p(y \mid X, w) + \log
p(w) \bigr]$
совпадает с регуляризованным решением Тихонова
при $q^0 = 0$ с параметром $\alpha = \frac{\sigma^2}{\nu^2}$.
\end{theorem}

\begin{corollary}[$L_1$ и лапласовский априор]
Если априорное распределение произведение лапласовских:
$p(w) \propto \exp(-\norm{w}_1/C)$, то MAP-оценка
совпадает с минимизатором $\norm{y - Xw}^2 + \frac{2\sigma^2}{C}\, \norm{w}_1$.
\end{corollary}

(лассо: разрежённость, отбор признаков).

Три имени одного объекта [51]: регуляризация Тихонова = гребневая
регрессия = $L_2$-регуляризация / снижение весов; $\alpha = \sigma^2/\nu^2$
— отношение неопределённости данных к априорной уверенности.

## Смещение–дисперсия

\begin{theorem}[разложение смещение–дисперсия]
Пусть $y = f + \varepsilon$ с $f = (f(x_1), \dots, f(x_m))^{\T}$,
$\E\varepsilon = 0$, $\E \varepsilon \varepsilon^{\T} = \sigma^2 I$, и
оценка $\widehat f(x_0) = h(x_0)^{\T} y$ линейна по $y$. Тогда для
прогноза в точке $x_0$, где $y_0 = f(x_0) + \varepsilon_0$ с $\varepsilon_0$
независим от $\varepsilon$ и $\E \varepsilon_0^2 = \sigma^2$,
$$\E \bigl[ (y_0 - \widehat f(x_0))^2 \bigr]
= \sigma^2 + \operatorname{Bias}^2\bigl(\widehat f(x_0)\bigr) +
\Var\bigl(\widehat f(x_0)\bigr) ,$$
где $\operatorname{Bias}(\widehat f(x_0)) = \E \widehat f(x_0) - f(x_0)$;
слагаемое $\sigma^2$ не зависит от модели (неустранимая ошибка). Для
$\widehat f(x_0) = h(x_0)^{\T} y$
$$\Var\bigl(\widehat f(x_0)\bigr) = \norm{h(x_0)}^2 \sigma^2 .$$
\end{theorem}

\begin{corollary}[гребень: смещение растёт, дисперсия падает]
Для гребневой оценки в точке $x_0$ дисперсия равна
$$\Var\bigl(\widehat f_\alpha(x_0)\bigr) = \norm{X (X^{\T}X + \alpha
I)^{-1} x_0}^2 \sigma^2 .$$
При росте $\alpha$ она монотонно не возрастает, а квадрат смещения не
убывает; сумма — U-образная кривая [16] (Хасти, Тибширани, Фридман).
\end{corollary}

## ИНС и универсальная аппроксимация

Искусственная нейронная сеть (англ. \textit{artificial neural network}) —
модель $f(x; \theta)$ из композиций простых функций (слоёв); нейрон —
звено $z = \varphi(w^{\T}x + b)$; персептрон — нейрон со знаковой $\varphi$.

Обучение — минимизация эмпирического риска
$J(\theta) = \frac1m \sum_{i=1}^m L\bigl(f(x_i; \theta),\, y_i\bigr) \to \min_\theta$
(нелинейный аналог уравнения первого рода) [51]. Невыпуклость: гарантий
корректности нет, инициализация — малые случайные значения; градиент —
обратное распространение по вычислительному графу, цена ≈ одного прямого
прохода [51].

\begin{theorem}[универсальная теорема аппроксимации Цыбенко — Хорника]
Сеть прямого распространения с линейным выходным слоем и хотя бы одним
скрытым слоем с произвольной «сплющивающей» функцией активации может
аппроксимировать любую борелевскую функцию, отображающую одно конечномерное
пространство в другое, с любой заданной ненулевой точностью, если скрытых
блоков достаточно [51] (Гудфеллоу, Бенджио, Курвил).
\end{theorem}

Оговорки: аппроксимируемость не означает обучаемости; число блоков в
худшем случае экспоненциально [51].

## Стохастический градиент

Стохастический оракул вместо $\nabla f(x)$ выдаёт несмещённую оценку
$\widehat g$ с конечной дисперсией: $\E\, \widehat g = \nabla f(x)$,
$\E \norm{\widehat g - \nabla f(x)}^2 \le D$ [37] (Гасников). Минибатч из
$r$ независимых оценок уменьшает дисперсию в $r$ раз:
$\E \norm{\widehat g_r - \nabla f}^2 \le D/r$ [37] (Гасников).

\begin{theorem}[сходимость SGD с постоянным шагом]
Пусть $f$ дифференцируема и $\mu$-сильно выпукла с минимумом в точке
$x^*$, на каждом шаге используется несмещённая оценка $\widehat g_k$ с
$\E \norm{\widehat g_k}^2 \le B^2$ при любом $x_k$, шаг $h$ постоянен и
$h \le \frac{1}{2\mu}$. Тогда
$$\E \norm{x_k - x^*}^2 \le (1 - 2h\mu)^k\, \norm{x_0 - x^*}^2 +
\frac{h B^2}{2\mu} .$$
\end{theorem}

Плато $hB^2/(2\mu)$ — цена стохастики; точность $\varepsilon$ достигается
за $k = O\bigl( \frac{B^2}{\mu^2} \frac{\ln(1/\varepsilon)}{\varepsilon} \bigr)$
итераций [37] (Гасников). По значению функции: $O(1/\sqrt k)$ выпуклый и
$O(1/k)$ сильно выпуклый случаи, обе неулучшаемы [37], [51].

## Импульс, Нестеров, Adam

\textbf{Импульс} (англ. \textit{momentum}) — экспоненциально затухающее
скользящее среднее градиентов [51]:
$$v^{k+1} = \beta v^k - \varepsilon\, \nabla J(\theta^k),
\qquad
\theta^{k+1} = \theta^k + v^{k+1},
\qquad \beta \in [0, 1) .$$
Раскрытие $v^{k+1} = \theta^{k+1} - \theta^k$ даёт шаг тяжёлого шарика
(мост к вопросу о минимизации функций многих переменных); локально
знаменатель $q = \frac{\sqrt\varkappa - 1}{\sqrt\varkappa + 1}$ [63] (Меркулов).

\textbf{Нестеров} — градиент в экстраполированной точке
$\widetilde\theta^k = \theta^k + \beta v^k$:
$$v^{k+1} = \beta v^k - \varepsilon\, \nabla J(\theta^k + \beta v^k),
\qquad
\theta^{k+1} = \theta^k + v^{k+1} .$$
Пакетно $O(1/k) \to O(1/k^2)$; в стохастике ускорения по оценкам нет [51].

\textbf{Adam} — моменты $s_k$, $r_k$, исправление смещения,
покомпонентный шаг:
$$\begin{gathered}
s_k = \rho_1 s_{k-1} + (1 - \rho_1)\, g_k, \quad
r_k = \rho_2 r_{k-1} + (1 - \rho_2)\, g_k \odot g_k, \quad
\widehat s_k = \tfrac{s_k}{1 - \rho_1^k}, \quad
\widehat r_k = \tfrac{r_k}{1 - \rho_2^k}, \\
\theta_{k+1} = \theta_k - \varepsilon\, \widehat s_k \big/ (\sqrt{\widehat r_k} + \delta_0).
\end{gathered}$$
Умолчания $\varepsilon = 0{,}001$, $\rho_1 = 0{,}9$, $\rho_2 = 0{,}999$;
статус слабее SGD: контрпримеры расходимости (Reddi et al., 2019).

## Ранняя остановка и гребень

Ранняя остановка — самая распространённая
регуляризация в машинном обучении: остановка обучения, когда ошибка на
отложенной контрольной части перестаёт убывать [51].

\begin{theorem}[эквивалентность ранней остановки и $L_2$-регуляризации]
Пусть $J(w) = \tfrac12 (w - w^*)^{\T} H (w - w^*) + \text{const}$ —
квадратичная функция с $H = Q \Lambda Q^{\T} \succeq 0$, градиентный спуск
с шагом $\varepsilon$ (таким, что $\varepsilon \lambda_i < 1$) стартует из
$w^{(0)} = 0$. Тогда:

1) после $\tau$ итераций $Q^{\T} w^{(\tau)} = \bigl[ I - (I - \varepsilon \Lambda)^\tau \bigr]
Q^{\T} w^*$;

2) минимум регуляризованного функционала $J(w) + \frac{\alpha}{2}
\norm{w}^2$ равен $Q^{\T} \widetilde w = (\Lambda + \alpha I)^{-1} \Lambda\, Q^{\T} w^*$;

3) покомпонентные множители
совпадают тогда и только тогда, когда $(I - \varepsilon \Lambda)^\tau = \alpha (\Lambda + \alpha I)^{-1}$;
для малых собственных значений $\lambda$ при $\varepsilon\lambda \ll 1$
условие выполнено при $\alpha \approx \frac{1}{\varepsilon \tau}$, то есть
$\tau \approx \frac{1}{\varepsilon \alpha}$.
\end{theorem}

Сквозной пример: $\tau^* = 20$, $\tau^* \varepsilon \alpha_{\mathrm{disc}} = 0{,}985 \approx 1$;
$1/(\varepsilon\tau^*) = 104{,}8$ против $\alpha_{\mathrm{disc}} = 103{,}2$.
Ранняя остановка — итерационная регуляризация Тихонова (метод Ландвебера) [14].

## Регуляризация в глубоком обучении

\begin{definition}[Гудфеллоу, Бенджио, Курвил, регуляризация]
«Регуляризация — это любая модификация алгоритма обучения, предпринятая
с целью уменьшить его ошибку обобщения, не уменьшая ошибку обучения» [51]
(Гудфеллоу, Бенджио, Курвил).
\end{definition}

Снижение весов: $\widetilde J(\theta) = J(\theta) + \frac{\alpha}{2}
\norm{w}^2$, штраф только на веса, не на смещения (смещение — параметр
положения отклика, а не чувствительности к входу); шаг градиентного спуска
$w \leftarrow (1 - \varepsilon\alpha)\, w - \varepsilon\, \nabla_w J$
[51]. Бэггинг — усреднение $k$ моделей: ошибка среднего
$\E \bigl[ \bigl( \frac1k \sum_i \varepsilon_i \bigr)^{\!2} \bigr] = \frac{v}{k} + \bigl(1 - \frac1k\bigr) c$ [51].

\begin{footnotesize}

| Метод | Механизм | Что покупается |
|---|---|---|
| Снижение весов | штраф $\frac{\alpha}{2}\norm{w}^2$; шаг $(1-\varepsilon\alpha)w - \varepsilon\nabla J$ | сжатие малых сингулярных направлений; устойчивость к шуму |
| Ранняя остановка | мониторинг контрольной ошибки; $\tau \approx 1/(\varepsilon\alpha)$ | тот же эффект, что у гребня, без подбора $\alpha$ |
| Прореживание | случайное выключение блоков | адаптивный $L_2$ (линейный случай); робастность к соседству решений |
| Бэггинг | усреднение $k$ моделей | дисперсия $v/k$ при сохранении общей части $c$ |
| Аугментация, шум к входу | расширение выборки, неопределённость входа | инвариантности; штраф $\norm{w}^2$ в линейном случае |

\end{footnotesize}

## Прореживание

Прореживание (англ. \textit{dropout}): каждый скрытый блок выключается
независимо с вероятностью $1 - p$ (обычно $p = 0{,}5$); на применении
выходы масштабируются на $p$ [51].

\begin{proposition}[dropout и адаптивный $L_2$ для линейной регрессии]
Применение прореживания к линейной регрессии эквивалентно снижению весов
по норме $L_2$, где для каждого входного признака задаётся свой
коэффициент снижения (Wager et al., 2013 — [51] (Гудфеллоу, Бенджио,
Курвил)). Именно: если $\mu_j \in \{0, 1\}$ — независимые индикаторы
включения признака с $\Prob\{\mu_j = 1\} = p$, то обучение по ожидаемой
потере
$$\E_\mu \norm{y - X(w \odot \mu)}^2 = \norm{y - p\, X w}^2 + p(1-p) \sum_j \norm{X_{\cdot j}}^2 w_j^2$$
есть гребневая регрессия с признакозависимым штрафом; для глубоких моделей
такой эквивалентности нет [51] (Гудфеллоу, Бенджио, Курвил).
\end{proposition}
