# Вопрос 09. Метрические и нормированные пространства. Гильбертовы пространства. Теорема Рисса

**Блок:** Функциональный анализ и преобразования
**Материал прошлого года:** лекция Л6 курса прошлого года
**Статус:** в работе — три артефакта собраны, идёт review-fix loop

Вопрос стоит на **уровне 0** графа зависимостей (корень) и обеспечивает семь
других — по таблице зависимостей глоссария это 04 (наблюдатели), 07
(преобразования Фурье, Лапласа, Хаара), 10 (методы минимизации), 15 (линейные
непрерывные функционалы, теорема Хана — Банаха), 02 (регуляризация), 05
(вейвлеты) и 16 (главные компоненты). Поэтому определения здесь выписываются полностью
и в той форме, в которой их потом цитируют соседние вопросы: расхождение
определения «гильбертово пространство» между вопросами дороже, чем лишний абзац
здесь.

## Каркас ответа

Каркас взят у лекции курса прошлого года и повторяет её порядок: метрические
пространства → полнота и банаховы → компактность → нормированные → пространства
$L_p$ → гильбертовы → теорема Рисса. Порядок не переизобретается: он и есть тот,
который слышал экзаменатор. Внутри каждого шага добавлены полные доказательства
(лекция их сжимает) и разбор посылок.

Логическая ось, которая держит этот порядок и проговаривается в конспекте:
**каждый следующий шаг добавляет одну структуру и получает за неё одну теорему.**
Метрика даёт близость и вместе с полнотой — принцип сжимающих отображений. Норма
согласует близость с линейностью и даёт эквивалентность норм в конечномерном.
Скалярное произведение даёт углы и вместе с полнотой — теорему о проекции. Теорема
Рисса — расплата по последнему счёту: проекция на $\ker f$ даёт представителя
функционала.

## Сквозной пример

Один на весь вопрос — **сигнал со скачком и прибор, измеряющий контраст.**

Сигнал $u(t) = \operatorname{sign}(t - 1/2)$ на $[0,1]$ (единичная амплитуда,
скачок посередине) и последовательность непрерывных «пандусов» $u_n$,
приближающих его. Прибор — функционал
$f(x) = \int_0^{1/2} x\,dt - \int_{1/2}^1 x\,dt$: разность средних по половинам.

Этот один пример работает в каждом разделе:

| Раздел | Что показывает |
|---|---|
| метрики | $\{u_n\}$ фундаментальна в метрике $L_2$, не фундаментальна в равномерной |
| полнота | $C[0,1]$ полно в равномерной метрике и не полно в метрике $L_2$; пополнение — $L_2$ |
| нормы | $\|\cdot\|_1, \|\cdot\|_2, \|\cdot\|_\infty$ на $\{u_n\}$ не эквивалентны |
| скалярное произведение | тождество параллелограмма на паре индикаторов половин обращается в ноль **только** при $p=2$ |
| проекция | проекции $u$ на многочлены: матрица Грама, обусловленность, ортогонализация |
| базисы | по Лежандру нужен бесконечный ряд, по Хаару — **один** коэффициент: $u$ и есть первый вейвлет Хаара |
| теорема Рисса | представитель функционала $f$ — тот же сигнал с обратным знаком, $y=-u$, и $\|f\| = \|u\| = 1$ |
| посылка полноты | тот же $f$ на $C[0,1]$ со скалярным произведением $L_2$ ограничен, а представителя в $C[0,1]$ **не имеет** |

Последняя строка — главная: она превращает «полнота существенна» из слов в
проверяемый контрпример на том же объекте, которым введён весь сюжет.

## Численные примеры

Четыре, все на сквозном примере; предсказание формулируется **до** прогона.

1. **Три метрики на одном семействе.** Пандусы $u_n$: замерить
   $\rho_\infty$, $\rho_2$, $\rho_1$ между членами и до $u$.
   *Предсказание:* $\rho_2(u_n,u) = 1/\sqrt{3n}$, $\rho_1(u_n,u) = 1/(2n)$ —
   обе аналитические, идут в golden-пин; в равномерной метрике
   последовательность не фундаментальна.
2. **Тождество параллелограмма отбирает $p=2$.** На паре индикаторов половин
   дефект равен $2 - 4\cdot 2^{-2/p}$ — точное выражение, ноль только при $p=2$.
   *Предсказание:* при $p=1$ дефект $1$, при $p=4$ — $2-2\sqrt2$.
3. **Проекция и матрица Грама.** Проекция $u$ на многочлены степени $\le n$ в
   $L_2[0,1]$: одночлены (матрица Гильберта) против ортонормированного базиса
   Лежандра. *Предсказание:* математически результат один, численно
   одночленный путь расходится с ортогональным начиная с $n$ порядка 10;
   тождество $\|u-\varphi\|^2 = \|u\|^2 - \sum c_k^2$ выполняется в
   ортогональном базисе до машинной точности. Отдельно: по Хаару — один
   ненулевой коэффициент и нулевая невязка.
   *Уточнение по итогам петли:* невязка каждого пути меряется **прямо**,
   интегралом от фактически полученного многочлена, а величина, которую обещает
   тождество, считается отдельной третьей кривой. Первая редакция считала
   невязку одночленного пути через тождество — то есть через утверждение,
   верное лишь в точном решении системы, которое пример и опровергает.
4. **Представитель функционала.** Частичные представители
   $y_n = \sum_{k\le n} f(e_k)e_k$ для сквозного $f$: $\|y_n\|$ растёт к
   $\|f\|=1$ снизу (Бессель); изометрия Рисса измеряется двумя независимыми
   путями на подпространстве степени 25. Для неограниченного функционала
   $g(x) = \sum k c_k$ те же частичные суммы дают $\|y_n\|^2 = \sum k^2 \to
   \infty$ — «нет представителя» видно как расходимость.
   *Предсказание:* первая кривая монотонно растёт и упирается в 1, вторая растёт
   как $n^{3/2}$.

Картинки, четыре: сигнал вместе с пандусами и три расстояния по $n$; дефект
тождества параллелограмма по $p$; обусловленность матрицы Грама и три невязки
по $n$ (минимум, фактическая, обещанная тождеством); $\|y_n\|$ для
ограниченного и неограниченного функционала.

**Второе доказательство теоремы Рисса** — [22] (Канторович, Акилов), §V.3.2,
теорема 14, с. 493–494: тот же путь через ядро функционала и ортогональное
разложение. Там же §V.3.3 — построение сопряжённого оператора через теорему

приписывает Фреше, для абстрактного сепарабельного гильбертова пространства —
фон Нейману, в общем случае — Реллиху.
