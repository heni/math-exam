# Вопрос 07. Преобразования Фурье, Лапласа, Хаара

**Блок:** Функциональный анализ и преобразования
**Материал прошлого года:** лекция Л3 (рамка «интегральное преобразование с
ядром», таблица ядер; Фурье — 8 свойств; Лаплас — связь с Фурье, решение ОДУ,
интеграл Бромвича; Хаар — система, матрица, пирамида средних и деталей; далее
вейвлеты — это вопрос 05)
**Статус:** в работе

Каркас ответа — по Л3: одна рамка (интегральное преобразование с ядром) и три
звена под ней. Сквозной пример блока — один сигнал, проведённый через все
звенья: экспоненциальный импульс $u(t)=e^{-t}\mathbb 1_{[0,\infty)}(t)$ —
у него считаются аналитически все три преобразования, а его «изломанная»
версия $t\,e^{-t}$ разделяет Фурье и Хаар на частотно-временной плоскости.
Мост к вопросу 05: система Хаара — простейший ортогональный вейвлет, пирамида
«сглаживание–детализация» — зачаток кратномасштабного анализа.

## Соглашения обозначений (зафиксированы здесь, до theory.md)

- **Нормировка Фурье — единичная** $\hat f(\omega)=\frac1{\sqrt{2\pi}}
  \int_{-\infty}^{\infty} f(t)e^{-i\omega t}\,dt$ (как в Л3 и [11]; у [34]
  нормировка без множителя — цитируемые формулы пересчитываются:
  $\hat f_{\text{[34]}}=\sqrt{2\pi}\,\hat f$, отсюда Парсеваль без множителей,
  свёртка $\widehat{f*g}=\sqrt{2\pi}\,\hat f\hat g$, обращение с
  $\frac1{\sqrt{2\pi}}$).
- **Переменная Лапласа — $s$** (как в Л3; у [30] она названа $p$, перенос
  формул однозначен). Коллизия с $s$ сплайна вопроса 01: области действия не
  пересекаются.
- **Корень из единицы в ДПФ — $\varepsilon_N=e^{2\pi i/N}$** (переименован из
  $\omega_N$ у [66]: буква $\omega$ занята частотой; перенос формул однозначен).
- ДПФ — без нормирующего множителя, обращение с $1/N$, Парсеваль с $1/N$ (по
  [66]); отступление от унитарной нормировки сознательное, следом за источником.
- Частота — $\omega$; комплексная переменная Лапласа — $s=\sigma+i\omega$
  (внутри частотная частота $\omega$ тоже $\omega$ — это общепринятая запись).

### Теоремы с полными доказательствами

- [x] **Т1 (свойства Фурье-образа на $L_1$).** Линейность; сдвиг и модуляция;
      растяжение; дифференцирование оригинала и образа; мажоранта
      $|\hat f|\le\|f\|_1/\sqrt{2\pi}$; непрерывность и $\hat f(\omega)\to0$
      (лемма Римана — Лебега, доказательство собственное).
- [x] **Т2 (теорема обращения Фурье).** $f,\hat f\in L_1$: формула обращения в
      каждой точке непрерывности; доказательство через гауссовскую
      регуляризацию [34] Теорема 2.1 (пересчёт нормировки).
- [x] **Т3 (Планшерель и Парсеваль).** Изометрия $L_1\cap L_2\to L_2$,
      продолжение на $L_2$, обратное преобразование на $L_2$; равенство
      Парсеваля [34] Теорема 2.3 (пересчёт нормировки).
- [x] **Т4 (теорема о свёртке).** $f,g\in L_1$: $\widehat{f*g}=
      \sqrt{2\pi}\,\hat f\hat g$ [34] Теорема 2.2 (пересчёт).
- [x] **Т5 (формула суммирования Пуассона).** Для $f$ с быстрым убыванием
      [34] Теорема 2.4. *Расширенная часть.*
- [x] **Т6 (теорема Котельникова — Шеннона).** Восстановление полосового
      сигнала по отсчётам, доказательство через Пуассона [34] Теорема 3.1.
      *Расширенная часть.*
- [x] **Т7 (неопределённость Гейзенберга).** $\sigma_t\sigma_\omega\ge 1/2$
      (после пересчёта нормировки — проверить множитель!), равенство на
      гауссианах [34] Теорема 2.5. *Расширенная часть.*
- [x] **Т8 (Лаплас: сходимость и аналитичность).** При $\operatorname{Re}s>a_0$
      изображение сходится абсолютно и равномерно в полуплоскости; $F(s)$
      аналитична; оценка $|F(s)|\le M/(\operatorname{Re}s-a_0)$; множитель
      сходимости связан с показателем роста. Формулировки по [30] §1.1,
      доказательства собственные.
- [x] **Т9 (Лаплас: единственность).** Оригинал восстанавливается по
      изображению однозначно [30]; доказательство через формулу обращения.
- [x] **Т10 (Лаплас: свойства).** Линейность; дифференцирование оригинала
      $f'\mapsto sF(s)-f(0)$ и следствие для $f^{(n)}$ (ключ к ОДУ);
      интегрирование оригинала; запаздывание; сдвиг по $s$; подобие; теорема о
      свёртке $f*g\mapsto F(s)G(s)$; теорема о произведении. Формулировки по
      [30] §1.1, доказательства собственные.
- [x] **Т11 (Лаплас: формула обращения Меллина).** $f(t)=
      \frac1{2\pi i}\int_{\sigma_1-i\infty}^{\sigma_1+i\infty}F(s)e^{st}\,ds$
      при $\sigma_1>a_0$ и условиях на $F$; доказательство собственное, через
      Т2 (подстановка $s=\sigma_1+i\omega$).
- [x] **Т12 (Хаар: ортонормированность).** Система $\{\psi_{j,k}\}_{j,k\in
      \mathbb Z}$ ортонормирована в $L_2(\mathbb R)$ [11] §1.3.3.
- [x] **Т13 (Хаар: полнота).** Если $f\in L_2$ ортогональна всем
      $\psi_{j,k}$, то $f=0$; доказательство усреднением по диадическим
      интервалам [11] §1.3.3. Следствие: система Хаара — ортонормированный
      базис (полнота/замкнутость — из вопроса 09).
- [x] **Т14 (Хаар: Парсеваль и сходимость ряда).** Равенство Парсеваля;
      сходимость ряда Хаара в $L_2$; для непрерывной $f$ равномерная сходимость
      частичных сумм уровня (через модуль непрерывности).
- [x] **Т15 (ДПФ).** Определение без множителя; лемма об ортогональности
      экспонент; формула обращения; Парсеваль с $1/N$; образ циклической
      свёртки [66] гл. 1 (теоремы 2.1, 3.1, 5.1), доказательства переносятся.
- [x] **Т16 (БПФ).** Схема Кули — Тьюки с прореживанием по времени;
      $O(N\log_2 N)$ с точным подсчётом операций [66] гл. 2 §3.
- [x] **Т17 (БПХ).** Дискретный базис Хаара ортогонален; быстрое
      преобразование Хаара за $2(N-1)$ сложений; обратная схема [66] гл. 2
      §§4–6.

### Численные примеры (examples.py, seed фиксирован)

- [x] **Пример 1.** Образы Фурье: прямоугольный импульс и $e^{-t}\mathbb
      1_{[0,\infty)}$ — аналитический образ против численного (интегрирование
      и БПФ с дополнением нулями); равенство Парсеваля как golden-пин.
      Плюс эффект Гиббса частичных сумм ряда Фурье скачка (тот же сигнал, что
      в вопросе 09): доля энергии в хвосте, overshoot около скачка.
- [x] **Пример 2.** Лаплас: задача Коши для колебательного контура
      ($y''+y=0$, $y(0)=0$, $y'(0)=1$ — решение $\sin t$; и затухающий контур
      $y''+2\beta y'+y=0$) — решение через образы против solve_ivp; сходимость
      численного обращения Меллина (квадратуры по трапециям) к точному.
- [x] **Пример 3.** Хаар против Фурье при сжатии сигнала со скачком
      (периодизация $e^{-t}$ с непрерывностью на окружности и скачком
      производной внутри отрезка — $t e^{-t}$ гладка на $[0,1]$, излома
      у неё нет; согласовано с писателем примера): пороговое обнуление
      коэффициентов, кривые «ошибка/доля коэффициентов»; у Фурье —
      осцилляции у скачка (Гиббс), у Хаара — их нет. Пины: БПХ тратит
      ровно $2(N-1)=8190$ сложений; при $\rho=1/64$ Хаар точнее Фурье
      в 8.3 раза ($5.5\cdot10^{-3}$ против $4.6\cdot10^{-2}$).
- [x] **Пример 4.** Теорема отсчётов: восстановление полосового сигнала по
      отсчётам (sinc-интерполяция); aliasing при недостаточной частоте —
      спектральный сдвиг как golden-пин.

## Заметки для петли

- Нормировка Фурье: единичная. Формулы [34] пересчитываются (частотная →
  единичная). Проверить Т7 (Гейзенберг): у [34] $\sigma_t\sigma_\omega\ge1/4$
  при безмножительной нормировке; после пересчёта в единичную множитель
  остаётся $1/2$ — проверить выводом.
- У [66] скалярное произведение линейно по первому аргументу и ДПФ без
  множителя; у [11] — по второму (привычная математическая конвенция). В
  конспекте — линейность по первому аргументу (как у [66]); скалярные
  произведения в Т12–Т14 только в форме $\langle f,\psi_{j,k}\rangle$ —
  однозначно.
- Л3 содержит сомнительные места, в конспект не брать: «коэффициенты Хаара
  затухают как $O(1/j)$», условие фрейма без квадрата, «теорема Дабеши» как
  имя, принцип неопределённости без неравенства. Наш текст опирается на
  [34]/[11]/[66].
- Слайд 5 Л3 про БПХ: пирамида $d_{j,k}=(s_{j-1,2k}-s_{j-1,2k+1})/\sqrt2$
  совпадает по смыслу с [66] (5.4) при нормировке $\sqrt2$; зафиксировать
  одну нормировку в конспекте (единичная, с $1/\sqrt2$) и связать с [66].
- Число операций БПХ у [66]: $2(N-1)$ сложений (без умножений) — пин в
  examples.
