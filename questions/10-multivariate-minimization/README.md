# Вопрос 10. Методы минимизации функций многих переменных

**Блок:** Оптимизация (примыкает к управлению и ML)
**Материал прошлого года:** лекция Л5 курса прошлого года (пособие Гасникова

метод проекции градиента, Франк—Вулф; статья Кабанихина—Криворотько про
градиент функционала через сопряжённую задачу)

## План содержания

Конспект двухчастный, по образцу вопроса 12. **Основная часть** — ядро
вопроса, **расширенная** — методы второго порядка, условная и негладкая
оптимизация и приложение к обратным задачам (акценты лекции Л5).

### Часть I. Основная

- [ ] постановка `min f(x)`, мотивация (функционал качества управления,
  эмпирический риск, невязка обратной задачи); сквозной пример —
  плохо обусловленная квадратичная задача;
- [ ] определения: L-гладкость (липшицевость градиента), выпуклость,
  μ-сильная выпуклость и эквивалентные формы; условия оптимальности
  1-го и 2-го порядка [12];
- [ ] лемма о мажорировании параболой и лемма спуска [37];
- [ ] градиентный спуск с постоянным шагом: теорема о сходимости в трёх
  режимах — невыпуклый (‖∇f‖→0), выпуклый (O(1/N)), сильно выпуклый
  (линейная, exp(−N/ϰ)) [37] с полным доказательством;
- [ ] точная линейная оценка для сильно выпуклых гладких и оптимальный
  шаг: q = (ϰ−1)/(ϰ+1) при γ = 2/(L+μ); неулучшаемость [13];
- [ ] нижние оценки для методов первого порядка [37], упр. 1.3;
- [ ] чебышёвское ускорение: устойчивая трёхчленная рекуррентность [02]
  §10.1.5; теорема — рекуррентность реализует чебышёвский полином ошибки
  (доказательство индукцией, своё: у [02] «можно показать»); оценка
  ‖y⁽ᵏ⁾−x*‖ ≤ q_k‖e⁰‖ и число итераций ~½√ϰ ln(2/ε) [09];
  **мост к вопросу 11** (многочлены Чебышёва I рода) — аппарат не
  переустанавливается;
- [ ] метод сопряжённых градиентов: построение [12] гл. 5 §3; конечность
  за ≤ n шагов на квадратичной; оценка через наименее уклоняющиеся
  многочлены [13]; тот же закон √ϰ без знания спектра [02] §10.2;
- [ ] вычислительная сторона: таблица «метод | принцип | скорость | цена
  итерации | что должен знать пользователь»;
- [ ] разобранные задачи (оптимальный шаг на квадратичной; число итераций
  при заданной точности);
- [ ] вопросы, которые стоит ожидать.

### Часть II. Расширенная

- [ ] метод тяжёлого шарика [13]: локальная сходимость, оптимальные
  параметры, q = (√ϰ−1)/(√ϰ+1); схема доказательства через удвоение
  размерности — детализирована до полного;
- [ ] ускоренный метод Нестерова [37]: постановка, оценки O(LR²/N²) и
  ((√ϰ−1)/(√ϰ+1))^{2N}; доказательство (линейный каплинг [37] §1 /
  подобные треугольники, упр. 3.7);
- [ ] метод Ньютона: локальная квадратичная сходимость [13] §5 гл. 1;
  теорема Ньютона—Канторовича с полным доказательством [22] гл. XVIII §1
  (условие h ≤ 1/2, априорные оценки, единственность); существенность
  посылок — контрпримеры [13];
- [ ] условная оптимизация (акцент лекции Л5): проекция на выпуклое
  замкнутое множество (критерий Бурбаки—Чини—Гольдстейна, неэкспансивность,
  доказательства — по слайдам лекции); метод проекции градиента
  (оценка O(LR²/N)); метод Франка—Вулфа (O(LR²/N); вариант
  O(LR²/N²) для сильно выпуклых — с оговоркой о неулучшаемости);
- [ ] негладкая оптимизация: субдифференциал и условие 0 ∈ ∂f(x*) [12]
  гл. 3 §4; субградиентный метод и оценка O(L₀R/√N) [37] §2;
- [ ] градиент функционала через сопряжённую задачу [14]: постановка
  обратной задачи, формула градиента невязки, вывод; **мост к вопросу 02**
  (ML и обратные задачи);
- [ ] что почитать ещё (обзорным абзацем): стохастический градиентный
  спуск и его нижние оценки [37], зеркальный спуск, универсальный
  градиентный спуск [37] §5;
- [ ] источники (раздел конспекта).

**Примеры (5):** (1) градиентный и наискорейший спуск на плохо
обусловленной квадратичной — фактический знаменатель прогрессии против
q = (ϰ−1)/(ϰ+1) и зигзаг; (2) чебышёвская трёхчленная рекуррентность против
стационарного шага и множительной формы — стресс-тест устойчивости;
(3) тяжёлый шарик и Нестеров против градиентного спуска — измеренные
знаменатели прогрессии; (4) сопряжённые градиенты: конечность за n шагов
и сравнение с чебышёвским методом; (5) условная оптимизация: проекция
градиента и Франк—Вулф на симплексе.

## Заметки для петли

- Обозначения: L — константа Липшица градиента, μ — сильная выпуклость
  в форме f(y) ≥ f(x) + ⟨∇f(x), y−x⟩ + (μ/2)‖y−x‖², ϰ = L/μ (как ϰ
  вопроса 11), γ_k — шаг, α и β — параметры тяжёлого шарика,
  proj_Q — проекция. У источников: у Сухарева ϑ = μ/2 (его опр. 3.2),
  у Поляка l = μ и L в §5 Ньютона — это Липшиц гессиана (у нас в этой
  теореме M), у Гасникова шаг h и число обусловленности χ. Перенос
  однозначен, но каждую формулу сверять с записью здесь;
- Формулировки теорем в `slides.md` — дословно из `theory.md`
  (машинная сверка, не глазами);
- Числа в тексте — только из `examples.py` (golden-пины) или из
  источников с главой выше;
- Локаторы в «Источниках» конспекта — bare [N], без страниц
