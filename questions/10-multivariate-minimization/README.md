### Часть II. Расширенная

- [x] метод тяжёлого шарика [13] (Поляк): локальная сходимость, оптимальные
  параметры, знаменатель q = (√ϰ−1)/(√ϰ+1); схема доказательства через
  удвоение размерности — детализирована до полного (корни квадратного
  трёхчлена, оптимизация по β — по [13], печ. с. 68–70);
- [x] ускоренный метод Нестерова [37] (Гасников): схема с последовательностью
  t_k (замыкание t_{k+2}² − t_{k+2} = t_{k+1}²), оценка 2LR²/(N+1)² для
  выпуклых; для сильно выпуклых — рестарты каждые m = ⌈4√ϰ⌉ итераций
  с оценкой 2LR²(1/2)^{2⌊N/m⌋}; доказательство — схема подобных
  треугольников (оценочные последовательности; у [37] — упр. 3.7,
  с. 39–41, 111–112); у [37] оценка с явной константой для сильно
  выпуклого случая «до числовых множителей», постоянный момент
  (√ϰ−1)/(√ϰ+1) — практическая форма (1.39);
- [x] метод Ньютона: локальная квадратичная сходимость [13] (Поляк) §5 гл. 1;
  теорема Ньютона—Канторовича с полным доказательством [22] (Канторович, Акилов) гл. XVIII §1
  (условие h ≤ 1/2, априорные оценки, единственность в открытом шаре
  радиуса r₁ — включая случай h = 1/2); существенность
  посылок — контрпримеры [13] (Поляк);
- [x] условная оптимизация (акцент лекции Л5): проекция на выпуклое
  замкнутое множество (критерий Бурбаки—Чини—Гольдстейна, неэкспансивность,
  доказательства — по слайдам лекции); метод проекции градиента
  (оценка O(LR²/N) через лемму о градиентном отображении); метод
  Франка—Вулфа (O(LR²/N); вариант
  O(LR²/N²) для сильно выпуклых — с оговоркой о неулучшаемости);
- [x] негладкая оптимизация: субдифференциал и условие 0 ∈ ∂f(x*) [12] (Сухарев, Тимохов, Федоров)
  гл. 3 §4; субградиентный метод с выводом оценки O(L₀R/√N) [37] (Гасников) §2;
- [x] градиент функционала через сопряжённую задачу [14] (Кабанихин): постановка
  обратной задачи, формула градиента невязки, вывод; **мост к вопросу 02**

- [x] что почитать ещё (обзорным абзацем): стохастический градиентный

**Примеры (5):** (1) градиентный и наискорейший спуск на плохо
обусловленной квадратичной — фактический знаменатель прогрессии против

стационарного шага и множительной формы — стресс-тест устойчивости
(относительная ошибка 8,9·10⁻⁶ против границы q₆₀ ≈ 1,2·10⁻⁵;
множительная расходится до ~10⁸–10⁹); (3) тяжёлый шарик и Нестеров
(постоянный момент) против градиентного спуска — измеренные знаменатели
q ≈ 0,94 и √q ≈ 0,97 против q* ≈ 1 − 2·10⁻³; рестартная теория
2^{−2/m}, m = ⌈4√ϰ⌉ = 127 (≈ 0,989 на итерацию) — консервативная
гарантия против практической формы; (4) сопряжённые градиенты: конечность
за n шагов и сравнение с чебышёвским методом; (5) условная
оптимизация: проекция градиента и Франк—Вулф на симплексе (наклон
≈ −1,07: Θ(1/k), а не O(1/k²)).

## Заметки для петли

- Обозначения: L — константа Липшица градиента, μ — сильная выпуклость
  в форме f(y) ≥ f(x) + ⟨∇f(x), y−x⟩ + (μ/2)‖y−x‖², ϰ = L/μ (как ϰ
  вопроса 11), γ_k — шаг, α и β — параметры тяжёлого шарика,
  proj_Q — проекция. Знаменатели: q* = (ϰ−1)/(ϰ+1) — градиентный
  спуск с оптимальным шагом, q = (√ϰ−1)/(√ϰ+1) — ускоренные методы
  (чебышёвские полуитерации, CG, тяжёлый шарик, рестарты Нестерова)
  и нижние оценки; ν = (μ_max+μ_min)/(μ_max−μ_min) — чебышёвский
  параметр сдвига (у [02] обозначен μ — переименован, коллизия с
  константой сильной выпуклости). У источников: у Сухарева ϑ = μ/2
  (его опр. 3.2),
  у Поляка l = μ и L в §5 Ньютона — это Липшиц гессиана (у нас в этой
  теореме M), у Гасникова шаг h и число обусловленности χ. Перенос
  однозначен, но каждую формулу сверять с записью здесь;
