# Постановка и мотивация

Регрессия отвечает на главный вопрос математического моделирования: по
наблюдениям зависимой величины $y$ от факторов $x$ восстановить функциональную
связь и использовать её для прогноза. Когда о связи известно только то, что
она приблизительно линейна, модель записывается как
$$y_i = a_i^{\T}\theta + \varepsilon_i,\qquad i = 1,\dots,m,$$
где $a_i\in\R^n$ — известный вектор факторов $i$-го наблюдения (первая
компонента равна $1$, если в модели есть свободный член), $\theta\in\R^n$ —
неизвестный вектор параметров, $\varepsilon_i$ — ошибка модели и измерения.
Вопрос развивает два сюжета: оценка наименьших квадратов для непрерывного
отклика и логистическая регрессия (англ. *logistic regression*) для бинарного.

Метод наименьших квадратов (МНК, англ. *least squares*) — проекция вектора
наблюдений на линейную
оболочку столбцов матрицы плана: это ортогональная проекция в смысле
[вопроса 09](../09-hilbert-riesz/) (теория Рисса). При шумных данных постановка
становится плохо обусловленной и требует регуляризации — её теория дана в
[вопросе 02](../02-ml-inverse-problems/) (регуляризация Тихонова = гребневая
регрессия); здесь та же конструкция получается с оценочной стороны. Логистическая
регрессия переводит линейную модель на бинарный отклик через вероятность и
обучается уже не явной формулой, а методами минимизации из
[вопроса 10](../10-multivariate-minimization/) (минимизация функций многих
переменных).

\begin{notation}
$m$ — число наблюдений, $n$ — число параметров ($m \ge n$), матрица плана
$A\in\R^{m\times n}$ имеет строки $a_i^{\T}$. Сингулярные числа $A$:
$d_1\ge\dots\ge d_n\ge0$ (обозначение как в
[вопросе 02](../02-ml-inverse-problems/), где буква $\sigma$ занята дисперсией
шума). Дисперсия шума — $\sigma^2$. Сигмоида: $s(z) = 1/(1+e^{-z})$.
Оценки обозначаются $\hat\theta$, невязка МНК $r = y - A\hat\theta$.
\end{notation}

# Линейная модель и оценка наименьших квадратов {#sec:ls}

\begin{definition}[линейная регрессионная модель]\label{def:model}
Наблюдения $y_i$ порождаются моделью
$$y_i = a_i^{\T}\theta + \varepsilon_i,\qquad i=1,\dots,m,$$
где $\theta\in\R^n$ неизвестно, ошибки $\varepsilon_i$ — случайные величины.
Матричная запись: $y = A\theta + \varepsilon$.
\end{definition}

\begin{definition}[оценка МНК]\label{def:ls}
Оценкой наименьших квадратов называется любой вектор
$$\hat\theta \in \argmin_{\theta\in\R^n} Q(\theta),\qquad
Q(\theta) = \|A\theta - y\|_2^2 = \sum_{i=1}^m (a_i^{\T}\theta - y_i)^2.$$
Величина $Q(\hat\theta)$ — остаточная сумма квадратов (RSS).
\end{definition}

Условия минимума называются нормальными уравнениями (англ. *normal
equations*).

\begin{theorem}[нормальные уравнения]\label{thm:normal}
Вектор $\hat\theta$ минимизирует $Q$ тогда и только тогда, когда
$$A^{\T}(A\hat\theta - y) = 0.$$
Если $\rank A = n$, то решение единственно и имеет вид
$$\hat\theta = (A^{\T}A)^{-1}A^{\T}y.$$
\end{theorem}

\begin{proof}
Для любых $\theta, z\in\R^n$ и $t\in\R$ по разности квадратов
\begin{equation}\label{eq:identity}
\|A(\theta + tz) - y\|_2^2 = \|A\theta - y\|_2^2 + 2t\,z^{\T}A^{\T}(A\theta - y) + t^2\|Az\|_2^2.
\end{equation}

\emph{Необходимость.} Пусть $\hat\theta$ — минимум, но $w := A^{\T}(A\hat\theta - y) \ne 0$.
Возьмём в \eqref{eq:identity} $\theta = \hat\theta$, $z = -w$ и малый $t > 0$: линейный член
$-2t\|w\|_2^2$ отрицателен, квадратичный $t^2\|Aw\|_2^2 = o(t)$, значит при малых
$t$ правая часть меньше $Q(\hat\theta)$ — противоречие.

\emph{Достаточность.} Если $A^{\T}(A\hat\theta - y) = 0$, то в \eqref{eq:identity} линейный член
обнуляется при любом $z$, и $\|A(\hat\theta+z)-y\|_2^2 = Q(\hat\theta) + \|Az\|_2^2 \ge Q(\hat\theta)$.

\emph{Единственность при полном ранге.} Матрица $A^{\T}A$ симметрична и положительно
определена: для $z \ne 0$ имеем $z^{\T}A^{\T}Az = \|Az\|_2^2 > 0$, так как
$\rank A = n$ означает $\ker A = \{0\}$. Значит $A^{\T}A$ обратима, и нормальные
уравнения дают единственное решение $(A^{\T}A)^{-1}A^{\T}y$.
\end{proof}

\begin{remark}[геометрия]\label{rem:geom}
Условие $A^{\T}(A\hat\theta - y) = 0$ означает ортогональность невязки
$r = y - A\hat\theta$ всем столбцам $A$, то есть всему $\range(A)$. Прогноз
$\hat y = A\hat\theta$ — ортогональная проекция $y$ на подпространство
$\range(A)$: задача МНК есть задача о наилучшем приближении в гильбертовом
пространстве $\R^m$ (вопрос 09, метрические и нормированные пространства,
Рисс). При $\rank A = n$ проектор записывается как
$$P_A = A(A^{\T}A)^{-1}A^{\T},\qquad \hat y = P_Ay,\qquad r = (I - P_A)y,$$
причём $P_A^{\T} = P_A$, $P_A^2 = P_A$, $\tr P_A = n$ (след равен рангу
проектора: в ортонормированном базисе $\range(A)$ дополненного до полного,
$P_A = \diag(I_n, 0)$).
\end{remark}

\begin{theorem}[существование и минимальная норма при неполном ранге]\label{thm:minnorm}
Множество решений задачи МНК непусто, выпукло и замкнуто. Среди решений есть
единственное решение минимальной евклидовой нормы; если $d_r > 0 = d_{r+1}$ и
$A = U\Sigma V^{\T}$ — сингулярное разложение, то
$$\hat\theta = \sum_{j=1}^{r} \frac{u_j^{\T}y}{d_j}\,v_j,$$
где $u_j, v_j$ — столбцы $U, V$.
\end{theorem}

\begin{proof}
Сведём задачу к координатам сингулярного разложения $A = U\Sigma V^{\T}$:
с подстановкой $\zeta = V^{\T}\theta$ (столбцы $V$ ортонормированы) имеем
$$Q(\theta) = \|\Sigma\zeta - U^{\T}y\|_2^2 = \sum_{j=1}^{r}\bigl(d_j\zeta_j - u_j^{\T}y\bigr)^2 + \sum_{j=r+1}^{m}(u_j^{\T}y)^2,\qquad \|\theta\|_2^2 = \|\zeta\|_2^2.$$

Непустота: первые $r$ слагаемых обращаются в нуль при $\zeta_j = u_j^{\T}y/d_j$ (и только так), последние от $\theta$ не зависят — значит любой $\theta = V\zeta$ с такими первыми $r$ координатами решает задачу. Замкнутость: $Q$ непрерывна, и множество решений есть полный прообраз точки $\min Q$.

Выпуклость: если $Q(\theta_1) = Q(\theta_2) = \min Q$, то для
$\theta = (\theta_1 + \theta_2)/2$ параллелограммное тождество
$$Q(\theta) = \tfrac12 Q(\theta_1) + \tfrac12 Q(\theta_2) - \tfrac14\|A(\theta_1-\theta_2)\|_2^2 \le \min Q,$$
значит $\|A(\theta_1 - \theta_2)\|_2 = 0$; тогда по \eqref{eq:identity} линейный член
обнуляется ($A(\theta_1-\theta_2) \perp$ невязке) и $Q$ постоянна на отрезке
$[\theta_1, \theta_2]$, то есть любая его точка — решение.

Минимум нормы: ядро $\ker A$ натянуто на $v_{r+1},\dots,v_n$, поэтому сужение
$Q$ на $(\ker A)^{\perp}$ в тех же координатах $\zeta$ есть сумма квадратов с
$d_j \ge d_r > 0$ плюс константа — непрерывная коэрцитивная строго выпуклая
функция, и на $(\ker A)^{\perp}$ минимум достигается в единственной точке
$\theta_*$. Любое решение отличается от $\theta_*$ на вектор $z \in \ker A$,
ортогональный к $\theta_*$, так что $\|\theta_* + z\|_2^2 = \|\theta_*\|_2^2 +
\|z\|_2^2 \ge \|\theta_*\|_2^2$ с равенством лишь при $z = 0$: решение
минимальной нормы существует и единственно. Его координаты
$\zeta_j = u_j^{\T}y/d_j$ при $j \le r$ и $\zeta_j = 0$ при $j > r$, то есть
$\theta_* = \sum_{j=1}^{r} \frac{u_j^{\T}y}{d_j}\,v_j$.
\end{proof}

\begin{definition}[псевдообратная матрица]\label{def:pseudo}
Псевдообратной Мура — Пенроуза (англ. \emph{Moore—Penrose pseudoinverse}) матрицы
$A = U\Sigma V^{\T}$ называется
$A^+ = V\Sigma^+U^{\T}$, где $\Sigma^+$ получается из $\Sigma$ транспонированием
и заменой положительных сингулярных чисел обратными. Решение минимальной нормы
задачи МНК есть $A^+y$; при полном ранге столбцов $A^+ = (A^{\T}A)^{-1}A^{\T}$.
\end{definition}

# Статистические свойства оценки МНК {#sec:stats}

Далее фиксируем стандартные посылки.

\begin{notation}[посылки (G)]\label{not:assum}
(G1) $y = A\theta + \varepsilon$ при детерминированной матрице $A$ полного
ранга ($\rank A = n < m$); (G2) $\E\varepsilon = 0$; (G3)
$\Var\varepsilon = \sigma^2 I_m$ (ошибки некоррелированы и одинаково дисперсны).
Нормальность ошибок пока не предполагается.
\end{notation}

\begin{theorem}[несмещённость и ковариация]\label{thm:unbiased}
При посылках (G) $\E\hat\theta = \theta$ и
$\Var\hat\theta = \sigma^2 (A^{\T}A)^{-1}$.
\end{theorem}

\begin{proof}
Оценка линейна по $y$: $\hat\theta = (A^{\T}A)^{-1}A^{\T}y = \theta +
(A^{\T}A)^{-1}A^{\T}\varepsilon$, откуда $\E\hat\theta = \theta$. Для
ковариации линейного преобразования $\Var(M\varepsilon) = M(\Var\varepsilon)M^{\T}$
при $M = (A^{\T}A)^{-1}A^{\T}$ получаем
$\Var\hat\theta = \sigma^2 (A^{\T}A)^{-1}A^{\T}A(A^{\T}A)^{-1} = \sigma^2 (A^{\T}A)^{-1}$.
\end{proof}

\begin{lemma}\label{lem:trace}
Пусть $P\in\R^{m\times m}$ симметрична и идемпотентна, $\rank P = k$, а
$\E\varepsilon = 0$ и $\Var\varepsilon = \sigma^2 I_m$. Тогда
$\E\|P\varepsilon\|_2^2 = \sigma^2 k$.
\end{lemma}

\begin{proof}
Симметричная идемпотентная матрица есть ортопроектор: в её спектральном
разложении $P = W\diag(I_k, 0)W^{\T}$ с ортогональной $W$. Тогда
$$\E\|P\varepsilon\|_2^2 = \E\bigl[\tr(P\varepsilon\varepsilon^{\T}P)\bigr] = \tr\bigl(P\,\E[\varepsilon\varepsilon^{\T}]P\bigr) = \sigma^2\tr P^2 = \sigma^2\tr P = \sigma^2 k,$$
где использованы линейность следа, $\E[\varepsilon\varepsilon^{\T}] = \sigma^2 I_m$
и $\tr P = k$ (след равен сумме собственных значений, у $P$ их ровно $k$
единичных).
\end{proof}

\begin{theorem}[несмещённая оценка дисперсии]\label{thm:sigma}
При посылках (G) оценка
$$\hat\sigma^2 = \frac{\|y - A\hat\theta\|_2^2}{m - n}$$
несмещена: $\E\hat\sigma^2 = \sigma^2$.
\end{theorem}

\begin{proof}
По теореме \ref{thm:unbiased} $A\hat\theta - A\theta = A(A^{\T}A)^{-1}A^{\T}\varepsilon = P_A\varepsilon$, поэтому $y - A\hat\theta = (I - P_A)\varepsilon$. Матрица $I - P_A$ — ортопроектор на $\range(A)^{\perp}$ ранга $m-n$ (см. замечание \ref{rem:geom}), остаётся применить лемму \ref{lem:trace}.
\end{proof}

Теорема Гаусса — Маркова (англ. *Gauss—Markov theorem*) утверждает, что среди
линейных несмещённых оценок оценка МНК оптимальна.

\begin{theorem}[Гаусс — Марков]\label{thm:gm}
При посылках (G) оценка $\hat\theta$ наименьших квадратов — наилучшая линейная
несмещённая оценка (англ. \emph{best linear unbiased estimator}, BLUE): для любой линейной
оценки $\tilde\theta = Cy$
$(C\in\R^{n\times m})$, несмещённой для всех $\theta$ при верной модели
($CA = I_n$), выполнено
$$\Var\hat\theta \preceq \Var\tilde\theta$$
(разность ковариаций положительно полуопределена), и равенство достигается
только при $C = (A^{\T}A)^{-1}A^{\T}$.
\end{theorem}

\begin{proof}
Разложим $C = (A^{\T}A)^{-1}A^{\T} + D$. Несмещённость $\tilde\theta$ для всех
$\theta$ равносильна $CA = I_n$; так как $(A^{\T}A)^{-1}A^{\T}A = I_n$, получаем
$DA = 0$. Ковариация $\tilde\theta = \theta + C\varepsilon$ равна
$\sigma^2 CC^{\T}$; вычисляем по разложению с учётом $DA = 0$:
$$CC^{\T} = \bigl((A^{\T}A)^{-1}A^{\T} + D\bigr)\bigl(A(A^{\T}A)^{-1} + D^{\T}\bigr) = (A^{\T}A)^{-1} + (A^{\T}A)^{-1}A^{\T}D^{\T} + DA(A^{\T}A)^{-1} + DD^{\T}.$$
Первый смешанный член: $\bigl(DA(A^{\T}A)^{-1}\bigr)^{\T} = 0$ и сам равен нулю.
Итого $\Var\tilde\theta = \Var\hat\theta + \sigma^2 DD^{\T} \succeq \Var\hat\theta$;
равенство в смысле Лёвнера возможно лишь при $D = 0$.
\end{proof}

\begin{remark}[что существенно в посылках]\label{rem:gm-fail}
Нормальность ошибок для BLUE не нужна — только нулевое среднее, равные
дисперсии и некоррелированность. Без несмещённости оптимальность исчезает:
оценка $\tilde\theta = c\hat\theta$ с $c < 1$ имеет ковариацию
$c^2\Var\hat\theta \prec \Var\hat\theta$, но смещена. Без равенства дисперсий
(гетероскедастичности) или при коррелированности ошибок $\hat\theta$
перестаёт быть BLUE, и оценку улучшают взвешенным МНК (веса обратно
дисперсиям). Регуляризованные оценки (раздел \ref{sec:ridge}) намеренно жертвуют
несмещённостью ради меньшей дисперсии — обмен, который выгоден на дне кривой
«смещение — дисперсия» (вопрос 02, машинное обучение и обратные задачи,
регуляризация).
\end{remark}

Теперь добавим нормальность ошибок и получим связь МНК с максимальным
правдоподобием.

\begin{theorem}[МНК как максимальное правдоподобие]\label{thm:mle}
Пусть $\varepsilon \sim \mathcal N(0, \sigma^2 I_m)$. Тогда:

1. оценка максимального правдоподобия параметра $\theta$ совпадает с оценкой
   МНК;
2. $\hat\theta \sim \mathcal N\bigl(\theta, \sigma^2(A^{\T}A)^{-1}\bigr)$;
3. $(m-n)\hat\sigma^2/\sigma^2 \sim \chi^2_{m-n}$ и оценки $\hat\theta$ и
   $\hat\sigma^2$ независимы;
4. оценка максимального правдоподобия дисперсии смещена:
   $\hat\sigma^2_{\mathrm{ML}} = \frac{\|y-A\hat\theta\|_2^2}{m}$,
   $\E\hat\sigma^2_{\mathrm{ML}} = \frac{m-n}{m}\sigma^2$.
\end{theorem}

\begin{proof}
Логарифм правдоподобия
$$\ln L(\theta, \sigma^2) = -\frac{m}{2}\ln(2\pi\sigma^2) - \frac{\|y - A\theta\|_2^2}{2\sigma^2}.$$
При любом $\sigma^2 > 0$ максимум по $\theta$ достигается при минимуме
$\|y - A\theta\|_2^2$, что и даёт п. 1. П. 2 следует из линейности $\hat\theta$
по нормально распределённому $y$ и теоремы \ref{thm:unbiased}.

П. 3: $y - A\hat\theta = (I - P_A)\varepsilon$ (теорема \ref{thm:sigma}). По
спектральному разложению $I - P_A = G\diag(0_n, I_{m-n})G^{\T}$; вектор
$\eta = G^{\T}\varepsilon/\sigma$ имеет распределение $\mathcal N(0, I_m)$, и
$$\frac{(m-n)\hat\sigma^2}{\sigma^2} = \frac{\|G^{\T}(I-P_A)\varepsilon\|_2^2}{\sigma^2} = \sum_{j=n+1}^{m}\eta_j^2 \sim \chi^2_{m-n}.$$
Для независимости заметим, что векторы $G^{\T}P_A\varepsilon$ (от которых
линейно зависит $\hat\theta$) и $G^{\T}(I-P_A)\varepsilon$ (от которого
зависит $\hat\sigma^2$) совместно гауссовы, и их ковариация равна
$\sigma^2 G^{\T}P_A(I-P_A)G = 0$; некоррелированные гауссовы векторы
независимы.

П. 4: сравнение формул для $\hat\sigma^2_{\mathrm{ML}}$ и $\hat\sigma^2$
вместе с теоремой \ref{thm:sigma} даёт
$\E\hat\sigma^2_{\mathrm{ML}} = \frac{m-n}{m}\sigma^2$.
\end{proof}

\begin{remark}[вывод для практики]\label{rem:tstat}
Из пп. 2–3 следует, что при нормальных ошибках статистика
$$(\hat\theta_j - \theta_j)\big/\bigl(\hat\sigma\sqrt{v_j}\bigr),$$
где $v_j$ — $j$-й диагональный элемент $(A^{\T}A)^{-1}$, имеет распределение
Стьюдента с $m-n$ степенями свободы — она служит для доверительных интервалов
и проверки значимости отдельных коэффициентов (см.
[вопрос 14](../14-interval-estimation-tests/) (интервальное оценивание и
проверка гипотез)).
\end{remark}

# Численная сторона МНК {#sec:numeric}

Решение $\hat\theta = (A^{\T}A)^{-1}A^{\T}y$ само по себе не алгоритм: оно
требует формирования $A^{\T}A$, и это источник потери точности. Пусть
$d_1 \ge \dots \ge d_n > 0$ — сингулярные числа $A$; **число обусловленности**
$$\kappa_2(A) = d_1/d_n.$$

\begin{theorem}[погрешность метода нормальных уравнений]\label{thm:normal-bad}
Если $\hat\theta_{NE}$ — решение, вычисленное по нормальным уравнениям в
машинной арифметике с точностью $u$ при точном формировании $A^{\T}A$ и
$A^{\T}y$, то
$$\frac{\|\hat\theta_{NE} - \hat\theta\|_2}{\|\hat\theta\|_2} \approx u\,\kappa_2(A)^2.$$
\end{theorem}

\begin{proof}[схема]
Разложение Холецкого $A^{\T}A = GG^{\T}$ в машинной арифметике решает не
исходную, а близкую систему $(A^{\T}A + E)\hat\theta_{NE} = A^{\T}y$ с
$\|E\|_2 \approx u\|A^{\T}A\|_2$ (свойство устойчивости разложения Холецкого
для положительно определённых матриц). По теореме о погрешности решения
системы ошибка делится на $\|A^{\T}A\|_2$ и умножается на
$\|(A^{\T}A)^{-1}\|_2 = 1/d_n^2$, а $\|A^{\T}A\|_2 = d_1^2$ — отсюда
$u\,d_1^2/d_n^2 = u\,\kappa_2(A)^2$.
\end{proof}

Прямой вывод $\hat\theta$ через $A^{\T}A$ квадратично чувствителен к
обусловленности. Устойчивые схемы работают с самой матрицей $A$.

\begin{theorem}[решение МНК через QR-разложение]\label{thm:qr}
Пусть $\rank A = n$ и $A = QR$ — тонкое QR-разложение ($Q\in\R^{m\times n}$
имеет ортонормированные столбцы, $R\in\R^{n\times n}$ верхняя треугольная).
Тогда $\hat\theta$ есть единственное решение системы
$$R\hat\theta = Q^{\T}y,\qquad \min_\theta Q(\theta) = \|(I - QQ^{\T})y\|_2^2.$$
Вычисленное таким образом $\hat\theta_{QR}$ есть точное решение задачи МНК для
близких данных $A + \delta A$, $y + \delta y$ с
$$\|\delta A\|_2 \lesssim mu\|A\|_2,\qquad \|\delta y\|_2 \lesssim mu\|y\|_2$$
(обратная устойчивость), поэтому его относительная ошибка есть $O\bigl(u(\kappa_2(A) + \tan\varphi\,\kappa_2(A)^2)\bigr)$ при ненулевой невязке.
\end{theorem}

\begin{proof}
Ортогональные преобразования сохраняют 2-норму. Дополним $Q$ до квадратной
ортогональной $\bar Q = [\,Q\ \bar Q_\perp\,]$; тогда
$$\|A\theta - y\|_2^2 = \bigl\|\bar Q^{\T}(A\theta - y)\bigr\|_2^2 = \|R\theta - Q^{\T}y\|_2^2 + \|\bar Q_\perp^{\T}y\|_2^2,$$
поскольку $\bar Q^{\T}A = \binom{R}{0}$. Второе слагаемое от $\theta$ не
зависит, первое обращается в нуль при $R\hat\theta = Q^{\T}y$; $R$ невырождена
(её сингулярные числа совпадают с $d_j > 0$), значит решение единственно.
Минимальное значение равно $\|\bar Q_\perp^{\T}y\|_2^2 = \|(I-QQ^{\T})y\|_2^2$.

Утверждение обратной устойчивости — результат Лоусона и Хэнсона о методе
Хаусхолдера: вычисленное $\hat R$ есть точный треугольный множитель матрицы,
близкой к $A$ с относительной погрешностью порядка $mu$, а обратная
подстановка устойчива. Оценка ошибки следует далее из теоремы
\ref{thm:perturb}.
\end{proof}

\begin{theorem}[чувствительность задачи МНК к данным]\label{thm:perturb}
Пусть $\|A\theta - y\|_2 = \min$ с невязкой $r$ и $\|(A + \delta A)\hat\theta -
(y + \delta y)\|_2 = \min$; $A, \delta A\in\R^{m\times n}$, $m \ge n$,
$\rank A = n$, $y \ne 0$,
$$\varepsilon = \max\Bigl\{\frac{\|\delta A\|_2}{\|A\|_2}, \frac{\|\delta y\|_2}{\|y\|_2}\Bigr\} < \frac{d_n}{d_1},\qquad
\sin\varphi = \frac{\|r\|_2}{\|y\|_2} \ne 1.$$
Тогда
\begin{equation}\label{eq:perturb-x}
\frac{\|\hat\theta - \theta\|_2}{\|\theta\|_2} \le \varepsilon\Bigl\{\frac{2\kappa_2(A)}{\cos\varphi} + \tan\varphi\,\kappa_2(A)^2\Bigr\} + O(\varepsilon^2),
\end{equation}
\begin{equation}\label{eq:perturb-r}
\frac{\|\hat r - r\|_2}{\|y\|_2} \le \varepsilon\bigl(1 + 2\kappa_2(A)\bigr)\min(1, m - n) + O(\varepsilon^2).
\end{equation}
\end{theorem}

\begin{proof}
Пишем $\delta A = \varepsilon E$, $\delta y = \varepsilon f$ с
$\|E\|_2 \le \|A\|_2$, $\|f\|_2 \le \|y\|_2$ и рассматриваем семейство
$A(t) = A + tE$, $y(t) = y + tf$, $t \in [0, \varepsilon]$. Так как
$t\|E\|_2 < d_n$ при $t \le \varepsilon$, все $A(t)$ имеют ранг $n$ и их
решения $x(t)$ нормальных уравнений дифференцируемы; тейлоровское разложение
в точке $t = 0$ даёт $\hat\theta = \theta + \varepsilon\dot x(0) +
O(\varepsilon^2)$ (точка применения — $t = \varepsilon$).

Дифференцируем тождество $A(t)^{\T}A(t)x(t) = A(t)^{\T}y(t)$ в нуле:
$$A^{\T}A\,\dot x(0) = A^{\T}(f - E\theta) + E^{\T}(y - A\theta),$$
откуда
\begin{equation}\label{eq:dotx}
\dot x(0) = (A^{\T}A)^{-1}A^{\T}(f - E\theta) + (A^{\T}A)^{-1}E^{\T}r.
\end{equation}
Оценим нормы множителей сингулярным разложением $A = U\Sigma V^{\T}$:
$$\|(A^{\T}A)^{-1}A^{\T}\|_2 = \frac{1}{d_n},\qquad \|(A^{\T}A)^{-1}\|_2 = \frac{1}{d_n^2},\qquad \|A(A^{\T}A)^{-1}\|_2 = \frac{1}{d_n}.$$
Первое слагаемое в \eqref{eq:dotx}:
$$\frac{\|(A^{\T}A)^{-1}A^{\T}(f-E\theta)\|_2}{\|\theta\|_2} \le \frac{\|f\|_2 + \|E\|_2\|\theta\|_2}{d_n\|\theta\|_2} \le \kappa_2(A)\Bigl(\frac{\|y\|_2}{\|A\|_2\|\theta\|_2} + 1\Bigr).$$
Второе:
$$\frac{\|(A^{\T}A)^{-1}E^{\T}r\|_2}{\|\theta\|_2} \le \frac{\|E\|_2\|r\|_2}{d_n^2\|\theta\|_2} \le \tan\varphi\,\kappa_2(A)^2,$$
так как ортогональность $A\theta \perp r$ (замечание \ref{rem:geom}) даёт
теорему Пифагора $\|A\theta\|_2^2 + \|r\|_2^2 = \|y\|_2^2$, то есть
$\|A\|_2\|\theta\|_2 \ge \|A\theta\|_2 = \|y\|_2\cos\varphi$ и
$\|r\|_2/\|A\|_2\|\theta\|_2 \le \tan\varphi$. Подстановка в \eqref{eq:dotx} даёт \eqref{eq:perturb-x}.

Для невязки: $r(t) = y(t) - A(t)x(t)$, дифференцирование даёт
$$\dot r(0) = (I - P_A)(f - E\theta) - A(A^{\T}A)^{-1}E^{\T}r,$$
где $P_A = A(A^{\T}A)^{-1}A^{\T}$ — ортопроектор. Используем
$\|I - P_A\|_2 = \min(1, m-n)$ (при $m = n$ проектор равен $I$, иначе его
норма равна $1$), $\|f\|_2 \le \|y\|_2$, $\|E\theta\|_2 \le \|A\|_2\|\theta\|_2
\le \kappa_2(A)\|y\|_2$ (так как $\|\theta\|_2 = \|A^+y\|_2 \le
\|y\|_2/d_n$) и $\|A(A^{\T}A)^{-1}E^{\T}r\|_2 \le \|E\|_2\|r\|_2/d_n \le
\kappa_2(A)\|r\|_2 \le \kappa_2(A)\min(1,m-n)\|y\|_2$, что и даёт \eqref{eq:perturb-r}.
\end{proof}

\begin{remark}[как читать оценки]\label{rem:perturb}
При нулевой невязке ($\varphi = 0$ в угле) чувствительность решения линейна
по $\kappa_2(A)$ — как у квадратной системы. Член $\tan\varphi\,\kappa_2^2$
включается при ненулевой невязке и делает задачу по-настоящему плохо
обусловленной при большом $\kappa_2$: квадратичная зависимость достигается на
примерах. Невязка, напротив, чувствительна к данным линейно. Отсюда
практическое правило:
решение считают по QR-разложению (Хаусхолдер или модифицированный
Грамм—Шмидт) или SVD, а нормальные уравнения с разложением Холецкого
применяют лишь при хорошей обусловленности и малом $n$ — они вдвое дешевле.
Полный ранг приближённо определяется по сингулярным числам: порог
$d_j \le \delta$ при допуске $\delta$ порядка $u\|A\|$ (или точности данных).
\end{remark}

Стоимость методов для $m \ge n$ (ведущие члены числа флопов [02]):

| Метод | Флопы | Устойчивость |
|---|---|---|
| Нормальные уравнения + Холецкий | $mn^2 + n^3/3$ | $u\kappa_2^2$ |
| QR Хаусхолдера | $2mn^2 - \tfrac23 n^3$ | обратно устойчив |
| QR (модиф. Грамм—Шмидт) | $2mn^2$ | обратно устойчив |
| SVD (Чана) | $2mn^2 + 11n^3$ | контроль ранга |

SVD нужен и в другой ситуации — при неполном ранге: он выдаёт решение
минимальной нормы $A^+y$ (теорема \ref{thm:minnorm}) и позволяет отсечь малые
сингулярные числа, от которых решение неустойчиво (мост к регуляризации).

# Регуляризация: гребень и лассо {#sec:ridge}

При плохой обусловленности $A^{\T}A$ (мультиколлинеарность факторов, $d_n \approx 0$)
дисперсия $\hat\theta$ велика — оценка неустойчива (подробный разбор и связь
с некорректными задачами — вопрос 02, машинное обучение и обратные задачи,
регуляризация). Гребневая регрессия (англ. *ridge
regression*) добавляет штраф за норму вектора параметров.

\begin{definition}[гребневая регрессия]\label{def:ridge}
Оценка гребневой регрессии с параметром $\alpha \ge 0$:
$$\hat\theta_{\alpha} = \arg\min_{\theta}\; Q(\alpha, \theta),\qquad Q(\alpha, \theta) = \|A\theta - y\|_2^2 + \alpha\|\theta\|_2^2.$$
\end{definition}

Параметр $\alpha$ у источников именуется $\lambda$ ([16]) или $\tau$ ([53]).

\begin{theorem}[существование, единственность и фильтр]\label{thm:ridge}
При $\alpha > 0$ задача гребня имеет единственное решение
$$\hat\theta_{\alpha} = (A^{\T}A + \alpha I)^{-1}A^{\T}y,$$
линейное по $y$; при $\alpha = 0$ это оценка наименьших квадратов
(единственная при полном ранге $A$, иначе — решение минимальной нормы).
Если $A = U\Sigma V^{\T}$ — сингулярное
разложение, то
$$\hat\theta_{\alpha} = \sum_{j=1}^{n}\frac{d_j}{d_j^2 + \alpha}\,(u_j^{\T}y)\,v_j,\qquad
A\hat\theta_{\alpha} = \sum_{j=1}^{n}\frac{d_j^2}{d_j^2 + \alpha}\,(u_j^{\T}y)\,u_j.$$
Коэффициенты $\dfrac{d_j^2}{d_j^2+\alpha} \le 1$ — фильтр: направления с малыми
сингулярными числами сжимаются сильнее. След шляпной матрицы гребня —
эффективное число степеней свободы:
$$\mathrm{df}(\alpha) = \tr\bigl[A(A^{\T}A+\alpha I)^{-1}A^{\T}\bigr] = \sum_{j=1}^{n}\frac{d_j^2}{d_j^2+\alpha},$$
непрерывно убывающее от $r = \rank A$ при $\alpha = 0$ до $0$ при
$\alpha \to \infty$.
\end{theorem}

\begin{proof}
По тождеству \eqref{eq:identity} с добавкой $\alpha\|\theta\|^2$:
$$Q(\alpha, \theta + tz) = Q(\alpha,\theta) + 2t\,z^{\T}\bigl(A^{\T}(A\theta - y) + \alpha\theta\bigr) + t^2\bigl(\|Az\|_2^2 + \alpha\|z\|_2^2\bigr).$$
При $\alpha > 0$ квадратичная форма строго положительно определена
($\|Az\|_2^2 + \alpha\|z\|_2^2 > 0$ при $z\ne0$), значит $Q$ строго выпукла,
а необходимое условие нулевого градиента $A^{\T}A\theta + \alpha\theta =
A^{\T}y$ даёт единственное решение. Фильтр получается подстановкой SVD:
$A^{\T}A + \alpha I = V(\Sigma^2 + \alpha I)V^{\T}$, обращение которой
переводится в веса $d_j/(d_j^2+\alpha)$. Для df: след диагональной в базисе
$U$ матрицы $U\,\diag\bigl(d_j^2/(d_j^2+\alpha)\bigr)\,U^{\T}$ равен сумме её
диагональных элементов.
\end{proof}

\begin{remark}[свойства гребня]\label{rem:ridge}
(1) Оценка смещена: $\E\hat\theta_{\alpha} = (A^{\T}A + \alpha
I)^{-1}A^{\T}A\,\theta \ne \theta$, зато дисперсия меньше, чем у МНК:
оценка линейна по $y$, поэтому
$$\Var\hat\theta_{\alpha} = \sigma^2 (A^{\T}A+\alpha I)^{-1}A^{\T}A(A^{\T}A+\alpha I)^{-1}
= \sigma^2\sum_{j=1}^n \frac{d_j^2}{(d_j^2+\alpha)^2}\,v_jv_j^{\T}
\preceq \sigma^2\sum_{j=1}^n \frac{1}{d_j^2}\,v_jv_j^{\T} = \Var\hat\theta,$$
так как у матриц общий собственный базис $v_j$ и
$d_j^2/(d_j^2+\alpha)^2 \le 1/d_j^2$; сжатие нормы самой оценки разобрано в
задаче \ref{prob:ridge}. Существует
$\alpha$, минимизирующее среднеквадратичный риск — обмен «смещение —
дисперсия» подробно разобран в вопросе 02 (машинное обучение и обратные
задачи, регуляризация). (2) В отличие от МНК, гребень
корректно определён при любом ранге и при $n > m$ (штраф делает матрицу
системы положительно определённой). (3) Байесовский смысл: $\hat\theta_{\alpha}$
— MAP-оценка при гауссовском априоре $\theta \sim \mathcal N(0, \nu^2 I)$ с
$\alpha = \sigma^2/\nu^2$ (вывод — вопрос 02, машинное обучение и обратные
задачи, регуляризация). (4) Параметр $\alpha$ выбирают
перекрёстной проверкой по правилу одной стандартной ошибки (вопрос 02,
машинное обучение и обратные задачи, регуляризация).
\end{remark}

Лассо заменяет квадратичный штраф на штраф $L_1$:
$$\min_{\theta}\ \|A\theta - y\|_2^2 \quad\text{при условии}\quad \|\theta\|_1 \le t,$$
что обнуляет часть коэффициентов и отбирает факторы (лапласовский априор;
сравнение гребня и лассо — вопрос 02, машинное обучение и обратные задачи,
регуляризация). Для гребня есть явная формула, для
лассо её нет — решают численно (проксимальный градиент, координатный спуск).

# Обучение регрессий первыми методами {#sec:gd}

Когда $m$ велико или $n$ велико, разложений тяжело, и обе задачи
(МНК и гребень) решают градиентными итерациями — теми же методами, что и
прочие задачи минимизации (вопрос 10, минимизация функций многих переменных;
подробная теория скоростей — [63]).

**Градиенты.** Для функционала МНК $\nabla Q(\theta) = 2A^{\T}(A\theta - y)$,
а его гессиан $2A^{\T}A$ имеет собственные значения на $[2d_n^2, 2d_1^2]$,
поэтому константа Липшица градиента $L = 2d_1^2$; для гребня
$L = 2(d_1^2 + \alpha)$. Шаг градиентного
спуска $\eta \le 1/L$ гарантирует убывание функционала (лемма спуска, [63]):
$Q(\theta_{k+1}) \le Q(\theta_k) - \eta(1 - L\eta/2)\|\nabla Q(\theta_k)\|_2^2$.
На квадратичной задаче $\mu = 2d_n^2$, $\kappa = L/\mu = \kappa_2(A)^2$, и
получаем линейную сходимость с коэффициентом $(\kappa - 1)/(\kappa + 1)$ —
в квадрате хуже, чем у самой матрицы $A$,
отсюда и выгода QR/SVD при плохой обусловленности; для гребня спектр сдвинут,
$\kappa = (d_1^2 + \alpha)/(d_n^2 + \alpha)$.

**Стохастический спуск** (англ. \emph{stochastic gradient descent}, SGD — [63],
[51]). На шаге берут случайное подмножество $B$
(минибатч) и оценку градиента $g(\theta) = \frac{2}{|B|}\sum_{i\in B}
(a_i^{\T}\theta - y_i)a_i$; она несмещённа для градиента среднего
функционала $\frac1m Q$: $\E_B g(\theta) = \frac{1}{m}\nabla Q(\theta)
= \frac{2}{m}A^{\T}(A\theta - y)$.
При убывании шага по правилу Роббинса — Монро $\sum_k\eta_k = \infty$,
$\sum_k\eta_k^2 < \infty$ итерации сходятся (формулировка — [63], [64];
стохастический градиентный спуск подробно разобран в вопросе 02, машинное
обучение и обратные задачи, регуляризация); увеличение
батча в $b$ раз снижает дисперсию оценки в $b$ раз.

**Моментум** (англ. \emph{momentum} — [63]). Усреднение градиентов $v_{k+1} = \beta v_k + \nabla Q(\theta_k)$,
$\theta_{k+1} = \theta_k - \eta v_{k+1}$ (метод тяжёлого шарика) для
квадратичной задачи ускоряет сходимость до коэффициента
$(\sqrt\kappa - 1)/(\sqrt\kappa + 1)$ вместо $(\kappa - 1)/(\kappa + 1)$
(вывод — вопрос 10, минимизация функций многих переменных; [63]) —
практический рецепт при большом $\kappa$.
Разница режимов видна на сквозном примере вопроса: матрица плана с
$\kappa_2(A) \approx 42$ даёт градиентному спуску на log-loss с шагом $1/L$
около $2{,}3\cdot10^4$ итераций, а IRLS в логистической части сходится за
$5$ итераций (числа — в `examples.ipynb`, примеры 2–3).

# Логистическая регрессия {#sec:logistic}

Теперь отклик бинарный: $y_i \in \{0, 1\}$ — принадлежность объекта $a_i$ к
классу $1$. Линейная модель на прямую $a_i^{\T}\theta$ выходить не может —
значения не из $\{0,1\}$; логистическая регрессия пропускает её через
сигмоиду (англ. *sigmoid*), превращая в вероятность.

\begin{definition}[логистическая модель]\label{def:logistic}
$$\Prob(y_i = 1 \mid a_i) = p_i(\theta) = s(a_i^{\T}\theta),\qquad s(z) = \frac{1}{1 + e^{-z}}.$$
Отсюда $\Prob(y_i = 0 \mid a_i) = 1 - p_i = s(-a_i^{\T}\theta)$ и правило
классификации $\hat y_i = \mathbb 1\{a_i^{\T}\theta > 0\}$: разделяющая
граница — гиперплоскость $a^{\T}\theta = 0$.
\end{definition}

\begin{lemma}[свойства сигмоиды]\label{lem:sigmoid}
$s'(z) = s(z)(1 - s(z))$; $s(-z) = 1 - s(z)$; $\ln s(z) = z - \ln(1 + e^z)$;
$\ln(1 - s(z)) = -\ln(1 + e^z)$.
\end{lemma}

\begin{proof}
Непосредственное дифференцирование и алгебра: $s(z) = e^z/(1+e^z)$, откуда
$\ln s(z) = z - \ln(1+e^z)$; остальное — проверка подстановкой.
\end{proof}

\begin{definition}[log-loss / бинарная перекрёстная энтропия]\label{def:logloss}
Функция правдоподобия выборки (наблюдения независимы):
$$L(\theta) = \prod_{i=1}^m p_i^{y_i}(1 - p_i)^{1-y_i}.$$
Логарифмическая функция потерь (англ. \emph{log-loss}, или бинарная
перекрёстная энтропия, англ. \emph{cross-entropy}) — отрицательное логарифмическое
правдоподобие:
$$Q(\theta) = -\ln L(\theta) = \sum_{i=1}^m\bigl[\ln\bigl(1 + e^{a_i^{\T}\theta}\bigr) - y_i\,a_i^{\T}\theta\bigr].$$
Оценка максимального правдоподобия есть $\arg\min_\theta Q(\theta)$.
\end{definition}

Явной формулы для минимизатора $Q$ нет (система оценочных уравнений
нелинейна): логистическая регрессия обучается итеративно — в этом коренное
отличие от линейной.

\begin{theorem}[гладкость, выпуклость, градиент и гессиан]\label{thm:log-convex}
$Q$ выпукла и бесконечно дифференцируема; с обозначениями $p = (p_i)$,
$W = \diag\bigl(p_i(1-p_i)\bigr)$:
$$\nabla Q(\theta) = A^{\T}(p - y),\qquad \nabla^2 Q(\theta) = A^{\T}WA \succeq 0.$$
Если $\rank A = n$ и все $0 < p_i < 1$, то $Q$ строго выпукла, и её минимум
(если существует) единствен. Минимум существует, если выполнено условие
перекрытия: для любого $z\in\R^n$ с $Az \ne 0$ найдётся $i$ такой, что
$a_i^{\T}z > 0$, $y_i = 0$, либо $a_i^{\T}z < 0$, $y_i = 1$.
\end{theorem}

Существование минимума связано с разделимостью классов: условие перекрытия
выполнено, если классы неразделимы даже в слабом смысле — иначе нашлось бы
$z$ с $Az \ne 0$, слабо разделяющее классы ($y_i = 1 \Rightarrow a_i^{\T}z \ge
0$, $y_i = 0 \Rightarrow a_i^{\T}z \le 0$), что прямо противоречит условию
перекрытия; при разделимости инфимум не достигается (замечание
\ref{rem:separation}).

\begin{proof}
Слагаемое $y_i a_i^{\T}\theta$ линейно, вторые производные даёт только
$\varphi_i(\theta) = \ln(1 + e^{a_i^{\T}\theta})$. По лемме
\ref{lem:sigmoid} $\nabla\varphi_i = s(a_i^{\T}\theta)\,a_i = p_i a_i$ и
$$\nabla^2\varphi_i = s'(a_i^{\T}\theta)\,a_ia_i^{\T} = p_i(1-p_i)\,a_ia_i^{\T}.$$
Суммирование по $i$ даёт формулы градиента и гессиана. Для любого $z\in\R^n$
$$z^{\T}A^{\T}WA\,z = \sum_{i=1}^m p_i(1-p_i)\,(a_i^{\T}z)^2 \ge 0,$$
так как $0 < p_i < 1$; значит $A^{\T}WA \succeq 0$ и $Q$ выпукла. Если
$\rank A = n$ и $z \ne 0$, то $Az \ne 0$, существует $i$ с $a_i^{\T}z \ne 0$,
и $z^{\T}\nabla^2 Q\,z > 0$ — строгая выпуклость.

Существование минимума. Вдоль луча $\theta = \theta_0 + tz$ пользуемся
$\ln(1+e^u) \ge \max(u, 0)$. Если $a_i^{\T}z > 0$ и $y_i = 0$, слагаемое
растёт как $t\,a_i^{\T}z \to +\infty$; если $a_i^{\T}z < 0$ и $y_i = 1$,
слагаемое растёт как $-t\,a_i^{\T}z$ (точнее,
$\ln(1+e^{a_i^{\T}\theta}) - a_i^{\T}\theta = \ln(1+e^{-a_i^{\T}\theta})
\to +\infty$). Значит, по условию перекрытия для любого $z$
с $Az \ne 0$ найдётся $i$ в одной из этих ситуаций, $Q \to +\infty$ вдоль
любого луча с $Az \ne 0$, и сужение $Q$ на $(\ker A)^{\perp}$ — непрерывная
коэрцитивная функция — достигает минимума; сдвиг на $\ker A$ значение $Q$ не
меняет ($a_i^{\T}(\theta + z) = a_i^{\T}\theta$ при $z \in \ker A$), поэтому
множество минимизаторов — непустое аффинное подпространство, параллельное
$\ker A$. При $\rank A = n$ оно состоит из одной точки по строгой выпуклости.
При разделимости классов инфимум не достигается (замечание
\ref{rem:separation}).
\end{proof}

\begin{remark}[оценочные уравнения]\label{rem:score}
Условие $\nabla Q = 0$ есть система $A^{\T}(y - p) = 0$ из $n$ нелинейных
уравнений; если среди столбцов $A$ есть константа, первое из них даёт
$\sum_i y_i = \sum_i p_i(\hat\theta)$: сумма предсказанных вероятностей равна
числу единиц. Это свойство используют для контроля сходимости.
\end{remark}

\begin{theorem}[метод Ньютона и IRLS]\label{thm:irls}
Пусть $\rank A = n$. Шаг Ньютона для $Q$ с текущей точки $\theta$:
$$\theta^{+} = \theta + (A^{\T}WA)^{-1}A^{\T}(y - p).$$
Он совпадает с решением взвешенной задачи наименьших квадратов с весами
$W$ и рабочим откликом $z = A\theta + W^{-1}(y - p)$:
$$\theta^{+} = \arg\min_{\varphi}\ (z - A\varphi)^{\T}W(z - A\varphi).$$
Итерации (приведение весов $W$ и отклика $z$ к текущей точке и решение
взвешенной МНК-задачи) называются повторно взвешенными наименьшими квадратами
(англ. \emph{iteratively reweighted least squares}, IRLS); вес максимален у объектов
у границы ($p_i \approx 1/2$).
\end{theorem}

\begin{proof}
Нормальные уравнения взвешенной задачи: $A^{\T}WA\,\varphi = A^{\T}Wz$.
Подставляем $Wz = WA\theta + (y - p)$:
$$A^{\T}WA\,\varphi = A^{\T}WA\,\theta + A^{\T}(y - p),$$
откуда $\varphi = \theta + (A^{\T}WA)^{-1}A^{\T}(y - p)$ — это и есть шаг
Ньютона (гессиан $\nabla^2Q = A^{\T}WA$ обратим при полном ранге $A$, так как
$W \succ 0$).
\end{proof}

\begin{remark}[сходимость и промахи]\label{rem:irls-conv}
Для строго выпуклой гладкой функции метод Ньютона локально квадратично
сходится к минимуму (теория — вопрос 10, минимизация функций многих
переменных); глобально на практике применяют
демпфирование: при возрастании $Q$ шаг делят пополам (у [16] — стандартная
рекомендация). Регуляризованный вариант $Q(\theta) + \frac{\alpha}{2}\|\theta\|_2^2$
имеет гессиан $A^{\T}WA + \alpha I \succ 0$ — сильную выпуклость при любом
ранге $A$ и сепарабельности классов (разделимость разбирается ниже), и тот же
шаг IRLS с заменой $A^{\T}WA \to A^{\T}WA + \alpha I$.
\end{remark}

\begin{remark}[разделимость классов]\label{rem:separation}
Если выборка линейно разделима (существует $\varphi$:
$y_i = 1 \Rightarrow a_i^{\T}\varphi > 0$, $y_i = 0 \Rightarrow
a_i^{\T}\varphi < 0$), то $\inf Q$ не достигается: вдоль луча
$\theta = t\varphi$ при $t \to \infty$ величина $Q$ строго убывает, значит
оценка максимального правдоподобия не существует ($\|\hat\theta\| \to
\infty$), и в точной арифметике $\nabla Q$ не обращается в нуль: вдоль луча
$\theta = t\varphi$ градиент убывает экспоненциально, поэтому любой
фиксированный порог $\varepsilon$ рано или поздно формально пройден, не
свидетельствуя о минимизаторе. Граничный случай — слабая разделимость через $z$ с $Az \ne 0$
(все объекты класса $1$ в полупространстве $a_i^{\T}z \ge 0$, класса $0$ — в
$a_i^{\T}z \le 0$, некоторые на границе): вдоль луча $\theta = tz$ величина
$Q$ так же строго убывает, уходя к конечному пределу, и минимум может не
достигаться. В машинной арифметике есть дополнительная ловушка:
вероятности $p_i$ сатурируют до точных $0$ и $1$, гессиан вырождается, и
норма градиента формально падает ниже любого порога — критерий
$\|\nabla Q\| < \varepsilon$ даёт ложную остановку при неограниченно
растущей $\|\theta_k\|$ (на сквозном примере вопроса $\|\theta_k\|$
достигает $\approx 718$ при выполненном пороге $10^{-8}$ — замер в
examples.ipynb, пример 4). Надёжные стоп-сигналы — рост $\|\theta_k\|$ и идеальная
классификация обучения. Выход — регуляризация (гребень с малым $\alpha$
делает минимум существующим и единственным) либо остановка по изменению
прогнозов. Это свойство важно помнить: идеально точная классификация на
обучении для логистической регрессии означает, что оценка ушла на
бесконечность.
\end{remark}

Мультиномиальный случай ($K$ классов) вводит $K-1$ векторов параметров через
логиты $\ln\frac{\Prob(G=k\mid a)}{\Prob(G=K\mid a)} = a^{\T}\theta_k$;
структура правдоподобия и шагов Ньютона та же, но весовая матрица на
наблюдение уже не диагональна [16]. Для отбора факторов применяют
$L_1$-штраф к $\theta$ (решение — координатным спуском).

# Метрики качества бинарной классификации {#sec:metrics}

Порог классификации $\hat y = \mathbb 1\{p_i > \pi\}$ (по умолчанию
$\pi = 1/2$) разбивает объекты по матрице ошибок (англ. *confusion
matrix*): TP и TN — верные
срабатывания, FP — ложная тревога, FN — пропуск. Из неё выводят:

| Метрика | Определение | Когда важна |
|---|---|---|
| Accuracy (доля верных, англ. *accuracy*) | $(\mathrm{TP}+\mathrm{TN})/m$ | классы сбалансированы |
| Precision (точность, англ. *precision*) | $\mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$ | цена ложной тревоги высока |
| Recall (полнота, англ. *recall*) | $\mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$ | цена пропуска высока |

Accuracy бесполезна при дисбалансе классов (достаточно отнести всех к
большему классу): например,
при $1\%$ единиц константный прогноз «все нули» даёт accuracy $99\%$.
Порог $\pi$ балансирует precision и recall и подбирается по контрольной
выборке.

**Где работает конструкция.**

| Постановка | Что минимизируется | Ответ | Что покупается |
|---|---|---|---|
| Линейная регрессия, полный ранг | $\|A\theta - y\|_2^2$ | $\hat\theta = (A^{\T}A)^{-1}A^{\T}y$ | несмещённость, BLUE (Гаусс — Марков) |
| Линейная регрессия, плохо обусловлена | $\|A\theta - y\|^2 + \alpha\|\theta\|^2$ | $(A^{\T}A+\alpha I)^{-1}A^{\T}y$ | устойчивость ценой смещения |
| Линейная регрессия, большие $m, n$ | то же, итеративно | GD/SGD, momentum | масштабируемость |
| Логистическая регрессия | log-loss (перекрёстная энтропия) | IRLS / GD / SGD | вероятность класса, разделяющая гиперплоскость |

# Разобранные задачи {#sec:problems}

\begin{problem}\label{prob:ridge}
Гребень через сингулярное разложение. Пусть $A = U\Sigma V^{\T}$. Вывести
$\hat\theta_{\alpha}$ и доказать, что $\|\hat\theta_{\alpha}\|_2 <
\|\hat\theta\|_2$ при $\alpha > 0$, если $\hat\theta \ne 0$.
\end{problem}

*Решение.* Формула — теорема \ref{thm:ridge}. Для норм в базисе $V$:
$$\|\hat\theta_{\alpha}\|_2^2 = \sum_{j=1}^n \frac{d_j^2}{(d_j^2+\alpha)^2}(u_j^{\T}y)^2,\qquad
\|\hat\theta\|_2^2 = \sum_{j=1}^n \frac{1}{d_j^2}(u_j^{\T}y)^2,$$
и $\dfrac{d_j^2}{(d_j^2+\alpha)^2} < \dfrac{1}{d_j^2}$ при $\alpha > 0$ и
$d_j > 0$; если $\hat\theta\ne0$, хотя бы одно слагаемое ненулевое и строгое
неравенство сохраняется. $\blacksquare$

\begin{problem}\label{prob:loggrad}
Градиент и гессиан log-loss непосредственно. Для одного наблюдения вычислить
$\nabla_\theta\,\bigl[\ln(1+e^{a^{\T}\theta}) - y\,a^{\T}\theta\bigr]$ и
$\nabla^2_\theta$, проверить положительную полуопределённость.
\end{problem}

*Решение.* Обозначим $u = a^{\T}\theta$. $\frac{\partial}{\partial\theta_j}
\ln(1+e^u) = \frac{e^u}{1+e^u}a_j = s(u)a_j$; линейное слагаемое даёт $-ya_j$.
Градиент: $(s(u) - y)a$. Гессиан: $\frac{\partial}{\partial\theta_k}
\bigl[s(u)a_j\bigr] = s'(u)a_ka_j = s(u)(1-s(u))a_ja_k$ — матрица
$s(u)(1-s(u))\,aa^{\T} = \lambda aa^{\T}$ с $\lambda > 0$; для любого $z$:
$z^{\T}(\lambda aa^{\T})z = \lambda(a^{\T}z)^2 \ge 0$. Сумма по наблюдениям
даёт $A^{\T}WA$ из теоремы \ref{thm:log-convex}. $\blacksquare$

\begin{problem}\label{prob:pseudo}
Неполный ранг. $A = \begin{pmatrix}1&1\\1&1\end{pmatrix}$, $y = (2, 0)^{\T}$.
Найти все решения МНК и решение минимальной нормы.
\end{problem}

*Решение.* Нормальные уравнения $A^{\T}A\theta = A^{\T}y$:
$\begin{pmatrix}2&2\\2&2\end{pmatrix}\theta = \binom{2}{2}$, то есть
$\theta_1 + \theta_2 = 1$; множество решений — прямая
$(t, 1-t)^{\T}$. Минимум нормы при $t = 1/2$: $\hat\theta = (1/2,\,1/2)^{\T}$.
Проверка через SVD: $d_1 = 2$, $u_1 = v_1 = (1,1)^{\T}/\sqrt2$;
$\hat\theta = \frac{u_1^{\T}y}{d_1}v_1 = \frac{\sqrt2}{2}\cdot
\frac{1}{\sqrt2}\binom11$. $\blacksquare$

\begin{problem}\label{prob:mle-sigma}
Эквивалентность МНК и правдоподобия. Записать правдоподобие модели
$y = A\theta + \varepsilon$, $\varepsilon\sim\mathcal N(0,\sigma^2 I)$,
показать, что максимизация по $\theta$ совпадает с МНК, и сравнить оценки
дисперсии.
\end{problem}

*Решение.* Плотность: $L = (2\pi\sigma^2)^{-m/2}\exp\bigl(-\|y-A\theta\|^2/
(2\sigma^2)\bigr)$; минимизация $-\ln L$ по $\theta$ — минимизация
$\|y-A\theta\|^2$. Оценка по $\sigma^2$:
$\hat\sigma^2_{\mathrm{ML}} = \|y-A\hat\theta\|^2/m$ с ожиданием
$\frac{m-n}{m}\sigma^2$ (теорема \ref{thm:mle}); несмещённая $\hat\sigma^2$
делит на $m-n$. $\blacksquare$
