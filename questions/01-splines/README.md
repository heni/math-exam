# Вопрос 01. Сплайн-аппроксимация, интерполяция

**Блок:** Приближение
**Материал прошлого года:** лекция Л8 (кадры 2–6: аппроксимация и критерии
близости, теорема Бореля, интерполяция Лагранжа/Ньютона, определение сплайна,
сходимость кубических сплайнов)
**Статус:** в работе (три артефакта собраны, гейты чисты; петля review-fix
запущена)

Каркас ответа взят из Л8 и совпадает с линией источников: общая задача
аппроксимации → наилучшее приближение (существование/единственность) →
полиномиальная интерполяция (Лагранж, Ньютон, остаточный член) → почему
полиномиальная интерполяция не работает (константа Лебега, Фабер, Рунге,
Бернштейн) → сплайны как ответ: определение, B-сплайны, кубическая
интерполяция, сходимость, экстремальное свойство. Сквозной пример блока
Приближение — функция с изломом $f(x)=|x|$ (тот же объект, что в вопросе 11):
там она показала слабость равномерных узлов, здесь — слабость глобальных
полиномов вообще и то, что покупают сплайны.

### Теоремы с полными доказательствами

- [x] **Т1 (существование наилучшего приближения).** Всякое конечномерное
      подпространство нормированного пространства — множество существования.
- [x] **Т2 (единственность).** В строго выпуклом пространстве наилучшее
      приближение из выпуклого замкнутого множества единственно; в
      гильбертовом пространстве — ортогональная проекция, нормальные
      уравнения.
- [x] **Т3 (интерполяция: существование и единственность).** Интерполяционный
      многочлен степени $\le n$ по $n+1$ узлам существует и единствен
      (определитель Вандермонда; формулы Лагранжа и Ньютона равны между
      собой).
- [x] **Т4 (остаточный член).** $f(x)-L_n(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}
      \omega_{n+1}(x)$; следствие — оценка через $\|\omega_{n+1}\|$ и
      оптимальные узлы (мост к вопросу 11).
- [x] **Т5 (оценка через константу Лебега).**
      $\|f-L_nf\|\le(1+\Lambda_n)E_n(f)$ — почему из гладкости ничего не
      следует при растущей константе.
- [x] **Т6 (теорема Фабера).** Для любой последовательности сеток есть
      непрерывная $f$ с расходящимся процессом интерполяции (формулировка;
      доказательство вне конспекта, ссылка [09]).
- [x] **Т7 (размерность пространства сплайнов).** $\dim Z_{m,k}(\Delta_n)=m+1+kn$
      и каноническое представление через усечённые степени.
- [x] **Т8 (свойства B-сплайнов).** Носитель $(x_j,x_{j+m+1})$, строгая
      положительность внутри, разбиение единицы, рекуррентность, симметрия;
      система B-сплайнов — базис $Z_{m,1}$.
- [x] **Т9 (существование и единственность кубического интерполяционного
      сплайна).** СЛАУ для $M_i=s''(x_i)$; строгое диагональное преобладание;
      все три типа краевых условий. Доказательство пишем сами (в источниках —
      отсылка): лемма о системе с доминированной диагональю.
- [x] **Т10 (сходимость кубического сплайна).** $f\in C^{(4)}$:
      $\|f^{(s)}-s^{(s)}\|\le M_4 h^{4-s}$, $s=0,1,2$ — с полным доказательством
      по схеме [09] (сеточная лемма).
- [x] **Т11 (равномерная сходимость для непрерывной $f$).** Квазиравномерная
      сетка ($h_i/h_j\le\rho$ при $|i-j|=1$) + стремление шага к нулю ⇒
      равномерная сходимость; точные пороги на отношение шагов
      ($p^*=(3+\sqrt5)/2$) — как факт со ссылкой [31].
- [x] **Т12 (теорема Холлидея, экстремальное свойство).** Среди всех $f\in
      C^{(2)}$, интерполирующих таблицу, естественный кубический сплайн
      единственный минимизатор $\int_a^b |f''(t)|^2\,dt$ (равенство Пифагора).
- [x] **Т13 (сглаживающий сплайн).** Минимизатор $\sum_i(y_i-f(x_i))^2+
      \alpha\int|f''|^2$ — естественный кубический сплайн; матрица
      сглаживания, $df=\tr S_\alpha$, выбор $\alpha$ по перекрёстной проверке.

### Замечания о существенности посылок

- [x] почему конечномерность в Т1 существенна (пример множества, задаваемого
      конечным числом параметров, но не замкнутого);
- [x] почему строгая выпуклость в Т2 существенна (примеры неединственности в
      $C$ и $L_1$; чебышёвское подпространство как спасение единственности);
- [x] что даёт гладкость в Т4 и почему для $|x|$ остаточный член молчит;
- [x] существенность посылок в Т9: почему краевые условия нужны именно два и
      почему условия «все в одном конце» плохи (накопление ошибок);
- [x] существенность квазиравномерности в Т11 (пример расходимости на
      неравномерных сетках — факт со ссылкой);
- [x] чем экстремальное свойство сплайнов **не является**: это не наилучшее
      равномерное приближение (вопрос 19) и не регуляризация Тихонова в общей
      постановке (вопрос 02) — хотя сглаживающий сплайн и есть тихоновская
      регуляризация для конкретного функционала.

### Численные примеры (`examples.py`)

- [x] **П1.** Сквозной пример $f(x)=|x|$ на $[-1,1]$: интерполяционные
      многочлены по равномерной сетке расходятся в точках внутри отрезка
      (пример С. Н. Бернштейна; замер в нескольких точках: расходимость в
      $x\approx0{,}3$ и в $x=1/2$, сходимость в $0$ — сверка с
      классической формулировкой «сходимость ровно в $-1, 0, 1$»,
      подтверждённой точным счётом). Рядом — функция Рунге $1/(1+25x^2)$:
      всплеск у краёв. Картинка, golden-пины.
- [x] **П2.** Кубический сплайн для той же $f(x)=|x|$ на той же равномерной
      сетке: сходимость; измеренный порядок в точке излома и вдали от него.
      Картинка, golden-пины.
- [x] **П3.** Построение сплайна: трёхдиагональная СЛАУ, прогонка против
      плотного решателя; измеренное диагональное преобладание; число
      обусловленности. Пин на согласие решений.
- [x] **П4.** Экстремальное свойство и сглаживание: $\int|s''|^2$ у
      естественного сплайна против других интерполянтов; сглаживание шумных
      данных, выбор $\alpha$ по leave-one-out CV; кривая $df_\alpha$ и ошибка.
      Картинки, golden-пины.

## Заметки для петли

- Сверка Бернштейна закрыта: [09] (с. 134) и [19] (с. 35) дают
  классическую формулировку (сходимость ровно в $-1, 0, 1$); драфт
  конспекта ошибочно усилил её до пяти точек $\pm1, \pm\tfrac12, 0$ —
  исправлено. Точный счёт и замер в примере 1 подтверждают версию
  «только $-1, 0, 1$» (в $x=\tfrac12$ погрешность неограниченна);
  пересказ с пятью точками — распространённая неточность.
- [25] нумерует степень на единицу иначе (порядок = степень + 1); при
  переносе формул из [25] пересчитывать индексы на наше соглашение
  (степень $m$, гладкость $C^{m-k}$).
- [35] §10 — «первоначальные понятия», доказательства со ссылками на
  Завьялова–Квасова–Мирошниченко (в наборе нет); размерность и
  представление (10.2) доказаны в [35] полностью.
- Оценка [35] (с. 117) дана только для параболического периодического
  сплайна; основная оценка для кубических — из [09].
- Терминология усечённой степени: $(x-t)_+^m$ у [35], $x_+^{m-1}$ у [25] —
  одно и то же с переносом степени.
