### Определения

- [x] многочлен Чебышёва I рода $T_n(x) = \cos(n\arccos x)$ — тригонометрическая
      форма; приведённый (со старшим коэффициентом 1) многочлен
      $\widetilde T_n = 2^{1-n} T_n$;
- [x] класс приведённых многочленов $\mathcal{M}_n$ — то, по чему берётся минимум
      в экстремальной задаче;
- [x] многочлен, наименее уклоняющийся от нуля на отрезке;
- [x] чебышёвские узлы: нули $T_n$ и точки экстремума $T_n$ — **два разных
      набора**, оба называются «узлами Чебышёва»;
- [x] константа Лебега сетки узлов.

### Теоремы с полными доказательствами

- [x] **Т1.** Рекуррентное соотношение $T_{n+1} = 2xT_n - T_{n-1}$; следствие:
      $T_n$ — многочлен степени $n$ со старшим коэффициентом $2^{n-1}$.
- [x] **Т2.** Нули, точки экстремума, $\|T_n\|_{C[-1,1]} = 1$, чередование знаков
      в $n+1$ точке.
- [x] **Т3.** Продолжение вне отрезка:
      $T_n(x) = \tfrac12\bigl[(x+\sqrt{x^2-1})^n + (x-\sqrt{x^2-1})^n\bigr]$ и
      экспоненциальный рост при $|x|>1$ — то, чем оплачивается ускорение
      итераций.
- [x] **Т4.** Ортогональность с весом $(1-x^2)^{-1/2}$ и нормы $\|T_n\|_{L_2,\rho}$.
- [x] **Л1 (достаточное условие).** Если приведённый многочлен достигает нормы в
      $n+1$ точке с чередованием знаков, он наименее уклоняется от нуля.
- [x] **Л2 (счёт корней).** Многочлен, у которого числа $(-1)^kR(t_k)$
      неотрицательны, а внутренние нули совпадают с нулями производной, имеет не
      менее $n$ корней с учётом кратности. Без неё не проходит единственность ни
      в Т5, ни в Т9 — в плане её сначала не было, добавлена по ходу.
- [x] **Т5 (экстремальное свойство).** $\min_{\mathcal{M}_n}\|Q\|_{C[-1,1]} =
      2^{1-n}$, минимум достигается **только** на $\widetilde T_n$
      (существование + единственность).
- [x] **Т6.** Произвольный отрезок: минимум равен $2\bigl(\tfrac{b-a}{4}\bigr)^n$.
- [x] **Т7 (остаточный член интерполяции).** $f - L_n f =
      \frac{f^{(n+1)}(\xi)}{(n+1)!}\,\omega_{n+1}$ — нужна, чтобы экстремальная
      задача получила прикладной смысл.
- [x] **Т8 (оптимальные узлы).** Узлы, минимизирующие $\|\omega_{n+1}\|$, — нули
      $T_{n+1}$, пересчитанные на $[a,b]$; минимум $2\bigl(\tfrac{b-a}{4}\bigr)^{n+1}$.
- [x] **П1 (дискретная ортогональность).** В нулях $T_n$ суммы
      $\sum_j T_p(x_j)T_q(x_j)$ равны $0$, $n$ или $n/2$; следствие — МНК-приближение
      по измерениям считается свёрткой, без решения системы. Добавлено по ходу,
      по вопросу пользователя о приближении измерений полиномами Чебышёва.
- [x] **Т8а (оценка через константу Лебега).**
      $\|f - L_n f\| \le (1+\Lambda_n)E_n(f)$ и $\Lambda_n \ge 1$ — путь, не
      требующий гладкости; добавлена по ходу, потому что без неё поведение
      $|x|$ нечем объяснить.
- [x] **Т9 (вторая нормировка).** В классе $\{P: \deg P \le n,\ P(0)=1\}$ минимум
      $\max_{[a,b]}|P|$ при $0<a<b$ равен $q_n = 2\sigma^n/(1+\sigma^{2n})$,
      $\sigma = (1-\sqrt\eta)/(1+\sqrt\eta)$, $\eta = a/b$; следствие — оценка
      чебышёвского ускорения итераций через число обусловленности. Буквы именно
      такие: $\rho$ занято весом ортогональности из Т4, $\xi$ — промежуточной
      точкой из Т7.

### Замечания о существенности посылок

- [x] почему в Л1 нужны именно $n+1$ точка и чередование знаков;
- [x] что ломается в Т7 без гладкости — и почему $f(x)=|x|$ не противоречит Т8;
- [x] почему в Т9 нужно $0 \notin [a,b]$;
- [x] чем экстремальное свойство $T_n$ **не является**: это не альтернансный
      критерий наилучшего приближения произвольной функции (вопрос 19).

### Численные примеры (`examples.py`)

- [x] **П1.** Экстремальное свойство: $\|\widetilde T_5\|$ против норм
      приведённых многочленов со случайными корнями и против численной
      минимизации по коэффициентам. Golden-пин.
- [x] **П2.** Сквозной пример $f(x)=|x|$ на $[-1,1]$: интерполяция по
      равномерным узлам расходится (пример С. Н. Бернштейна), по чебышёвским —
      сходится. Картинка.
- [x] **П3.** Откуда берётся выигрыш: $\|\omega_{n+1}\|$ для трёх наборов узлов
      против теоретического минимума $2(\tfrac{b-a}{4})^{n+1}$; константы Лебега
      двух сеток. Картинка.
- [x] **П4.** Чебышёвское ускорение: простая итерация против чебышёвского
      набора параметров на плохо обусловленной матрице; погрешность после $n$
      шагов и бюджет в 60 шагов при разной обусловленности; отдельно — цена
      порядка параметров. Две картинки. Golden-пины на измеренные величины.
- [x] **П5.** Приближение измерений: обусловленность и точность двух базисов,
      точность дискретной ортогональности, устойчивость коэффициентов к росту
      степени. Картинка. Добавлен по ходу.

## Источники

Основной — [09] (Самарский, Гулин), гл. 2 §5 «Многочлены Чебышева», с. 103–108:
постановка экстремальной задачи, лемма о чередовании знаков, экстремальное
свойство, случай произвольного отрезка, вторая нормировка. Оттуда же гл. 2 §6
(с. 109–115) — чебышёвский набор итерационных параметров, и гл. 3 §2 (с. 132–136)
— остаточный член интерполяции, оптимальный выбор узлов, пример
С. Н. Бернштейна о расходимости на равномерной сетке.

- [35] (Бердышев, Петрак), с. 48–49 — определение через $\cos(n\arccos t)$,
  рекуррентность, вес $(1-t^2)^{-1/2}$, многочлены II рода. Источник нашей
  нормировки.
- [19] (Бердышев, Субботин), с. 15 — та же ортогональная система в перечне
  классических; с. 34–35 — поведение $\|L_n\|$ для равномерной сетки ($\ge \gamma^{\,n}$)
  и для чебышёвской ($\le C\ln n$), теорема Бернштейна — Фабера.
- [43] (Зализняк), с. 238–243 — те же факты в другой нормировке имён
  («нормированный полином»), явные $T_0,\dots,T_8$, разложение по $T_n$ как
  почти наилучшее приближение. Служит сверкой.
- [02] (Голуб, Ван Лоун), §10.1.5 «Метод чебышевских полуитераций» — то же
  ускорение итераций под другим русским именем; источник проверенного
  английского названия *Chebyshev semi-iterative method* (там же ссылка на
  Golub, Varga, 1961).
- [39] (Boyd, Vandenberghe) — чебышёвское приближение как задача выпуклой
  оптимизации; в вопросе 11 не используется, нужен в вопросе о наилучшем
  равномерном приближении.

**Цикл 6** — нашёл два настоящих дефекта в самих гейтах, оба давние: пункт 2
(битые ссылки на картинки) не мог завалить сборку, потому что цикл `while read`
стоял в конвейере и присваивание `fail=1` терялось в подоболочке — гейт печатал
«[!]» и возвращал ноль; пункт 3 (свежесть артефактов) не смотрел на картинки,
хотя их строит ноутбук, а вставляют конспект и слайды. Оба починены и проверены
подстановкой дефекта. Заодно вскрылось, что `make` собирал PDF **раньше**
картинок — порядок целей исправлен. Содержательно: причина хорошей
обусловленности чебышёвского базиса была названа неверно (ограниченность
$\abs{T_p}\le1$ ничего не объясняет, потому что и $\abs{x^p}\le1$).

**Цикл 7** — показал, что и вторая попытка объяснения не работала: постоянная по
$k$ внедиагональ не может объяснять рост обусловленности в тысячу раз. Верное
объяснение — через непрерывную матрицу Грама с весом $1$, которую приближает
сетка: у $T_i$ её обусловленность растёт от $8{,}4$ до $39$, у $x^i$ это
матрица гильбертова типа. Оно посчитано и напечатано в примере 5. Там же
вскрылось, что довод «коэффициенты не меняются при росте $k$» верен **только**
в чебышёвских узлах: на равномерной сетке они плывут, и это измерено.

**Отдельно о процессе.** Третий цикл был запущен параллельно с правками, и
ревьюер читал движущийся файл: первый его проход пришлось выбросить. Это ошибка
ведения петли, а не ревью; записана в накопитель проекта.
