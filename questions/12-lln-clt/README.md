# Вопрос 12. Закон больших чисел. Центральная предельная теорема

**Блок:** Решения и статистика
**Материал прошлого года:** лекция курса прошлого года, где ЗБЧ и ЦПТ стоят
рядом с интерполяцией и проверкой гипотез
**Статус:** артефакты собраны, петля не пройдена

Вопрос стоит на уровне 1 графа зависимостей, но ребро из вопроса 08 (случайные
величины и векторы, корреляционная теория) **определительное**: от 08 нужны
только определения математического ожидания, дисперсии и независимости плюс
неравенство Чебышёва, а их конспект обязан выписать у себя всё равно. Поэтому
вопрос берётся раньше 08 и доказывает неравенство Чебышёва сам.

### Определения

- [x] сходимость **по вероятности**, **почти наверное** (с вероятностью 1),

      режима, в которых формулируются предельные теоремы;
- [x] выборочное среднее $\overline X_N$ и сумма $S_N$ — то, о чём все
      утверждения вопроса;
- [x] **состоятельность**, **сильная состоятельность** и **асимптотическая
      нормальность** оценки — статистические имена трёх сходимостей;
- [x] эмпирическая функция распределения $F^*_N$ — объект, на котором ЗБЧ
      усиливается до равномерного (теорема Гливенко — Кантелли);
- [x] условие Линдеберга и условие (отношение) Ляпунова;
- [x] вероятная ошибка метода Монте-Карло.

### Теоремы с полными доказательствами

- [x] **Т1 (неравенство Маркова — Чебышёва в общей форме).** Для
      неотрицательной неубывающей $f$ и любого $a>0$
      $\Prob\{\abs{\xi}\ge a\}\le \E f(\abs{\xi})/f(a)$; частные случаи
      $f(x)=x$ (неравенство Маркова) и $f(x)=x^2$, применённое к
      $\xi-\E\xi$ (неравенство Чебышёва).
- [x] **З1 (точность неравенства Чебышёва).** Двухточечное распределение, на
      котором неравенство обращается в равенство, — то есть константу $1/\varepsilon^2$
      улучшить нельзя без дополнительных посылок.
- [x] **Т2 (соотношения между видами сходимости).** Почти наверное $\Rightarrow$
      по вероятности $\Rightarrow$ по распределению; в среднем квадратичном
      $\Rightarrow$ по вероятности. Контрпримеры ко всем обратным импликациям.
- [x] **Т3 (слабый ЗБЧ в форме Чебышёва).** Для попарно некоррелированных
      величин с дисперсиями, ограниченными одной константой $C$,
      $\overline X_N - \E\overline X_N \to 0$ по вероятности; скорость — явная
      оценка $C/(N\varepsilon^2)$.
- [x] **С1 (теорема Бернулли).** Частота события сходится по вероятности к его
      вероятности — как следствие Т3.
- [x] **Т4 (характеристическая функция: нужные свойства).** Определение,
      $\abs{\varphi}\le1$, мультипликативность на независимых слагаемых,
      разложение до второго момента; характеристическая функция нормального
      закона.
- [x] **Л1 (гауссовское сглаживание).** Плотность нормального закона есть
      обратное преобразование Фурье от $e^{-\delta^2t^2/2}$ — выкладка,
      заменяющая ссылку на формулу обращения.
- [x] **Т5 (лемма о сходимости распределений).** Если характеристические функции
      сходятся поточечно к $e^{-t^2/2}$, а вторые моменты равны единице, то
      функции распределения сходятся к $\Phi$. Это тот аналитический шаг, который
      в учебниках отдаётся теореме Леви о непрерывности; доказывается свёрткой с
      узким нормальным законом, без теоремы Хелли и без теоремы единственности.
- [x] **Т6 (ЗБЧ Хинчина).** Для независимых одинаково распределённых величин с
      конечным математическим ожиданием $\overline X_N \to a$ по вероятности —
      **без** предположения о конечной дисперсии.
- [x] **Л2 (лемма Бореля — Кантелли, первая часть).** Если
      $\sum\Prob(A_N)<\infty$, то почти наверное происходит лишь конечное число
      событий $A_N$.
- [x] **Т7 (неравенство Колмогорова).** $\Prob\{\max_{k\le N}\abs{S_k}\ge
      \varepsilon\}\le \Var S_N/\varepsilon^2$ — усиление неравенства Чебышёва с
      максимума по одному $N$ на максимум по всей траектории.
- [x] **Т8 (усиленный ЗБЧ при конечной дисперсии).** $\overline X_N\to a$ почти
      наверное. Доказательство: неравенство Колмогорова на двоичных блоках плюс
      Л2.
- [x] **Т9 (ЦПТ для одинаково распределённых).** Главная теорема вопроса:
      нормированная сумма сходится по распределению к стандартному нормальному
      закону. Полное доказательство: Т4 $\to$ разложение $\to$ Т5.
- [x] **С2 (интегральная теорема Муавра — Лапласа).** Следствие Т9 для схемы
      Бернулли.
- [x] **Т10 (асимптотический доверительный интервал).** Основное приложение,
      разбираемое полностью: из Т9 и Т6 (для выборочной дисперсии) следует, что
      $\overline X_N \pm z_{1-\alpha/2}S_N/\sqrt N$ накрывает $a$ с вероятностью,
      стремящейся к $1-\alpha$. Заодно — оценка нужного объёма выборки и её
      сравнение с оценкой по неравенству Чебышёва.
- [x] **Т11 (ЦПТ в форме Линдеберга).** Приложение в сжатой форме
      «задача — идея — результат»; доказательство вынесено в отдельный раздел.
- [x] **С3 (условие Ляпунова).** Проверяемое достаточное условие; вывод из Т11.

### Замечания о существенности посылок

- [x] **конечность дисперсии в Т3 существенна, но не необходима:** Т6 обходится
      одним первым моментом, а неравенство Чебышёва при бесконечной дисперсии
      не даёт вообще ничего;
- [x] **конечность математического ожидания существенна:** для распределения
      Коши выборочное среднее распределено так же, как одно наблюдение, и ЗБЧ
      неверен ни в одном из режимов;
- [x] **независимость ослабляется по-разному в разных теоремах:** слабому ЗБЧ
      довольно некоррелированности, усиленному ЗБЧ Колмогорова — попарной
      независимости, а ЦПТ независимость нужна по существу;
- [x] **для зависимых последовательностей предел может быть случайным:** у
      стационарной в широком смысле последовательности среднее сходится к
      сумме математического ожидания и случайного слагаемого, и последнее
      исчезает ровно в эргодическом случае;
- [x] **конечность дисперсии в ЦПТ существенна:** при бесконечной дисперсии
      нормировка $\sqrt N$ не та, и предел не нормальный;
- [x] **ЦПТ — утверждение о центре, а не о хвостах:** сходимость функций
      распределения поточечная (и равномерная), но относительная погрешность в
      далёком хвосте не контролируется;
- [x] **скорость сходимости в ЦПТ третьим абсолютным моментом не описывается**:
      он работает мажорантой в оценке Берри — Эссеена, а фактическую скорость
      задают решётчатость слагаемого и асимметрия со знаком; правило
      «$N\ge30$ достаточно» ложно как общее утверждение.

### Численные примеры (`examples.py`)

Сквозной пример один: **выборка независимых измерений одного датчика**, у
которой меняется только закон шума — нормальный, равномерный, бернуллиевский с
редкими выбросами, Парето с бесконечной дисперсией, Коши без среднего. Все
четыре примера — про одну и ту же выборку и один и тот же вопрос «что даёт
усреднение».

- [x] **Пример 1.** ЗБЧ в действии и его отсутствие: траектории $\overline X_N$
      по пяти законам. Предсказание: три первых сходятся, Парето сходится
      медленнее и прыжками, Коши не сходится вовсе.
- [x] **Пример 2.** Сколько измерений нужно: объём выборки по неравенству
      Чебышёва против объёма по ЦПТ, и фактическая вероятность покрытия при
      каждом из двух. Предсказание: отношение объёмов около пяти, покрытие по
      Чебышёву — почти единица (оценка расточительна), по ЦПТ — около
      заявленного, кроме асимметричного случая.
- [x] **Пример 3.** Скорость сходимости в ЦПТ: $\sup_x\abs{F_N(x)-\Phi(x)}$ как
      функция $N$ для четырёх законов. Предсказание: убывает как $N^{-1/2}$, а
      множитель пропорционален третьему абсолютному моменту.
- [x] **Пример 4.** Где ЦПТ ломается: при бесконечной дисперсии нормировка
      $\sqrt N$ даёт расползающуюся гистограмму, а $N^{1/\alpha}$ —
      стабильную. Предсказание: выборочная дисперсия суммы, нормированной на
      $\sqrt N$, растёт как степень $N$ с показателем $2/\alpha-1$.

## Отступления от ориентиров, зафиксированные как выбор

**Объём конспекта — около 30 страниц при ориентире 6–12.** Ориентир стайлгайда отвечает
вопросу с одним приложением; здесь ядро само по себе велико. Распределение
измерено по собранному PDF: постановка, аппарат и обозначения — 3 страницы,
виды сходимости и неравенства — 2,5, закон больших чисел и усиленный закон — 5,
характеристические функции и предельный переход — 4, центральная предельная
теорема — 2, приложения — 7, задачи и ожидаемые вопросы — 3, вынесенные
доказательства — 2. Ядро (разделы 1–9) — 16 страниц: в нём два главных
утверждения вопроса, а не одно, плюс аппарат, без которого ни одно из них не
доказывается.

**Характеристические функции изложены здесь, хотя тема примыкает к вопросу о
случайных величинах и корреляционной теории.** Оставлены сознательно: без них
нет доказательства центральной предельной теоремы, а конспект самодостаточен.
Изложено ровно то, что используется: четыре свойства и характеристическая
функция нормального закона.

**Теорема Леви о непрерывности не воспроизводится.** Вместо неё доказан нужный
частный случай — с нормальным пределом и при равномерно ограниченных вторых
моментах, — сглаживанием узким нормальным законом. Это короче общей теоремы
примерно на три страницы (теорема Хелли о выборе, равенство Парсеваля и теорема
единственности не понадобились) и не оставляет в конспекте ни одного
недоказанного шага.

**Усиленный закон больших чисел доказан при конечной дисперсии, а не в форме
Колмогорова.** Сильнейшая форма (критерий $\E\abs{\xi_1}<\infty$, ослабление до
попарной независимости) приведена как внешний результат со ссылкой и нигде не
используется. Причина: её доказательства нет ни в одной книге набора, а
самостоятельное воспроизведение потребовало бы теоремы о трёх рядах и леммы
Кронекера — это заметно больше материала, чем даёт вопрос.

**Число слагаемых обозначено $N$, а не $n$.** Все источники вопроса пишут $n$;
буква $N$ выбрана по таблице зарезервированных букв глоссария (размер выборки).
Расхождение с источниками заявлено в глоссарии.

## Что вскрылось при работе

**Предсказание в примере 3 не сбылось, и это вошло в материалы.** Ожидалось, что
предельное значение $\sup_x\abs{F_{\zeta_N}-\Phi}\sqrt N$ пропорционально
$\rho_3/\sigma^3$ — множителю из неравенства Берри — Эссеена. Измерение даёт
$0{,}3989$, $1{,}1888$ и $0{,}1330$ при отношениях $\rho_3/\sigma^3$, равных
$1$, $4{,}15$ и $2{,}41$: порядок нарушен. Фактическую скорость задают асимметрия
со знаком и шаг решётки, и сумма двух вкладов воспроизводит все три измеренных
измеренные числа с точностью $5\cdot10^{-4}$, причём свидетельство дают две
строки из трёх: у симметричного бернуллиевского закона совпадение тождественно.
Замечание о посылках в конспекте переписано под измерение.

**Предсказание в примере 4 сбылось качественно и не сбылось количественно.**
Наклоны $+0{,}222$ и $+0{,}055$ вместо $+0{,}167$ и $0$: сходимость к
устойчивому закону при $\alpha=1{,}5$ медленная, и на $N\le10^4$ асимптотика не
установилась. Свидетельством оставлен локальный наклон на отрезке $[3000;10\,000]$
(на отрезке $[3000;10\,000]$ он равен $+0{,}192$ против предсказанного $1/6$). Разность наклонов двух нормировок,
которой сперва была предъявлена «проверка до шестого знака», оказалась
**тождеством**: обе кривые получены делением одного массива на два масштаба, и
то же число выходит на чистом шуме. Утверждение снято из всех четырёх
артефактов, в ноутбуке строка подписана как контроль арифметики.

**Решётчатый вклад в скорость ЦПТ сперва брался из внешней формулы
$h/(2\sigma\sqrt{2\pi})$, теперь меряется** как половина наибольшего атома
биномиального распределения: числа изменились в четвёртом знаке ($0{,}91473$
вместо $0{,}91524$), зато утверждение перестало зависеть от локальной предельной
теоремы, которой в наборе источников нет. Вклад асимметрии остаётся опознанием
по совпадению чисел, и это сказано прямо.
