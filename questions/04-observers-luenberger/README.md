# Вопрос 04. Наблюдатели динамических систем. Наблюдатель Люенбергера

**Блок:** Управление
**Материал прошлого года:** лекция Л2 курса прошлого года (постановка задачи

**Статус:** в работе (2026-10-21)

## План содержания

Сквозной объект — линейная стационарная система
$\dot x = Ax + Bu$, $y = Cx$, $A \in \R^{n\times n}$,
$B \in \R^{n\times k}$, $C \in \R^{m\times n}$, $\rank C = m < n$
($m$ измерений). Сквозной пример — двойной интегратор
$\dot x_1 = x_2$, $\dot x_2 = u$, $y = x_1$ ($n = 2$, $m = k = 1$):
тот же объект ведёт вопрос 06 (это же управление как задача Понтрягина)
и вопрос 20 (его дискретный аналог).

### Теория

- [x] **Постановка и мотивация**: зачем восстанавливать состояние по
  измерениям (управление по выходу, фильтрация); мост к вопросу 06;
- [x] **Задача наблюдения**: восстанавливающий линейный функционал
  $\alpha^{\T} x(t) = \int \gamma^{\T} y\, dt$ ($\alpha$ — вектор
  функционала наблюдения, $\gamma$ — вес), сведение к интегральному
  уравнению с переходной матрицей $\Phi(t, t_0) = e^{A(t-t_0)}$;
  определение наблюдаемости через разрешимость для любого $\alpha$;
  эквивалентное определение через нулевой выход [26] (опр. 1–4 §24);
  различие «по будущим / по прошлым наблюдениям» (Калман, [23] §1.7,
  печ. с. 84–85) — наблюдаемость против восстанавливаемости, для
  стационарных систем совпадение;
- [x] **Критерии наблюдаемости**: грамиан наблюдаемости
  $M(t_0, t_1) = \int_{t_0}^{t_1} \Phi^{\T} C^{\T} C \Phi\, dt$;
  теорема: наблюдаемость ⟺ невырожденность $M$, формула восстановления
  $x(t_0) = M^{-1} \int \Phi^{\T} C^{\T} y\, dt$ (полное доказательство
  по [26] §24, т. 1 и 3); ранговый критерий
  $\rank [C^{\T}, A^{\T}C^{\T}, \dots, (A^{\T})^{n-1}C^{\T}] = n$
  (полное доказательство: через грамиан и Кэли—Гамильтона, [23] т. 1.32,
  [26] т. 8 §24); дуальность с управляемостью (полное доказательство,
  [26] т. 9 §24, [23] т. 1.41);
- [x] **Лемма об устойчивости линейной системы**: все решения
  $\dot\varepsilon = F\varepsilon$ сходятся к нулю при любых начальных
  ⟺ $\operatorname{Re}\lambda_i(F) < 0$; оценка
  $\norm{\varepsilon(t)} \le M e^{-\sigma t}\norm{\varepsilon(0)}$
  (полное доказательство через жорданову форму; аппарат устойчивости —
  подложка [03], [04]);
- [x] **Наблюдатель полного порядка**: определение (сходимость для любых
  начальных условий; синонимы — идентификатор [26], state estimator /
  state reconstruction device [26] печ. с. 272); конструкция
  $\dot{\hat x} = A\hat x + Bu + V(y - C\hat x)$ с матрицей усиления $V$;
  уравнение ошибки $\dot\varepsilon = (A - VC)\varepsilon$; теорема о
  назначении спектра: наблюдаемость ⟺ произвольное размещение полюсов
  $A - VC$ (полное доказательство: скалярный случай через
  идентификационное каноническое представление [26] §25 т. 1; многомерный
  — циклификация и редукция к скалярному, леммы о циклификации и о
  циклическом векторе с доказательствами);
  замечания: компромисс скорость/шум ([26] §25 зам. 2, [23] печ. с. 382);
  фильтр Калмана — оптимальный выбор $V$ при шумах (мост к вопросу 08,
  одним абзацем);
- [x] **Наблюдатель Люенбергера пониженного порядка**: мотивация
  (размерность $n - m$ вместо $n$); построение по лекции: дополнение
  строк $C$ до базиса матрицей $W$, $(\widetilde C, D) = (C; W)^{-1}$,
  неизмеряемая часть $\zeta = Wx$, уравнение для оценки $\hat\zeta$ с
  усилением $V$ и производной $\dot y$, ошибка $e = \zeta - \hat\zeta$:
  $\dot e = (W - VC)AD\, e$; замена $\zeta_2 = \hat\zeta - Vy$,
  устраняющая $\dot y$; итог $\hat x = \widetilde C y + DVy + D\zeta_2$
  (вывод полный); теорема о назначении спектра: при наблюдаемости спектр
  $(W-VC)AD$ назначаем (полное доказательство для $m = 1$ по [26] §26
  т. 1 через ИКП; для общего $m$ — конструкция канонического базиса [26]
  §26 т. 2 со всеми определениями и подсчётом размерности $n - m$);
  общая алгебраическая форма — уравнение Сильвестра $TA - DT = S$ [26]
  §26 (печ. с. 291–295), Л2-конструкция — частное решение $T = W - VC$
  (замечанием с выкладкой $TA - FT = (W-VC)A(\widetilde C + DV)C$);
  замечание: прямая связь $y \to \hat x$ повышает чувствительность к
  шуму измерений [23] печ. с. 387;
- [x] **Принцип разделения**: управление по оценке $u = -K\hat x$;
  замкнутая система $2n$-го порядка, в переменных $(x, \varepsilon)$
  матрица блочно-диагональна, $\varphi_0 = \varphi_{\text{у}} \cdot
  \varphi_{\text{и}}$ (полное доказательство, [26] §27 т. 1, [23] т. 5.1);
  следствие — раздельное конструирование регулятора и наблюдателя;
  формулировки для пониженного наблюдателя ([26] §27 т. 2–3) и для
  стабилизируемой/обнаруживаемой пары ([23] т. 5.2);
- [x] **Вычислительная сторона**: таблица «полный / пониженный /
  фильтр Калмана»: что минимизируется, где работает, чувствительность
  к шуму;
- [x] **Разобранные задачи**: (1) полный наблюдатель двойного
  интегратора, $V$ из желаемого $\varphi_{\text{ж}} = (\lambda + 2)^2$
  (числа совпадают с примером 1 ноутбука); (2) наблюдатель Люенбергера
  для того же объекта, $\zeta_2$: $\dot\zeta_2 = -2\zeta_2 - 4y + u$,
  $\hat x_2 = \zeta_2 + 2y$; (3) существенность наблюдаемости: пара
  «невидимая неустойчивая мода» против «невидимой устойчивой моды»
  (прямой расчёт ранга и поведения ошибки, числа из ноутбука);
- [x] **Вопросы, которые стоит ожидать**;
- [x] **Источники** (раздел конспекта): bare `[N] (авторы)` без страниц.

**Примеры (4):** (1) полный наблюдатель двойного интегратора:
размещение полюсов в $(-2, -2)$ ($v_1 = v_2 = 4$ из сравнения
$\lambda^2 + v_1\lambda + v_2$ с $(\lambda+2)^2$), симуляция ошибки

независимости ошибки от управления $u$; (2) наблюдатель Люенбергера для
того же объекта ($v = 2$): сходимость оценки $\hat x_2 = \zeta_2 + 2y$

(3) принцип разделения: $u = -K\hat x$ с полюсами регулятора
$-1 \pm i$ ($k_1 = k_2 = 2$), замкнутая система $4$-го порядка,
собственные значения = полюса регулятора ∪ полюса наблюдателя
(golden-пин), траектории $x(t)$ и $\hat x(t)$; (4) существенность
наблюдаемости: невидимая мода $e^{t}$ ($A = \diag(0, 1)$, $C = (1, 0)$)
— ошибка растёт против невидимой устойчивой моды ($A = \diag(-1, -2)$) —
ошибка сходится; ранги матрицы наблюдаемости (golden-пины).

## Заметки для петли

  у [23] — $e$), $W$ — дополняющий блок к $C$, $(\widetilde C, D) =
