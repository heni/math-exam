---
title: "Вопрос 14. Интервальное оценивание. Проверка статистических гипотез"
---

**Основной результат.** Неравенство Рао — Крамера
$\Var_\theta\widehat\theta\ge(\tau'(\theta))^2/I_N(\theta)$ с критерием
эффективности; ОМП состоятельна, асимптотически эффективна и
$\sqrt N(\widehat\theta^{\text{МП}}-\theta)\xrightarrow{d}\mathcal N(0,1/i(\theta))$.
Точные доверительные интервалы нормальной модели строятся центральными
статистиками ($z$, $t$, $\chi^2$); двойственность «интервал — критерий»; для
простых гипотез равномерно наиболее мощный критерий — по лемме Неймана —
Пирсона отношение правдоподобия; для односторонних альтернатив при
монотонном отношении правдоподобия р.н.м.к. — квантильная область по
достаточной статистике.

## Определения

- **Выборка** $\xi=(\xi_1,\dots,\xi_N)$ — независимые одинаково распределённые
с распределением $P_\theta$; **статистика** $T(\xi)$ — борелевская функция;
**оценка** — статистика для приближения $\theta$.
- **Несмещённость:** $\E_\theta\widehat\theta=\theta$; **состоятельность:**
$\widehat\theta_N\xrightarrow{\Prob}\theta$; **эффективность:** минимальная
дисперсия среди несмещённых.
- **Информация Фишера:** $I_N(\theta)=\Var_\theta\bigl(\frac{\partial}{\partial\theta}\ln p_\theta(\xi)\bigr)
=-\E_\theta\bigl(\frac{\partial^2}{\partial\theta^2}\ln p_\theta(\xi)\bigr)$.
- **Доверительный интервал** уровня $\gamma$: $\Prob_\theta(T_1<\theta<T_2)\ge\gamma$
(точный — при равенстве); асимптотический — по $\liminf$.
- Распределения: **Стьюдента** $t_k=\xi/\sqrt{\eta/k}$;
**Фишера — Снедекора** $F_{k,m}=(\xi/k)/(\eta/m)$; $\chi^2_k$.
- **Гипотеза** $H_0:\theta\in\Theta_0$ простая/сложная; **критерий** —
критическая область $S$; ошибки I и II рода; **функция мощности**
$\beta(\theta,S)$, **размер** $\alpha(S)=\sup_{\Theta_0}\beta$, уровень
значимости $\alpha$; **р.н.м.к.** — максимальная мощность при всех
$\theta\in\Theta_1$ среди критериев уровня $\alpha$; **p-value** —
наименьший уровень, отклоняющий $H_0$.
- **Монотонное отношение правдоподобия** по $T$: $p_{\theta_2}/p_{\theta_1}=\psi(T)$,
$\psi$ неубывает для всех пар $\theta_1<\theta_2$.

## Теоремы

- **Т1 (Рао — Крамера).** При регулярности для несмещённой оценки $\tau(\theta)$:
$\Var_\theta\widehat\theta\ge(\tau'(\theta))^2/I_N(\theta)$; равенство
$\Leftrightarrow$ $\frac{\partial}{\partial\theta}\ln p_\theta=C(\theta)(\widehat\theta-\tau(\theta))$
(критерий эффективности).
- **Т2 (асимптотическая нормальность ОМП).** При условиях регулярности:
$\sqrt N(\widehat\theta^{\text{МП}}-\theta)\xrightarrow{d}\mathcal N(0,1/i(\theta))$
— состоятельность и асимптотическая эффективность.
- **Т3 (метод центральной статистики).** Если распределение $G(\xi,\theta)$ не
зависит от $\theta$, то $\{\theta:g_1\le G(\xi,\theta)\le g_2\}$ —
доверительная область уровня $\gamma=\Prob(g_1\le G\le g_2)$.
- **Т4 (нормальная выборка).** $\overline X_N$ и $s_N^2$ независимы;
$(N-1)s_N^2/\sigma^2\sim\chi^2_{N-1}$; $\overline X_N\sim\mathcal N(a,\sigma^2/N)$;
статистика Стьюдента $T=\frac{\overline X_N-a}{s_N}\sqrt N\sim t_{N-1}$.
- **Т5 (четыре ДИ нормальной модели, $\beta_{\pm}=(1\pm\gamma)/2$).** $a$,
$\sigma$ известно: $\overline X_N\pm z_{\beta_{+}}\sigma/\sqrt N$; $a$,
$\sigma$ неизвестно: $\overline X_N\pm t_{\beta_{+};N-1}s_N/\sqrt N$;
$\sigma^2$, $a$ известно: $\bigl(N\widehat\sigma_a^2/\chi^2_{\beta_{+};N},\,
N\widehat\sigma_a^2/\chi^2_{\beta_{-};N}\bigr)$; $\sigma^2$, $a$ неизвестно:
$\bigl((N-1)s_N^2/\chi^2_{\beta_{+};N-1},\,(N-1)s_N^2/\chi^2_{\beta_{-};N-1}\bigr)$.
Две выборки: разность средних при равных $\sigma$ — через $t_{N+M-2}$ и
$s_{\text{обш}}^2$; отношение дисперсий — через $F$.
- **Т6 (двойственность интервал — критерий).** Доверительная область уровня
$\gamma=1-\varepsilon$ $\Leftrightarrow$ семейство критериев уровня
$\varepsilon$ для точечных $H_0:\theta=\theta_0$ (отклонение $\Leftrightarrow$
$\theta_0\notin S(\xi)$).
- **Т7 (Нейман — Пирсон).** Для простых $H_0$ против $H_1$ область
$S_\lambda=\{p_1-\lambda p_0\ge0\}$ максимизирует мощность при заданном
$\Prob_0(S)$ и несмещённа; при $\Prob_0(S_\lambda)=\varepsilon$ это р.н.м.к.
уровня $\varepsilon$.
- **Т8 (монотонное отношение правдоподобия).** При МОРП по $T$ с непрерывным
распределением критерий $S=\{T\ge c\}$ с $\Prob_{\theta_0}(T\ge c)=\varepsilon$
— р.н.м.к. для $H_0:\theta\le\theta_0$ против $H_1:\theta>\theta_0$.
- **Т9 (критерии нормальной модели).** $H_0:a=a_0$, $\sigma$ известно:
$U=\sqrt N(\overline X_N-a_0)/\sigma$, $\abs U\ge z_{\beta_{+}}$
(односторонний — р.н.м.к.); $\sigma$ неизвестно: $T=\sqrt N(\overline X_N-a_0)/s_N\sim t_{N-1}$;
$H_0:\sigma^2=\sigma_0^2$: $\chi^2=(N-1)s_N^2/\sigma_0^2$; две выборки
$H_0:a_1=a_2$: $t_{N+M-2}$ с $s_{\text{обш}}$; $H_0:\sigma_1^2=\sigma_2^2$:
$F=s_{1N}^2/s_{2M}^2$ (критерий Фишера). При неизвестном $\sigma$ односторонний
t-критерий оптимален лишь среди несмещённых.
- **Т10 (Пирсон, $\chi^2$).** При верной $H_0$ критерий согласия Пирсона
$\widehat\chi^2_N\xrightarrow{d}\chi^2_{r-1}$.
- **Т11 (Колмогоров).** Если $F$ непрерывна, то распределение
$D_N=\sup_t\abs{F_N^{*}-F}$ не зависит от $F$ (инвариантность) и
$\Prob\{\sqrt ND_N<\lambda\}\to K(\lambda)=\sum_k(-1)^ke^{-2k^2\lambda^2}$.

## Методы и алгоритмы

- **Построение доверительного интервала.** Центральная статистика
$G(\xi,\theta)$ с известным распределением (для нормальной модели — Т4) →
квантили $g_1,g_2$ → область $\{\theta:g_1\le G(\xi,\theta)\le g_2\}$ уровня
$\gamma=\Prob(g_1\le G\le g_2)$; при неизвестном параметре распределения —
асимптотические интервалы по ЦПТ (вопрос 12).
- **Построение критерия.** Лемма Неймана — Пирсона: отношение правдоподобия
$S_\lambda=\{p_1-\lambda p_0\ge0\}$, порог $\lambda$ из уровня
$\Prob_0(S_\lambda)=\varepsilon$; для односторонних альтернатив при МОРП —
квантильная область по достаточной статистике (Т8); рабочий уровень —
p-value наблюдения.
