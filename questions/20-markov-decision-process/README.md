  оптимум E = 2,256 при стратегии «всегда удобрять», π = (6/59, 31/59, 22/59);
  дисконт α = 0,6: оптимальная {1,2,2}, f = (8,97; 6,63; 3,38). Матрицы
  P¹, P², R¹, R² сверены с изображением печ. с. 738 (слой местами битый:
  0 читается как D, 8 как @); числа задачи садовника закреплены golden-пинами
  ноутбука.
- Терминология источников: [60] — «марковская задача принятия решений»,
  стратегия, альтернатива; [44] — «управляемый марковский процесс», стратегия
  a(s); англ. tradition (и [55]) — policy, value function. Основное слово у нас —
  «стратегия», англ. policy. Марковская стратегия — выбор от пары (t, i_t)
  (последовательность π_t: S → A); стационарная детерминированная — одно
  отображение π: S → A (путаница двух признаков — находка ревью экзаменатора,
  исправлена в определении `def:policy`).
- Дисконт: у [60] — α, у [44]/[55] — γ. У нас γ (α занят: уровень значимости
  вопроса 14, вектор функционала наблюдения вопроса 04). Заявлено в глоссарии
  блока.
- Стационарное распределение у [60] обозначено π; у нас π — стратегия (как в
  [55]), стационарное распределение — μ. Заявлено в глоссарии блока.
- Сходимость итераций по ценности/стратегиям и существование оптимальной
  стационарной стратегии у [60] не доказываются; строгое доказательство —
  наше (через сжатие), в стиле [55] (англ., гл. про MDP).
- Посылка неприводимости всех стационарных стратегий в теоремах среднего
  дохода на задаче садовника нарушена (четыре стратегии с π(3) = 1
  поглощающие, μ = (0,0,1); итерации стартуют с {1,1,1}) — оговорено в
  `rem:unichain`; общая рама — унихейловая модель [55].
- LQ-пример — предельный случай γ = 1, W = 0 (константа c обнуляется;
  посылки теоремы читаются как стабилизируемость (A, B) и детектируемость
  (Q^½, A)); в условии задачи R = 1. Предел h → 0 — в алгебраическое
  (непрерывное) уравнение Риккати и только после масштабирования Q, R на h;
  образ полюса s = −1 — дискретизация Тастина (2−h)/(2+h), не «билинейная
  Эйлера» (находка ревью экзаменатора, исправлена).
- Опечатка источника: [60] (печ. 746) печатает E³ = 0,4 для стратегии 3 —
  верное значение −1,0 (её μ = (0,0,1), v₃ = −1); документирована в ноутбуке,
  не исправляется молча.
