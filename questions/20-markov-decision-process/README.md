## Связи с другими вопросами

Опирается на [вопрос 03](../03-decision-bayes-minimax/) (общая проблема
принятия решения: функция потерь, средний риск Байеса) и [вопрос 06](../06-optimal-control-pontryagin/)
(оптимальное управление: уравнение Беллмана в непрерывном времени, связь
p = −∇S с принципом максимума, задача Риккати). Сквозной объект управленческого
блока — линейная система с обратной связью: здесь её дискретный стохастический
аналог (LQ-модель). Марковские цепи — подложка из теории случайных процессов
(вопрос 08 даёт вероятностный аппарат: условное математическое ожидание).
