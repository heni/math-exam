---
title: "Вопрос 20. Марковский процесс принятия решения"
---

**Основной результат.** Для бесконечного дисконтированного горизонта
($\gamma\in(0,1)$) оптимальная функция цены — единственная неподвижная
точка сжимающего оператора Беллмана $\mathcal{T}$
($\norm{\mathcal{T}V-\mathcal{T}W}_\infty\le\gamma\norm{V-W}_\infty$):
$V^{*}(i)=\max_a\bigl[v_i(a)+\gamma\sum_jp_{ij}(a)V^{*}(j)\bigr]$; оптимальная
стратегия существует, стационарная и детерминированная; итерации по ценности
сходятся со скоростью $\gamma^k$, а метод итераций по стратегиям конечен
(не более $|A|^n$ итераций). Для среднего дохода в неприводимом случае
$g^{\pi}=\mu^{\T}r^{\pi}$ не зависит от старта и определяется системой с
потенциалом $f$.

## Определения

- **Марковский процесс принятия решения** $(S,A,P,r)$: конечные $S$ и $A$,
стохастические матрицы $P(a)=(p_{ij}(a))$, доходы $r_{ij}(a)$;
**мгновенный доход** $v_i(a)=\sum_jp_{ij}(a)r_{ij}(a)$ — ожидаемый доход
за шаг в состоянии $i$ при действии $a$ (им пользуются все критерии).
- **Стратегия** — правило выбора действия по истории $h_t$; марковская —
от $(t,i_t)$; стационарная — не от $t$; детерминированная стационарная —
$\pi\colon S\to A$.
- **Критерии:** конечный горизонт $V_N^{\pi}(i)=\E^\pi\sum_{t<N}\gamma^tr_{i_ti_{t+1}}(a_t)$;
бесконечный дисконтированный $V^{\pi}(i)=\E^\pi\sum_{t\ge0}\gamma^tr_{i_ti_{t+1}}(a_t)$;
средний доход $g^{\pi}=\lim_{T\to\infty}\frac1T\E^\pi\sum_{t<T}r_{i_ti_{t+1}}(a_t)$.

## Теоремы

- **Т1 (принцип оптимальности).** Хвост оптимальной стратегии оптимален
относительно достигнутого состояния (и двойственно).
- **Т2 (Беллман, конечный горизонт).** $V_N^{*}=0$,
$V_t^{*}(i)=\max_a\bigl[v_i^{t}(a)+\gamma\sum_jp_{ij}^{t}(a)V_{t+1}^{*}(j)\bigr]$;
оптимальная стратегия существует, марковская, детерминированная —
максимизирующие действия.
- **Т3 (оптимальность Беллмана, бесконечный горизонт).** $\mathcal{T}$ —
$\gamma$-сжатие в $\norm{\cdot}_\infty$; $V^{*}$ — единственная
неподвижная точка; $V_{k+1}=\mathcal{T}V_k$ сходится:
$\norm{V_k-V^{*}}_\infty\le\frac{\gamma^k}{1-\gamma}\norm{V_1-V_0}_\infty$;
оптимальная стратегия стационарная детерминированная,
$\pi^{*}(i)\in\arg\max_a\bigl[v_i(a)+\gamma\sum_jp_{ij}(a)V^{*}(j)\bigr]$.
- **Т4 (оценка стратегии).** $V^{\pi}=(I-\gamma P^{\pi})^{-1}r^{\pi}
=\sum_{t\ge0}\gamma^t(P^{\pi})^tr^{\pi}$ — единственное решение
$V=r^{\pi}+\gamma P^{\pi}V$ ($I-\gamma P^{\pi}$ обратима при $\gamma<1$).
- **Т5 (улучшение стратегии).** $\pi'(i)\in\arg\max_a\bigl[v_i(a)+\gamma\sum_jp_{ij}(a)V^{\pi}(j)\bigr]$
(при ничьей сохраняется $\pi$) $\Rightarrow$ $V^{\pi'}\ge V^{\pi}$
покомпонентно; строгое улучшение в одном состоянии даёт строгое везде, откуда
достижимо. Следствие: итерации по стратегиям конечны ($\le|A|^n$) и последняя
стратегия оптимальна.
- **Т6 (средний доход).** Для стационарной $\pi$ с неприводимой цепью
$g^{\pi}=\sum_i\mu_ir_i$ не зависит от старта; существует потенциал $f$
(с точностью до константы) с $g^{\pi}+f(i)=r_i+\sum_jp_{ij}f(j)$.
Улучшение по правилу $\arg\max_a\bigl[v_i(a)+\sum_jp_{ij}(a)f^{\pi}(j)\bigr]$
не убывает $g$ (при неприводимости всех стратегий). Лемма сравнения: если
$g+f(i)\ge v_i(a)+\sum_jp_{ij}(a)f(j)$ для всех $(i,a)$, то средний доход
любой стратегии $\le g$.
- **Т7 (LP-формулировка).** При весах $b_i>0$ задача $\min_V\sum_ib_iV(i)$ при $V(i)\ge v_i(a)+\gamma\sum_jp_{ij}(a)V(j)$
имеет единственное решение $V^{*}$; двойственная задача по $w_{ia}\ge0$ с
балансными уравнениями; вершинный оптимум задаёт детерминированную
оптимальную стратегию.
- **Т8 (квадратичная задача, Риккати) [A].** При стабилизируемости
$(\sqrt\gamma A,B)$ и детектируемости $(Q^{1/2},\sqrt\gamma A)$ функция цены
$V^{*}(x)=x^{\T}Kx+c$, $K\succeq0$ — решение алгебраического уравнения
Риккати $K=Q+\gamma A^{\T}KA-\gamma^2A^{\T}KB(R+\gamma B^{\T}KB)^{-1}B^{\T}KA$,
$c=\frac{\gamma}{1-\gamma}\tr(KW)$, оптимальное управление — линейная
обратная связь $u^{*}(x)=-Lx$,
$L=\gamma(R+\gamma B^{\T}KB)^{-1}B^{\T}KA$.
- **Т9 (дискретный принцип максимума) [A].** При аффинности $F_t$ по $u$ и
выпуклости $\Phi_t(x,\cdot)+V_{t+1}(F_t(x,\cdot))$ оптимальное управление
удовлетворяет $u_t^{*}\in\arg\max_uH_t(x_t^{*},u,p_t)$,
$H_t=-\Phi_t+p^{\T}F_t$, с сопряжённой системой
$p_{t-1}=-\partial_{x}\Phi_t+\bigl(\partial_xF_t\bigr)^{\T}p_t$,
$p_{N-1}=-\nabla\Theta(x_N^{*})$ — формулы ПМП для дискретной задачи
(мост к вопросу об оптимальном управлении).

## Методы и алгоритмы

- **Итерации по ценности (value iteration).** $V_{k+1}=\mathcal{T}V_k$ из
любого $V_0$; сходимость $\norm{V_k-V^{*}}_\infty\le\frac{\gamma^k}{1-\gamma}
\norm{V_1-V_0}_\infty$; стратегия из жадного выбора по предельной функции
оптимальна (Т3).
- **Итерации по стратегиям (policy iteration).** Цикл «оценка — улучшение»:
$V^{\pi}=(I-\gamma P^{\pi})^{-1}r^{\pi}$, затем
$\pi'(i)\in\arg\max_a\bigl[v_i(a)+\gamma\sum_jp_{ij}(a)V^{\pi}(j)\bigr]$ (при
ничьей сохраняется $\pi$); $V^{\pi'}\ge V^{\pi}$ покомпонентно (Т4, Т5);
алгоритм конечен — не более $|A|^n$ итераций, последняя стратегия оптимальна.
- **Q-learning [A].**
$\mathcal{Q}_{k+1}(s_k,a_k)=(1-\beta_k)\mathcal{Q}_k(s_k,a_k)+\beta_k\bigl[r_k+\gamma\max_{a'}\mathcal{Q}_k(s_{k+1},a')\bigr]$
по наблюдаемым переходам $(s_k,a_k,r_k,s_{k+1})$, не зная $p$ и $r$ заранее
[55]; сходимость почти наверное — стохастическая аппроксимация при
$\sum\beta_k=\infty$, $\sum\beta_k^2<\infty$ и посещаемости всех пар $(s,a)$.

*Аппарат (сжато):* уравнение Колмогорова—Чепмена $p_{ij}^{(m+l)}=\sum_kp_{ik}^{(m)}p_{kj}^{(l)}$;
для неприводимой цепи стационарное распределение $\mu^{\T}P=\mu^{\T}$
единственно, $\mu_j>0$, среднее время возвращения $1/\mu_j$; эргодичность:
$\norm{a^{\T}P^t-b^{\T}P^t}_1\le2(1-n\delta)^{\lfloor t/m\rfloor}$.
