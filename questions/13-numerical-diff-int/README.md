### Теоремы с полными доказательствами

- [x] **Т1.** Остатки прямоугольников, трапеций и Симпсона (Тейлор и
      интерполянт Эрмита $H_3$; неулучшаемость констант — с функциями,
      на которых достигается равенство). [09] гл. 4 §1.
- [x] **Т2 (лемма Ричардсона).** Подъём порядка точности в таблице —
      доказательство по индукции, [09] гл. 4 §1.
- [x] **Т3 (критерий интерполяционного типа).** Точность на $\mathcal P_n$
      влечёт интерполяционность. [09] гл. 4 §2.
- [x] **Т4.** Лемма о симметричных формулах и теорема о повышении степени
      точности ($n \to n+1$). [09] гл. 4 §2.
- [x] **Т5 (основная теорема о формулах Гаусса).** Точность на $\mathcal P_{2n-1}$
      равносильна ортогональности $\omega$ с весом $\rho$ плюс интерполяционный
      тип. [09] гл. 4 §3.
- [x] **Т6.** Существование и единственность формул Гаусса; простота корней
      ортогонального многочлена; положительность коэффициентов. [09] гл. 4 §3.
- [x] **Т7 (остаток формул Гаусса).** Собственное доказательство по методу,
      указанному в [09]: интерполянт Эрмита с двукратными узлами, ядро
      $\rho\omega^2$ знакопостоянно, теорема о промежуточном значении.
- [x] **Т8.** Разностные формулы: разложения погрешности, порядки на
      равномерной сетке и потеря порядка на неравномерной (коэффициент
      $x_i - x + (h_{i+1}-h_i)/3$ при $u'''$). [09] гл. 4 §4.
- [x] **Т9.** Баланс погрешностей $2\delta/h$ и $M_2 h/2$, критический шаг
      $h_0 = 2\sqrt{\delta/M_2}$, минимум $2\sqrt{\delta M_2}$; неулучшаемость
      $\sqrt{2M\varepsilon}$ — с атрибуцией Стечкину по [19] гл. V.
- [x] **П1.** Наилучшие формулы для классов: прямоугольники оптимальны на
      периодических $C^r$; наилучшие операторы дифференцирования (Стечкин) —
      раздел «Наилучшие формулы для классов функций», факты с атрибуцией,
      доказательства по [19] не воспроизводятся.

### Замечания о существенности посылок

- [x] неулучшаемость констант в остатках (функции достижения);
- [x] неустойчивость формул Ньютона — Котеса при $n \ge 10$ (разноимённые
      коэффициенты) → составные формулы и Гаусс;
- [x] дифференцирование некорректно по Адамару, интегрирование корректно
      (сглаживает);
- [x] что ломается при изломе функции (сквозной пример: порядок падает до
      $1{,}5$, экстраполяция по формальному порядку улучшает лишь в $2{,}5$
      раза);
- [x] оптимальность по степени точности и оптимальность по классу — разные
      постановки; рамка минимакса живёт в вопросе 19 (наилучшее равномерное
      приближение) — замечание-мост.

### Численные примеры (`examples.py`, 3 примера, 18 golden-пинов)

- [x] **П1 (сквозной, интегрирование).** $\int_0^1 \sqrt{1-x}\,dx = 2/3$:
      измеренный порядок трапеций $1{,}4962$ вместо $2$; правило Рунге
      недооценивает ошибку ($0{,}595$ против асимптотических $0{,}6095$);
      Ричардсон по $p=2$ улучшает в $2{,}5$ раза, процесс Эйткена — в $88$;
      сравнение Симпсона и Гаусса — Лежандра при равном числе вычислений $f$
      ($11$–$164$ раза). Картинка fig-01. (Функция и феномен — из примера 5.2
      [43] гл. 5, адаптировано на $\sqrt{1-x}$; теория — [09].)
- [x] **П2 (сквозной, дифференцирование).** Часть А: $g = \sin x +
      \varepsilon\sin\omega x$ — $\|g-f\|\le\varepsilon$, $\|g'-f'\| =
      \varepsilon\omega$ (некорректность по Адамару). Часть Б: квантование
      данных с шагом $2\delta$ — минимум средней ошибки в окрестности
      $h_0 = 2\sqrt{\delta/M_2}$ величиной $\asymp 2\sqrt{\delta M_2}$, max по
      точкам прижимается к огибающей $2\delta/h + M_2 h/2$. Картинка fig-02.
- [x] **П3.** Формулы Эрмита против равномерной сетки: на $e^x$ машинная
      точность при $n=16$; на $|x|$ наклон $2{,}003$ (хвост ряда по $T_k$ даёт
      $O(n^{-2})$ со знакопеременным множителем $(-1)^{n+1}$); равномерные
      узла дают отрицательные веса ($\sum|c_j| \approx 65{,}3$ при $\sum c_j =
      \pi$ при $n=16$); узлы Голуба — Велша совпали с явной формулой до
      $4{,}4\cdot10^{-16}$. Картинка fig-03.
- [ ] **П4** (опциональная численная проверка неулучшаемости
      $\sqrt{2M\varepsilon}$) — опущена: теорема Стечкина дана с атрибуцией,
      численная иллюстрация баланса в П2 покрывает феномен.
