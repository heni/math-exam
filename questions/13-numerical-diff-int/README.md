# Вопрос 13. Численное дифференцирование и интегрирование

**Блок:** Приближение
**Материал прошлого года:** лекция Л9 курса прошлого года
**Статус:** план содержания составлен (2026-10-14, согласуется с пользователем)

Вопрос уровня 2: требует [вопрос 11](../11-chebyshev-polynomials/) (нули $T_n$ и
ортогональность с весом $(1-x^2)^{-1/2}$ — основа формул Эрмита) и частично
[вопрос 01](../01-splines/) (сплайны как приближающие функции). Основа
конспекта — гл. 4 книги [09] (с. 161–190): выбор узлов обосновывается
ортогональностью и алгебраической степенью точности, оценки погрешности идут
через $\max |f^{(k)}|$.

## Что должно войти

План — контракт на объём: отметка ставится, когда пункт фактически написан и
прочитан целиком, а не когда упомянут.

### Определения

- [ ] квадратурная формула: узлы, коэффициенты, весовая функция, погрешность;
      составные формулы;
- [ ] алгебраическая степень точности;
- [ ] квадратура интерполяционного типа; симметричная квадратурная формула;
- [ ] правило Рунге (апостериорная оценка); экстраполяция Ричардсона;
      метод Ромберга как её частный случай;
- [ ] формулы Гаусса; ортогональные многочлены с весом и их роль (узлы — нули);
- [ ] формулы Эрмита (= квадратура Гаусса—Чебышёва): узлы — нули $T_n$, веса
      $\pi/n$; оба имени при первом употреблении; фиксация ловушки: «Эрмит»
      здесь — вес $(1-x^2)^{-1/2}$, а не многочлены Эрмита (вес $e^{-x^2}$);
- [ ] разностные формулы дифференцирования (односторонние, центральные);
      погрешности усечения и округления;
- [ ] некорректность дифференцирования по приближённым данным (по Адамару —
      термин и рамка от [вопроса 02](../02-ml-inverse-problems/));
- [ ] (опционально) наилучшая квадратурная формула для класса функций
      $E(W, \{p_k, x_k\})$; задача Стечкина о наилучшем операторе
      дифференцирования.

### Теоремы с полными доказательствами

- [ ] **Т1.** Остатки прямоугольников, трапеций и Симпсона (вывод через Тейлора
      и через интерполянт Эрмита $H_3$); неулучшаемость констант в остатках.
      [09] гл. 4 §1.
- [ ] **Т2 (лемма Ричардсона).** Подъём порядка точности в экстраполяционной
      таблице — доказательство по индукции есть у [09] гл. 4 §1.
- [ ] **Т3 (критерий интерполяционного типа).** Точность на $\mathcal P_n$
      влечёт интерполяционность формулы. [09] гл. 4 §2.
- [ ] **Т4.** Лемма о симметричных формулах и теорема о повышении степени
      точности ($n \to n+1$). [09] гл. 4 §2.
- [ ] **Т5 (основная теорема о формулах Гаусса).** Точность на $\mathcal P_{2n-1}$
      равносильна ортогональности фундаментального многочлена $\omega$ с весом
      $\rho$ плюс интерполяционный тип. [09] гл. 4 §3 — доказательство есть.
- [ ] **Т6.** Существование и единственность формул Гаусса; простота корней
      ортогонального многочлена на $[a,b]$; положительность коэффициентов.
      [09] гл. 4 §3.
- [ ] **Т7 (остаток формул Гаусса).** Доказательства нет ни в одной книге
      набора (у [09] — отсылка к Крылову—Бобкову—Монастырному, вне набора) →
      собственное по указанному в [09] методу: интерполянт Эрмита с двукратными
      узлами, ядро сохраняет знак.
- [ ] **Т8.** Разностные формулы дифференцирования: разложения погрешности,
      порядки на равномерной сетке и потеря порядка на неравномерной.
      [09] гл. 4 §4.
- [ ] **Т9.** Баланс погрешностей округления и усечения: условие
      $2\delta/h \asymp M_2 h$, критический шаг; вывод о некорректности.
      [09] гл. 4 §4. Неулучшаемость оценки $\sqrt{2M\varepsilon}$ — факт с
      атрибуцией Стечкину по [19] гл. V.
- [ ] **П1 (опционально).** Наилучшие квадратурные формулы для классов:
      прямоугольники оптимальны на периодических $C^r$; наилучшие операторы
      дифференцирования. [19] гл. V — доказательств нет; судьба раздела —
      открытое решение (см. ниже).

### Замечания о существенности посылок

- [ ] неулучшаемость констант в остатках (контрпримеры из [09]);
- [ ] неустойчивость формул Ньютона—Котеса при $n \ge 10$ (разноимённые
      коэффициенты) → составные формулы и Гаусс;
- [ ] дифференцирование некорректно по Адамару, интегрирование корректно
      (сглаживает);
- [ ] что ломается в оценках остатка при изломе функции (сквозной пример:
      порядок падает);
- [ ] оптимальность по степени точности ≠ оптимальность по равномерной норме:
      где живёт минимаксная постановка (вопрос 19 о наилучшем равномерном
      приближении; [19] гл. V) — замечание-мост.

### Численные примеры (`examples.py`)

- [ ] **П1 (сквозной, интегрирование).** $\int_0^1 \sqrt{1-x}\,dx = 2/3$
      (излом производной в $x=1$): измеренный порядок трапеций $\hat p \approx
      1{,}5$ вместо $2$; правило Рунге; Ричардсон по теоретическому $p$ почти
      не улучшает, а процесс Эйткена по трём сеткам — улучшает; сравнение
      Симпсона и Гаусса при равном числе вычислений $f$. Картинка. (Функция и
      феномен — из примера [43] гл. 5, теория — [09].)
- [ ] **П2 (сквозной, дифференцирование).** $g(x) = \sin x + \varepsilon
      \sin(\omega x)$: $|g - f| \le \varepsilon$, а $|g' - f'| = \varepsilon\omega$
      произвольно велико; плато ошибки при малых $h$; измерение баланса
      $2\delta/h$ против $M_2 h/2$, оптимального шага и достижимой точности;
      сверка с критическим шагом $h_0 = 2\sqrt{\delta/M_2}$. Golden-пины.
- [ ] **П3.** Формулы Эрмита (узлы $\cos\frac{(2k-1)\pi}{2n}$, веса $\pi/n$)
      против равномерной сетки на функции с изломом и на гладкой: сходимость,
      устойчивость (равные веса). Картинка.
- [ ] **П4 (опционально).** Наилучшее дифференцирование для класса $|f''| \le M$:
      численная проверка неулучшаемости $\sqrt{2M\varepsilon}$ (ни один линейный
      функционал не бьёт центральную разность).

### Разобранные задачи

- [ ] остаток Симпсона двумя способами: интерполянт Эрмита $H_3$ и
      экстраполяция трапеций ([09]);
- [ ] перенос формул Эрмита на произвольный отрезок линейной заменой;
      вычисление интеграла с весом $(1-x^2)^{-1/2}$;
- [ ] автоматический выбор шага по правилу Рунге с заданной точностью
      $\varepsilon$ ([09]);
- [ ] оценка $|\int f - \int \varphi| \le (b-a)\,\|f-\varphi\|_C$ — задача-мост
      к вопросу 19.

## Пробелы набора (пишем сами или опускаем)

- остаток формул Гаусса (Т7) — доказательство своё;
- формула Эйлера—Маклорена — у [09] только асимптотическое разложение
  («формула Эйлера») без доказательства: либо своё, либо ограничиться формой
  [09] (для метода Ромберга её достаточно);
- сходимость квадратурных процессов для непрерывных функций (теорема
  Стеклова) — нет ни в одной книге набора → опускаем;
- оценка погрешности через наилучшие приближения $E_n(f)$ — нет: элементарная
  собственная выкладка (несколько строк) или опускаем;
- кубатурные формулы — замечание по [43] §5.5, теорем нет.
