Сквозной объект — та же линейная система, что в вопросе 04:
$\dot x = Ax + Bu$, сквозной пример — двойной интегратор
$\dot x_1 = x_2$, $\dot x_2 = u$ ($n = 2$, $r = 1$, $U = [-1, 1]$ или
$\R$): то же управление, что в вопросе 04, но теперь вход $u$ не известен, а
подлежит выбору — по критерию качества. Тот же объект ведёт вопрос 20
(дискретный аналог).

### Теория

- [x] **Постановка и мотивация**: задача оптимального управления с
  ограничением $u(t) \in U$; чем она отличается от задач вариационного
  исчисления (замкнутое $U$ → экстремум на границе, $\partial H/\partial u
  = 0$ бессильно; невыпуклость $f^0$ по $u$ → разрывные оптимальные
  управления даже при $U = \R$); пример неразрешимости в гладком классе
  [50] §6.5 (пример 6.3: нижняя грань не достигается ни на одной
  непрерывной паре); мост к вопросу 04 (тот же объект, измерения → оценка →
  управление) и к вопросу 10 (минимизация функционала качества);
  существование решения — теорема Филиппова [56] гл. 4 (выпуклость
  расширенного множества $\{y^0 \geq f^0, y = f\}$; в примере
  неразрешимости она нарушена — подынтегральная функция невыпукла, — но
  оптимум есть: кусочно-постоянное $u^* = \pm 1$, теорема достаточна, не
  необходима);
- [x] **Определения**: допустимое управление (кусочно-непрерывное,
  $u(t) \in U$), допустимый процесс, критерий Больца
  $J = \int_{t_0}^{T} f^0\,dt + \Phi(x(T))$ (частные случаи Лагранж и
  быстродействие), функция Понтрягина $H = p^{\T} f - \lambda_0 f^0$,
  сопряжённая система $\dot p = -\partial H/\partial x$, экстремальный
  процесс; конвенция знака — гамильтонова форма лекции ($\lambda_0 \geq 0$,
  максимум $H$), согласованная с [20]; у [50], [12], [56] запись
  $H = \psi_0 f^0 + \psi^{\T} f$ с $\psi_0 \leq 0$ — та же конвенция при
  $\psi_0 = -\lambda_0$, $\psi = p$;
- [x] **Принцип максимума** (формулировка по [12] гл. 8, [50] гл. 7, [56]
  гл. 1 согласованно): существование $(\lambda_0, p(t)) \not\equiv 0$,
  $\lambda_0 \geq 0$; условие максимума $H$ по $u$; трансверсальность на
  свободном/многообразном конце; замечания: ненулевость и однородность по
  $(\lambda_0, p)$ (нормировка), постоянство $\max_{u \in U} H$ вдоль
  автономной оптимальной пары и условие $\max_u H = 0$ при свободном
  времени ([50] т. 7.1, зам. 7.1 — с полным доказательством постоянства
  через $m(t) = \max_v H(x^*(t), p(t), v)$ и нулевого максимума вариацией
  терминального момента),
  необходимость условий, абнормальный случай $\lambda_0 = 0$ (в примерах
  исключается через противоречие, как в лекции; при свободном правом конце
  невозможен автоматически: $p(T) = 0 \Rightarrow p \equiv 0$);
- [x] **Теорема Филиппова** (существование, [56] гл. 4): формулировка
  (компакт $U$, непрерывность и гладкость по $x$, условие роста, выпуклость
  расширенного множества $\{y^0 \geq f^0, y = f\}$), замечание о
  существенности выпуклости: в примере неразрешимости условие нарушено,
  но оптимум есть — теорема достаточна, не необходима; схема
  доказательства — минимизирующая последовательность, Арцела, измеримый
  выбор;
- [x] **Общая формулировка ПМП** ([56] гл. 1): многообразия на обоих
  концах, свободное время ($\max_u H = 0$), неавтономность
  ($\dot m = \partial H/\partial t$ вместо постоянства);
- [x] **Доказательство** — полное доказательство сформулированной теоремы
  (абнормальный случай при свободном правом конце исключён автоматически,
  поэтому нормальный случай $\lambda_0 = 1$ не ограничивает общности),
  закреплённый левый конец и свободный правый конец, по [12] гл. 8 §2
  п. 3: лемма Гронуолла (с доказательством), оценки приращения траектории и
  функционала (оформляются леммами), игольчатая вариация, предельный переход;
  замечание: случай закреплённого правого конца и $\lambda_0 = 0$ требует
  той же схемы в полном объёме ([50] §7.2 — идея: игольчатые вариации
  Макшейна, выпуклость предельного множества достижимости; атрибуция —
  общий нелинейный случай доказал В. Г. Болтянский, линейный — Р. В.
  Гамкрелидзе, см. [50] печ. 208–209);
- [x] **Трансверсальность на терминальном многообразии** — схема через
  конус вариаций в $\R^{n+1}$ (координата критерия) и отделимость от
  конуса улучшений $\{(-s, \zeta)\}$ (по схеме [12]);
- [x] **Связь с вариационным исчислением** (теорема): простейшая задача ВИ
  как задача управления с $\dot x = u$, $U = \R^r$; из принципа максимума
  следует уравнение Эйлера (полное доказательство: обоснование
  $\lambda_0 \neq 0$ через неограниченность $U$, интегрирование сопряжённой
  системы; посылка — минимум среди кусочно-гладких, ПМП — условие сильного
  экстремума) — [12] §3, [56] §27; замечание: из глобального максимума $H$
  следуют условия Вейерштрасса и Лежандра, из непрерывности $p$ —
  условие Вейерштрасса — Эрдмана (непрерывность $\psi$ и $H$ — у [56]
  §27);
- [x] **Линейные системы и задача быстродействия**: постановка
  $\dot x = Ax + Bu$, выпуклый компакт $U$; условие максимума
  $\max_{u\in U} p^{\T}Bu$; теорема (bang-bang): при управляемости
  $(A, B)$ экстремаль кусочно-постоянна со значениями в вершинах $U$
  (полное доказательство для скалярного $u$ через аналитичность
  $p^{\T}(t)b$, как у [50] т. 7.3); лемма о числе действительных корней
  квазимногочлена $\sum_i P_i(t)e^{\lambda_i t}$ (посылка: вещественный
  спектр и вещественные коэффициенты — без неё ложна, контрпример
  $\sin t$; полное доказательство индукцией по числу слагаемых через
  обобщённую теорему Ролля); теорема
  Фельдбаума: при вещественном спектре $A$ не более $n - 1$ переключений
  (полное доказательство по [50] т. 7.4); у [20] те же оценки — «теорема
  Беллмана — Фельдбаума»; замечание: для линейных задач быстродействия
  условия ПМ необходимы и достаточны (Гамкрелидзе; [50] т. 7.5–7.6 —
  единственность при $0 \in \operatorname{int} U$ и достижимости нуля);
  абзац об особых (сингулярных) управлениях ($g \equiv 0$ на интервале,
  условия высших порядков);
- [x] **Разобранные задачи**:
  1. двойной интегратор, минимум энергии: $x(0) = (2, 1)$, $T = 4$,

  2. двойной интегратор, быстродействие: синтез
     $u^* = -\mathrm{sgn}\!\bigl(x_1 + \tfrac{1}{2}x_2\abs{x_2}\bigr)$

     $x_1 = -\tfrac{1}{2}x_2\abs{x_2}$); оптимальность — верификация

  3. пример лекции: $\int_{-\pi}^{\pi} x\sin t\,dt \to \mathrm{extr}$ при

   $\max_u H$ (пин `energy_maxH_const` $= 25/32$);
3. Двойной интегратор, быстродействие из $(-2, -1)$: численное
   интегрирование bang-bang по синтезу; пины `timeopt_t_switch` $=
   1 + \sqrt{5/2}$, `timeopt_switch_x1` $= -5/4$, `timeopt_T` $=
   1 + \sqrt{10}$; проверки по численным дугам: $\max_u H \equiv 0$ и

   кривой переключения;

## Заметки для петли

- Обозначения (локальные для вопроса): $t_0$ — начальный момент, $T$ —
  терминальный (время свободно или фиксировано постановкой);
  $\varphi$ в записи лекции — правая часть динамики, в конспекте правая
  часть — $f(t,x,u) = (f_1, \dots, f_n)^{\T}$ (как у [50], [12]); $f^0$ —
  подынтегральная функция критерия (как у [50]); $\Phi$ — терминант
  критерия Больца (коллизия с переходной матрицей вопроса 04 заявлена в
  тематическом глоссарии; в конспекте 06 фундаментальная матрица
  обозначается $e^{At}$, буквой не выносится); $p \in \R^n$ —
  сопряжённый вектор (в лекции — $p$; у [50], [12], [56] — $\psi$);
  $\lambda_0 \geq 0$ — множитель цели (в лекции — $\lambda_0$; у [50],
  [12] — $\psi_0 \leq 0$; связь $\psi_0 = -\lambda_0$);
  $H(t, x, p, u) = p^{\T} f(t,x,u) - \lambda_0 f^0(t,x,u)$ — функция
  Понтрягина, условие максимума по $u$; $U \subset \R^r$ — множество
  допустимых значений управления (компакт или $\R^r$ по постановке);
  $J$ — критерий качества; $x^*$, $u^*$ — оптимальная пара (шляпка
  $\hat{\phantom{x}}$ не используется: в вопросе 04 она — за оценкой
  состояния); $S(x)$ — функция оптимального времени/Беллмана в разборе задачи 2;
  кривая переключения буквой не обозначается (у [20] — через уравнение);
- Заявленные коллизии (вносить в тематический глоссарий блока):
  $\Phi$ — терминант критерия (06) против переходной матрицы $\Phi(t,
