# Постановка

## Зачем это нужно

- Функция $f$ задана таблицей значений с погрешностью; её нужно заменить
  функцией $p$ с малым числом параметров — сжатие численной информации.
- Полная погрешность складывается из пяти слагаемых: дискретизации,
  исходных данных, уклонения от класса $V$, алгоритма и вычислений.
- Равномерная норма отвечает требованию близости в каждой точке;
  наилучшее равномерное приближение (англ. \emph{best uniform
  approximation}) минимизирует максимум уклонения.

## Формальная постановка

Дано: компакт $Q$, система $\Phi = \{\varphi_0, \dots, \varphi_n\} \subset C(Q)$, $V_n = \operatorname{lin}\Phi$, $f \in C(Q)$. Требуется
найти $p^* \in V_n$ с

$$ \|f - p^{*}\|_{C(Q)} = E(f, V_n) = \inf_{p \in V_n} \|f - p\|_{C(Q)}. $$

Элемент $p^{*}$ — элемент наилучшего приближения; множество всех таких
элементов $P_V(f)$, отображение $f \mapsto P_V(f)$ — метрическая проекция
(англ. \emph{metric projection}, вообще говоря многозначное). Главный
пример: $\varphi_k(t) = t^k$,
$V_n = \mathcal{P}_n$, $E_n(f)$.

# Основные результаты

## Условие Хаара

\begin{definition}
Система $\Phi = \{\varphi_0, \dots, \varphi_n\} \subset C(Q)$
удовлетворяет условию Хаара (англ. \emph{Haar condition}), если
любой нетривиальный полином $p \in V_n$ ($p \not\equiv 0$) имеет на
$Q$ не более $n$ различных нулей.
\end{definition}

Эквивалентно: $D(t_0, \dots, t_n) = \det(\varphi_i(t_j)) \ne 0$ для любых
$n+1$ различных точек. Примеры: $\{1, t, \dots, t^n\}$ на отрезке;
тригонометрическая система на окружности.

## Чебышёвский альтернанс

\begin{definition}
Пусть $f \in C[a,b]$, $p \in \mathcal{P}_n$, $\Delta = f - p$.
Набор точек $a \le t_0 < t_1 < \dots < t_{n+1} \le b$ называется
чебышёвским альтернансом (англ. \emph{alternation},
\emph{equioscillation}), если
$$ \Delta(t_i) = \sigma (-1)^i \|\Delta\|_{C[a,b]}, \qquad i = 0, 1, \dots, n+1, $$
где $\sigma = +1$ или $\sigma = -1$ — один для всех $i$. Набор точек
$t_0 < t_1 < \dots < t_{n+1}$ называется валле-пуссеновским (набором с
чередованием знака погрешности), если
$\Delta(t_i)\,\Delta(t_{i+1}) < 0$ при всех $i = 0, \dots, n$.
\end{definition}

Валле-пуссеновский набор — ослабление чебышёвского: чередование знака
без достижения нормы.

## Существование

\begin{theorem}[о существовании]
Пусть $X$ — нормированное пространство, $V \subset X$ — конечномерное
подпространство. Тогда для всякого $x \in X$ в $V$ существует элемент
наилучшего приближения: множество $P_V(x)$ непусто.
\end{theorem}

**Схема:** срез $\{p \in V : \|x - p\| \le \|x - p_0\|\}$ — ограниченный
замкнутый шар в конечномерном пространстве, значит компакт; непрерывная
функция $\|x - p\|$ достигает минимума по Вейерштрассу.

## Критерий Колмогорова

\begin{theorem}[А. Н. Колмогоров]
Пусть $\Phi = \{\varphi_0, \dots, \varphi_n\} \subset C(Q)$ — линейно
независимая система, $f \in C(Q)$, $p^{*} \in V_n = \operatorname{lin}\Phi$,
$\Delta = f - p^{*}$, $Q^* = \{t \in Q : |\Delta(t)| = \|\Delta\|\}$.
Многочлен $p^{*}$ является элементом наилучшего приближения для $f$ тогда
и только тогда, когда не существует многочлена $q \in V_n$ со свойством
$$ q(t)\,\Delta(t) > 0 \qquad \forall\, t \in Q^*. $$
\end{theorem}

Эквивалентно: $0 \in \operatorname{conv}\{\Delta(t)\varphi(t) : t \in Q^*\}$,
где $\varphi(t) = (\varphi_0(t), \dots, \varphi_n(t)) \in \R^{n+1}$;
по Каратеодори достаточно $n+2$ точек экстремума.

## Теорема Валле—Пуссена

\begin{theorem}[Валле—Пуссен]
Пусть $f \in C[a,b]$, $p \in \mathcal{P}_n$, $\Delta = f - p$. Если
существует набор точек $a \le t_0 < t_1 < \dots < t_{n+1} \le b$ с
$\Delta(t_i)\Delta(t_{i+1}) < 0$ для всех $i = 0, \dots, n$, то
$$ E_n(f) \ge \min_{i=0,\dots,n+1} |\Delta(t_i)|. $$
\end{theorem}

Двусторонняя оценка для любого $p$: $\min_i|\Delta(t_i)| \le E_n(f) \le \|\Delta\|$ — основа критерия остановки.

## Альтернансный критерий Чебышёва

\begin{theorem}[П. Л. Чебышёв]
Многочлен $p^{*} \in \mathcal{P}_n$ является многочленом наилучшего
равномерного приближения для $f \in C[a,b]$ тогда и только тогда, когда
для погрешности $\Delta = f - p^{*}$ существует чебышёвский альтернанс,
то есть набор точек $a \le t_0 < t_1 < \dots < t_{n+1} \le b$ со
свойством
$$ \Delta(t_i) = \sigma (-1)^i \|\Delta\|_{C[a,b]}, \qquad i = 0, 1, \dots, n+1, $$
где $\sigma = +1$ или $-1$ — одно на все точки.
\end{theorem}

**Схема:** необходимость — через Колмогорова (многочлен с нулями между
точками, где $\Delta = \pm\|\Delta\|$); достаточность — через
Валле—Пуссена.

## Единственность: теорема Хаара

\begin{theorem}[А. Хаар]
Подпространство $V_n = \operatorname{lin}\{\varphi_0, \dots, \varphi_n\}$
является чебышёвским подпространством пространства $C(Q)$ (то есть для
каждой $f \in C(Q)$ элемент наилучшего приближения единствен) тогда и
только тогда, когда система $\Phi$ удовлетворяет условию Хаара.
\end{theorem}

**Схема:** необходимость — при $D = 0$ конструкция $F$ с двумя
наилучшими приближениями $\pm\varepsilon p$; достаточность — лемма о
$n+2$ экстремальных точках погрешности.

Чебышёвское подпространство (англ. \emph{Chebyshev subspace}) — то, на
чём метрическая проекция однозначна.

## Сильная единственность

\begin{theorem}[о сильной единственности]
Пусть система $\Phi = \{\varphi_0, \dots, \varphi_n\}$ удовлетворяет
условию Хаара на $Q = [a,b]$, $f \in C(Q)$, $p^{*}$ — многочлен
наилучшего приближения для $f$. Существует константа
$\gamma = \gamma(f) > 0$ такая, что для любого многочлена $p \in V_n$
$$ \|p - p^{*}\|_{C(Q)} \le \gamma\, \bigl(\|f - p\|_{C(Q)} - \|f - p^{*}\|_{C(Q)}\bigr). $$
\end{theorem}

«Почти наилучший» многочлен близок к наилучшему: $\|p - p^{*}\| = O(\eta)$
при $\|f - p\| = E_n(f) + \eta$ — это и есть сильная единственность
(англ. \emph{strong unicity}).

## Непрерывность метрической проекции

\begin{theorem}[о непрерывности]
Пусть $V \subset C(Q)$ — чебышёвское подпространство, на котором
метрическая проекция обладает свойством сильной единственности с
константой $\gamma$. Тогда метрическая проекция удовлетворяет условию
Липшица:
$$ \|P(f) - P(f_0)\|_{C(Q)} \le 2\gamma\, \|f - f_0\|_{C(Q)}
\qquad \forall\, f, f_0 \in C(Q). $$
\end{theorem}

## Где ломается

\begin{remark}
Без условия Хаара единственность необязательна, и это видно уже на
простейших двумерных системах. Пример: $f(x) = x$ на $[-1,1]$,
$V = \operatorname{lin}\{1, x^2\}$. Условие Хаара нарушено: многочлен
$x^2 - c$ имеет два нуля $\pm\sqrt{c}$ при $c > 0$. Прямая проверка
(разобрана в \texttt{examples.ipynb}, пример 3) даёт
$E(x, V) = 1$, и наилучшими являются все многочлены $p_a(x) = a(1 - x^2)$
с $a \in [-1/2, 1/2]$: $\|x - p_a\| = 1$ для всех этих $a$ и $\|x - p\| > 1$
вне семейства. Элемент наилучшего приближения определяется неединственно,
причём множество наилучших многочленов — целый отрезок в пространстве
коэффициентов.
\end{remark}

На областях размерности $\ge 2$ чебышёвских подпространств размерности
$\ge 2$ нет вовсе (теорема Мерхьюбера) — переход к сетке и линейному
программированию.

## Алгоритм Валле—Пуссена—Ремеза

На сетке $Q = \{t_1, \dots, t_N\}$, $N \ge n+2$: референс $\tau^k$ из
$n+2$ точек, приращение $p^k$ и число $e^k$ из системы
$\Delta^k(t_i^k) - p^k(t_i^k) = (-1)^i e^k$, где
$\Delta^k = f - (p^0 + \dots + p^{k-1})$; обмен одной точки референса
на точку максимума $|\Delta^k|$ с сохранением чередования.

\begin{theorem}[о сходимости алгоритма]
В обозначениях выше для любого $\varepsilon > 0$ найдётся номер $k$, для
которого многочлен $p = p^0 + p^1 + \dots + p^{k-1}$ удовлетворяет
$\|f - p\|_{C(Q)} \le E + \varepsilon$. При этом $|e^k|$ монотонно
возрастает к $E$, а скорость сходимости геометрическая: $E - |e^k| \le \vartheta\, (E - |e^{k-1}|)$ при некотором $0 < \vartheta < 1$, зависящем
от сетки.
\end{theorem}

## Критерий останова

На каждом шаге $|e^k| \le E \le \|\Delta^{k+1}\|$ (Валле—Пуссен плюс
определение инфимума), поэтому

$$ \|\Delta^{k+1}\| - |e^k| \le \varepsilon \;\Rightarrow\; \|f - p\| - E \le \varepsilon $$

— апостериорная оценка погрешности алгоритма без знания $E$.

## Сведение к линейному программированию

\begin{proposition}
Пусть $Q = \{t_1, \dots, t_N\}$ — конечное множество,
$f, \varphi_0, \dots, \varphi_n$ — функции на $Q$,
$A = \bigl(\varphi_k(t_j)\bigr)_{\substack{j=1,\dots,N \\ k=0,\dots,n}}$,
$b = \bigl(f(t_j)\bigr)_{j=1}^N$. Тогда
$$ E(f, V_n)_Q = \min\bigl\{u \in \R : -u \le (b - Ac)_j \le u,\ j = 1, \dots, N,\ c \in \R^{n+1}\bigr\}. $$
Двойственная задача:
$$ E(f, V_n)_Q = \max\bigl\{ b^{\mathsf T} \nu : \|\nu\|_1 \le 1,\ A^{\mathsf T}\nu = 0 \bigr\}. $$
\end{proposition}

Три минимакса под одним словом: чебышёвская регрессия (ЛП), альтернанс и
Ремез (хааровы системы), статистический минимакс Донохо (шум, риск).

## Полнота многочленов и скорость

\begin{theorem}[Стоуна — Вейерштрасса]
Пусть $B$ — компактное метрическое пространство, $\mathcal A$ —
подалгебра алгебры $C(B)$, содержащая постоянные функции и
разделяющая точки $B$ (для любых $x \ne y$ существует $g \in \mathcal A$
с $g(x) \ne g(y)$). Тогда $\mathcal A$ всюду плотна в $C(B)$: для любой
$f \in C(B)$ и любого $\varepsilon > 0$ существует $g \in \mathcal A$
со $\|f - g\|_{C(B)} < \varepsilon$.
\end{theorem}

\begin{theorem}[Джексона]
Для любой $f \in C[a,b]$ и любого $n = 1, 2, \dots$
$$ E_n(f) \le 2\,\omega\!\left(\frac{b-a}{n+1},\, f\right). $$
\end{theorem}

Для $f \in C^r$: $E_n(f) \le K_r n^{-r}\,\omega((b-a)/(n+1), f^{(r)})$.

# Задачи

## Задача 1: наилучшая прямая для $|x|$ на сетке

**Условие.** $Q = \{-1, -\tfrac12, 0, \tfrac12, 1\}$, $f(x) = |x|$,
$n = 1$, старт с $\tau^0 = \{-\tfrac12, 0, \tfrac12\}$.

. . .

**Решение.** Шаг 1: приращение $p^0 = \tfrac14$, $|e^0| = \tfrac14$;
шаг 2: $\tau = \{-1, 0, 1\}$ после обмена, $|e^1| = \tfrac13$;
шаг 3: сумма $p^0 + p^1 + p^2 \equiv \tfrac12$, $|e^2| = \tfrac12 =
\|\Delta\|$ — стоп. Ответ совпадает с непрерывной задачей:
$p^* \equiv \tfrac12$.

## Задача 2: случаи $n = 0$ и $n = 1$

**Условие.** Найти наилучшее приближение $f \in C[a,b]$ константами и
(для выпуклой $f$) прямыми.

. . .

**Решение.** $n = 0$: $p^* \equiv \tfrac12(\min f + \max f)$, альтернанс
из двух точек. $n = 1$ (выпуклая $f$): наклон $a_1^* = (f(b) - f(a))/(b-a)$, $a_0^* = \tfrac12(\max(f - a_1^* x) + \min(f - a_1^* x))$;
альтернанс из трёх точек. Для $|x|$: $p^* \equiv \tfrac12$.

# Где это работает

| Постановка | Что минимизируется | Ответ | Что покупается |
|---|---|---|---|
| Сжатие численной информации | $\|f - p\|_\infty$ по классу $V$ | $p^*$ с минимаксным уклонением | хранение и быстрый счёт значений |
| Навигация по геофизическим полям | уклонение аппроксимации карты | полином/рациональная дробь | ошибка привязки по уклонению |
| Чебышёвская регрессия $b \approx Ax$ | $\|Ax - b\|_\infty$ через ЛП | точка допустимого множества | устойчивость к ограниченному шуму |
| Оптимальное восстановление | наихудшая погрешность оценки функционала | наилучшая квадратурная формула | гарантии для класса функций |

# Итог

## Что нужно помнить

- Альтернансный критерий Чебышёва: наилучшесть $\Leftrightarrow$
  чередование знака погрешности в $n+2$ точках.
- Теорема Хаара: единственность для всех $f$ $\Leftrightarrow$ условие
  Хаара; без него единственность не гарантируется, на многомерных
  областях — сетки и ЛП.
- Сильная единственность даёт липшицевость метрической проекции и
  устойчивость к погрешностям данных.
- Ремез на сетке сходится геометрически; критерий останова —
  двусторонняя оценка Валле—Пуссена $|e^k| \le E \le \|\Delta^{k+1}\|$.
- Экстремальное свойство многочленов Чебышёва — частный случай
  приближения $f(x) = x^n$; константа Лебега объясняет проигрыш
  интерполяции наилучшему многочлену.
