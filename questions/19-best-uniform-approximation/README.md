# Вопрос 19. Наилучшее равномерное приближение

**Блок:** Приближение
**Материал прошлого года:** нет
**Статус:** план содержания составлен (2026-10-14, согласуется с пользователем)

Вопрос уровня 1: требует [вопрос 11](../11-chebyshev-polynomials/) (общая
нормировка $T_n$ и $\widetilde T_n$; экстремальное свойство — частный случай
приближения $f(x) = x^n$). Доказательства берутся главным образом из [35] —
единственного источника набора с полными выкладками по теореме Хаара,
критерию Колмогорова, альтернансу, Валле—Пуссену и сходимости алгоритма Ремеза
на сетке; [08] даёт общую рамку и обобщения; [19] — формулировки и разобранный
пример.

## Что должно войти

План — контракт на объём: отметка ставится, когда пункт фактически написан и
прочитан целиком, а не когда упомянут.

### Определения

- [ ] пространство $C(Q)$ с нормой $\|\cdot\|_\infty$; система функций
      $\{\varphi_k\}$, обобщённые многочлены $\sum a_k \varphi_k$; величина
      $E_n(f)$;
- [ ] элемент наилучшего приближения; чебышёвское подпространство;
- [ ] условие Хаара (не более $n-1$ нулей нетривиального обобщённого
      многочлена; эквивалент — невырожденность всех определителей
      $\det(\varphi_i(x_j))$);
- [ ] чебышёвский альтернанс; набор точек с чередованием знака погрешности
      (валле-пуссеновский альтернанс);
- [ ] сильная единственность; непрерывность метрической проекции
      $f \mapsto p^*(f)$;
- [ ] сеточная (дискретная) постановка; сведение её к линейному
      программированию;
- [ ] рамка «сжатие численной информации» ([35] гл. I): полная погрешность
      приближения;
- [ ] (опционально) Т-системы [08] (= чебышёвские системы); рациональное
      приближение.

### Теоремы с полными доказательствами

- [ ] **Т1 (существование).** В любом конечномерном подпространстве $C(Q)$
      элемент наилучшего приближения существует. Доказательство: [35] §2.1
      (ограниченная компактность срезов) или [08] теорема 3.3.
- [ ] **Т2 (критерий Колмогорова).** Характеризация элемента наилучшего
      приближения через множество экстремальных точек (нуль в выпуклой оболочке
      знаков погрешности). Доказательство [35] — есть (используется теорема
      Каратеодори, дана там же).
- [ ] **Т3 (теорема Валле—Пуссена).** Двусторонняя оценка $E_n(f)$ по набору
      с чередованием знака: $\min_i |\Delta(x_i)| \le E_n(f) \le \|\Delta\|$.
      Доказательство [35]; обобщённый вариант — [08] теорема 7.1.
- [ ] **Т4 (теорема Чебышёва, альтернансный критерий).** Для многочленов:
      наилучшесть равносильна чередованию знака погрешности в $n+2$ точках.
      Необходимость — через Т2 ([35]); достаточность — через Т3. Перенос на
      чебышёвские системы — замечание со строгим обоснованием по [08]
      (альтернансный критерий доказан полностью для линейного случая).
- [ ] **Т5 (теорема Хаара).** Единственность элемента наилучшего приближения
      для каждой $f$ равносильна условию Хаара. Полное доказательство [35]
      (необходимость — конструкция функции с двумя элементами наилучшего
      приближения; достаточность — через лемму о наборе экстремальных точек).
      Определение и формулировка также [19] с. 12.
- [ ] **Т6 (сильная единственность).** Константа $\gamma$ в оценке
      $\|p - p^*\| \le \gamma\,(\|f - p\| - E_n(f))$. [35] §5.3.
- [ ] **Т7 (непрерывность метрической проекции).** [35] §2.3; формулировка
      [19] с. 13.
- [ ] **Т8 (алгоритм Валле—Пуссена—Ремеза на сетке).** Монотонность
      $|\varrho_k|$ и сходимость к $E$ со скоростью геометрической прогрессии.
      Доказательство [35] §8.1 (у [19] §4 — монотонность и конечность).
      Непрерывный случай (второй алгоритм Ремеза) — замечанием: в наборе с
      доказательством сходимости его нет.
- [ ] **Т9 (сведение к ЛП и двойственность).** Сеточная задача как задача
      линейного программирования; двойственная задача. [35] §8.2, [39] §1.2 и
      пример 5.6; непрерывная двойственность [08].
- [ ] **Замечание (о скорости $E_n(f) \to 0$).** Теорема Вейерштрасса—Стоуна
      с доказательством [08]; теорема Джексона — формулировка с атрибуцией
      (доказательства в наборе нет, [19] со ссылками на внешние источники).

### Замечания о существенности посылок

- [ ] примеры неединственности при отсутствии условия Хаара: $f(x) = x$ в
      $\operatorname{span}\{1, x^2\}$ на $[-1,1]$ (континуум элементов
      наилучшего приближения); конструкция из доказательства необходимости Т5;
- [ ] невозможность условия Хаара на многомерных областях (Мерхьюбер, [08]) →
      сетки и сведение к ЛП;
- [ ] чем альтернанс отличается от леммы о чередовании [вопроса 11](../11-chebyshev-polynomials/):
      критерий наилучшести для произвольной непрерывной $f$ против
      утверждения о конкретном многочлене; экстремальное свойство $T_n$ —
      частный случай $f = x^n$;
- [ ] три минимакса под одним словом: чебышёвская регрессия (сведение к ЛП),
      альтернанс, статистический минимакс Донохо ([57], [59]) — развести
      одним замечанием;
- [ ] (опционально) рациональное приближение: валле-пуссеновский альтернанс с
      весовым множителем знаменателя ([35] §7).

### Численные примеры (`examples.py`)

- [ ] **П1.** Алгоритм Ремеза для $f(x) = |x|$, $n = 1$: аналитический ответ
      $p^* \equiv 1/2$, $E_1 = 1/2$, альтернанс в $-1, 0, 1$; дискретный
      обменный алгоритм на 5-точечной сетке повторяет разобранный в [19] и [35]
      пример; график сходимости $|\varrho_k| \uparrow E$. Golden-пин.
- [ ] **П2 (сквозной).** Функция с пиком ($1/(1+25x^2)$ — функция Рунге, или
      $\sqrt{x+1}$ на $[0,1]$): полный Ремез против интерполяции в
      чебышёвских узлах; сравнение с $E_n(f)$; объяснение отношения ошибок
      через константу Лебега (мост к вопросу 11). Картинка.
- [ ] **П3.** Неединственность без условия Хаара: $f(x) = x$,
      система $\{1, x^2\}$ на $[-1,1]$ — перебор параметра $c \in [-1,1]$,
      $E = 1$; проверка нарушения условия Хаара.
- [ ] **П4 (опционально).** Сеточная задача через ЛП (`linprog`) против
      обменного алгоритма.

## Источники

Основной источник доказательств — [35] (Бердышев, Петрак): условие Хаара и
теорема Хаара с доказательством, критерий Колмогорова с доказательством,
теорема Чебышёва (необходимость), теорема Валле—Пуссена с доказательством,
сильная единственность, непрерывность метрической проекции, алгоритм
Валле—Пуссена—Ремеза на сетке с доказательством сходимости, сведение к ЛП,
рациональное приближение (теоремы Чебышёва и Валле—Пуссена для дробей) —
гл. I §2, §5, §7, §8. Там же рамка «сжатия численной информации» и прикладные
задачи гл. III.

- [08] (Коллатц, Крабс) — профильная рамка: общая теория чебышёвского
  приближения (существование теорема 3.3; Н-множества и Т-системы, гл. III;
  альтернансный критерий с полным доказательством, гл. II §7; непрерывность
  Т-операторов, гл. II §8; двойственность, гл. IV §2; теоремы Стоуна и
  Вейерштрасса с доказательством, гл. VI §1; задачи с решениями, приложение §5).
  Классический алгоритм Ремеза не излагается (упоминание и справки, с. 224).
- [19] (Бердышев, Субботин): условие Хаара и теорема Хаара — с. 12; теоремы
  Чебышёва и Валле—Пуссена — с. 19–20 (формулировки); алгоритм Ремеза на сетке
  с доказательством монотонности — с. 23–25; разобранный пример $|x|$, $n=1$ —
  с. 25; теорема Джексона — формулировка, с. 17–18. Гл. V — мост к вопросу 13.
- [31] (труды конференции Стечкина, 1975) — атрибуции: Каленчук-Порханова

  операторов — мост к вопросу 13), Арестов (приближение неограниченных
