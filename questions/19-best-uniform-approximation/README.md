### Определения

- [x] пространство $C(Q)$ с нормой $\|\cdot\|_\infty$; система функций
      $\{\varphi_k\}$, обобщённые многочлены $\sum a_k \varphi_k$; величина
      $E_n(f)$;
- [x] элемент наилучшего приближения; множество существования,
      единственности, чебышёвское подпространство;
- [x] условие Хаара (не более $n-1$ нулей нетривиального обобщённого
      многочлена для системы из $n$ функций; в нашей нормировке [35] —
      система из $n+1$ функции, не более $n$ нулей; эквивалент —
      невырожденность всех определителей $\det(\varphi_i(x_j))$);
- [x] чебышёвский альтернанс; валле-пуссеновский набор (чередование знака
      погрешности без достижения нормы);
- [x] сильная единственность; непрерывность метрической проекции
      $f \mapsto P_V(f)$;
- [x] сеточная (дискретная) постановка; сведение её к линейному
      программированию;
- [x] рамка «сжатие численной информации» ([35] гл. I): полная погрешность
      приближения (пять слагаемых, § 1.5);
- [x] Т-системы [08] (= чебышёвские системы) — в замечании к теореме
      Хаара; рациональное приближение — замечанием ([35] § 7, атрибуция
      Ахиезера для обобщённой теоремы Валле—Пуссена).

### Теоремы с полными доказательствами

- [x] **Т1 (существование).** В любом конечномерном подпространстве
      нормированного пространства элемент наилучшего приближения
      существует. [35] § 2.1 (ограниченная компактность срезов).
- [x] **Т2 (критерий Колмогорова).** Характеризация через множество
      экстремальных точек $Q^*$; следствие про нуль в выпуклой оболочке
      (с леммой Каратеодори). [35] § 5.2.
- [x] **Т3 (теорема Валле—Пуссена).** Двусторонняя оценка $E_n(f)$ по
      набору с чередованием знака. [35] § 5.2; обобщённый вариант — [08]
      теорема 7.1 (замечанием).
- [x] **Т4 (теорема Чебышёва, альтернансный критерий).** Необходимость —
      через Т2 ([35]); достаточность — через Т3; перенос на чебышёвские
      системы — замечанием со строгим обоснованием по [08] (гл. II § 7).
- [x] **Т5 (теорема Хаара).** Единственность для каждой $f$ равносильна
      условию Хаара, полное доказательство [35] § 5.1 (необходимость —
      конструкция функции $F$ с двумя наилучшими приближениями;
      достаточность — лемма о наборе из $n+2$ экстремальных точек).
- [x] **Т6 (сильная единственность).** Константа $\gamma$ в оценке
      $\|p - p^{*}\| \le \gamma\,(\|f - p\| - E_n(f))$. [35] § 5.3.
- [x] **Т7 (непрерывность метрической проекции).** Липшицевость при
      сильной единственности ($2\gamma$); пример С. Б. Стечкина о потере
      равномерной непрерывности. [35] § 2.3.
- [x] **Т8 (алгоритм Валле—Пуссена—Ремеза на сетке).** Монотонность
      $|e^k|$ и сходимость к $E$ со скоростью геометрической прогрессии.
      [35] § 8.1. Непрерывный случай (второй алгоритм Ремеза) —
      замечанием: доказательства сходимости в наборе нет.
- [x] **Т9 (сведение к ЛП и двойственность).** Сеточная задача как ЗЛП;
      двойственная задача $\max b^{\mathsf T}\nu$ при $\|\nu\|_1 \le 1$,
      $A^{\mathsf T}\nu = 0$. [35] § 8.2, [39] § 1.2, § 6.1, упражнение
      5.6 из § 5.6.
- [x] **Замечание (о скорости $E_n(f) \to 0$).** Теорема Стоуна —
      Вейерштрасса с полным доказательством (по Дьедонне, [08] гл. VI
      § 1); теорема Джексона — формулировка с атрибуцией [19] (с. 17–18,
      со ссылками на внешние источники).

### Замечания о существенности посылок

- [x] примеры неединственности при отсутствии условия Хаара: $f(x) = x$
      в $\operatorname{span}\{1, x^2\}$ на $[-1,1]$ — континуум элементов
      наилучшего приближения (пример 3, разбор с границей $E = 1$ и плато
      $a \in [-1/2, 1/2]$); конструкция из доказательства необходимости Т5;
- [x] невозможность условия Хаара на многомерных областях (Мерхьюбер,
      [08], гл. II, § 6) → сетки и сведение к ЛП;
- [x] чем альтернанс отличается от леммы о чередовании [вопроса 11](../11-chebyshev-polynomials/):
      критерий наилучшести для произвольной непрерывной $f$ против
      утверждения о конкретном многочлене; экстремальное свойство $T_n$ —
      частный случай $f = x^n$;
- [x] три минимакса под одним словом: чебышёвская регрессия (сведение к
      ЛП), альтернанс и Ремез, статистический минимакс Донохо ([57],
      [59]) — разведены замечанием с мостами к регрессиям и функции потерь;
- [x] рациональное приближение: валле-пуссеновский альтернанс с весовым
      множителем знаменателя — замечанием ([35] § 7).

### Численные примеры (`examples.py`)

- [x] **П1.** Алгоритм Ремеза для $f(x) = |x|$, $n = 1$: аналитический
      ответ $p^{*} \equiv 1/2$, $E_1 = 1/2$, альтернанс в $-1, 0, 1$;
      дискретный обменный алгоритм на 5-точечной сетке: три итерации,
      $|e^k| = 1/4 \to 1/3 \to 1/2$; график сходимости. Golden-пины на
      точные рациональные значения; свободная ЛП-сверка
      (`bounds=(None, None)` — иначе scipy по умолчанию требует $c \ge 0$).
- [x] **П2 (сквозной).** Функция Рунге $1/(1+25x^2)$: наилучший многочлен
      (многоточечный обменный алгоритм на сетке, базис Чебышёва) против
      интерполяции в узлах Чебышёва; $E_n$ убывает геометрически с
      измеренным знаменателем $0{,}8198 = 5/(\sqrt{26}+1)$ (полюсы
      $\pm i/5$); отношение $\|f - L_n\|/E_n$ лежит в $[1, 1+\Lambda_n]$
      (константа Лебега — мост к вопросу 11).
- [x] **П3.** Неединственность без условия Хаара: $f(x) = x$, система
      $\{1, x^2\}$ на $[-1,1]$ — плато уклонения $E = 1$ ровно при
      $a \in [-1/2, 1/2]$; проверка нарушения условия Хаара.
- [x] **П4 (опционально)** — сведение к ЛП закрыто сверкой внутри П1.
