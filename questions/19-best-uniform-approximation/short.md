---
title: "Вопрос 19. Наилучшее равномерное приближение"
---

**Основной результат.** Элемент наилучшего равномерного приближения в
конечномерном подпространстве $C(Q)$ существует всегда; он единствен для
всякой $f$ тогда и только тогда, когда система удовлетворяет условию Хаара
(теорема Хаара), а критерий оптимальности — чебышёвский альтернанс: погрешность
$\Delta=f-p^{*}$ достигает нормы по модулю в $n+2$ точках с чередованием
знаков (теорема Чебышёва). Скорость приближения даёт теорема Джексона
$E_n(f)\le2\omega(\frac{b-a}{n+1},f)$; плотность многочленов — Стоун —
Вейерштрасс.

## Определения

- $V\subset C(Q)$ — множество существования / единственности /
чебышёвское (по множеству $P_V(f)$ элементов наилучшего приближения);
чебышёвское подпространство — конечномерное чебышёвское множество.
- Система $\Phi=\{\varphi_0,\dots,\varphi_n\}$ удовлетворяет **условию
Хаара**, если любой нетривиальный полином из $V_n$ имеет не более $n$
различных нулей на $Q$.
- **Чебышёвский альтернанс** погрешности $\Delta=f-p$: точки
$a\le t_0<\dots<t_{n+1}\le b$ с $\Delta(t_i)=\sigma(-1)^i\norm{\Delta}$,
$\sigma=\pm1$ одно на всех; **валле-пуссеновский набор**: $\Delta(t_i)\Delta(t_{i+1})<0$.
- **Сильная единственность** в $f$: $P_V(f)=\{p^{*}\}$ и
$\norm{p-p^{*}}\le\gamma\bigl(\norm{f-p}-\norm{f-p^{*}}\bigr)$ для всех
$p\in V$.
- **Сеточная постановка:** $E(f,V)_Q=\inf_{p\in V}\max_{t\in Q}\abs{f(t)-p(t)}$
на конечном $Q=\{t_1,\dots,t_N\}$, $N\ge n+2$.

## Леммы

- **Каратеодори.** Всякая точка $\operatorname{conv}M\subset\R^{N}$ — выпуклая
комбинация не более $N+1$ точек $M$.
- **Об экстремальном множестве.** При условии Хаара для погрешности
наилучшего приближения существует $n+2$ точки с $\abs{\Delta}=\norm{\Delta}$.
- Отображение $x\mapsto\rho(x,V)$ липшицево с константой $1$.

## Теоремы

- **Т1 (существование).** Всякое конечномерное подпространство нормированного
пространства — множество существования.
- **Т2 (А. Н. Колмогоров).** $p^{*}\in V_n$ — наилучшее приближение $f$
$\Leftrightarrow$ не существует $q\in V_n$ с $q(t)\Delta(t)>0$ на
$Q^{*}=\{\abs{\Delta}=\norm{\Delta}\}$; эквивалентно: $0\in\operatorname{conv}\{\Delta(t)\varphi(t):t\in Q^{*}\}$,
и тогда есть $n+2$ точки с взвешенным обнулением моментов (по Каратеодори).
- **Т3 (Валле—Пуссен, оценка снизу).** Если у $\Delta=f-p$ есть
валле-пуссеновский набор $t_0<\dots<t_{n+1}$, то
$E_n(f)\ge\min_i\abs{\Delta(t_i)}$.
- **Т4 (П. Л. Чебышёв, альтернанс).** Для $f\in C[a,b]$ многочлен
$p^{*}\in\mathcal{P}_n$ — наилучшее равномерное приближение $\Leftrightarrow$
у $\Delta=f-p^{*}$ есть чебышёвский альтернанс из $n+2$ точек.
- **Т5 (А. Хаар).** $V_n$ — чебышёвское подпространство $C(Q)$
$\Leftrightarrow$ $\Phi$ удовлетворяет условию Хаара.
- **Т6 (о сильной единственности).** При условии Хаара на $[a,b]$ сильная
единственность выполнена с некоторой $\gamma=\gamma(f)>0$.
- **Т7 (о непрерывности метрической проекции).** Для чебышёвского
подпространства со свойством сильной единственности:
$\norm{P(f)-P(f_0)}\le2\gamma\norm{f-f_0}$.
- **Т8 (дискретная задача — ЛП).** При $A=(\varphi_k(t_j))$, $b=(f(t_j))$:
$E(f,V_n)_Q=\min\{u:-u\le(b-Ac)_j\le u\}=\max\{b^{\mathsf T}\nu:
\norm{\nu}_1\le1,\ A^{\mathsf T}\nu=0\}$.
- **Т9 (Стоуна — Вейерштрасса).** Подалгебра $\mathcal A\subset C(B)$ с
константами, разделяющая точки компакта $B$, всюду плотна в $C(B)$.
- **Т10 (Джексона).** $E_n(f)\le2\omega\bigl(\frac{b-a}{n+1},f\bigr)$; для
$f\in C^r$: $E_n(f)\le\frac{K_r}{n^r}\omega\bigl(\frac{b-a}{n+1},f^{(r)}\bigr)$;
для липшицевой с константой $L$: $E_n(f)\le\frac{2L(b-a)}{n+1}$.

## Методы и алгоритмы

- **Алгоритм Ремеза (обмена).** Шаг $k$: по набору
$a\le t_0^k<\dots<t_{n+1}^k\le b$ решают $(n+2)\times(n+2)$-систему
$f(t_i^k)-P_k(t_i^k)=(-1)^i e_k$ относительно коэффициентов
$P_k\in\mathcal P_n$ и $e_k$; для $\Delta_k=f-P_k$ берут точку максимума
$|\Delta_k|$ и заменяют ей одну точку набора, сохранив чередование знаков
(обмен). Критерий остановки: $|e_k|\le E_n(f)\le\|\Delta_k\|_\infty$, стоп
при $\|\Delta_k\|_\infty-|e_k|\le\varepsilon$. Сходимость: на сетке
геометрическая ($E-|e_k|\le\vartheta(E-|e_{k-1}|)$), в непрерывной
постановке при условии Хаара — линейная с константой через сильную
единственность; для гладкой $f$ с невырожденным альтернансом локально
квадратично — обычно 1–2 итерации; на конечной сетке — ЛП (Т8).

## Следствия

- **Вейерштрасс.** $E_n(f)\to0$ для всякой $f\in C[a,b]$; многомерные
многочлены плотны в $C(B)$, $B\subset\R^m$ компакт; тригонометрические
многочлены плотны среди $2\pi$-периодических (все — случаи Т9).
